# Покер в Telegram

Техасский холдем для компании друзей. **Стол — в Telegram Mini App**: зелёное
сукно, свои карты внизу экрана, борд и банк по центру, игроки по кругу, чей
ход — видно сразу. **Группа — лобби и доска объявлений**: карточка комнаты
с кнопкой «🃏 Открыть стол» и итоги вечера. Бот сам тасует, сдаёт, считает
банк и сайд-поты — или, в режиме дилера, игра идёт настоящими картами, а бот
только считает фишки.

Фишки виртуальные. Никаких настоящих денег, платежей и ставок на деньги.

Как и почему устроен интерфейс — [docs/miniapp-ux.md](../docs/miniapp-ux.md).

```
Группа ──/newgame──▶ Бот ──карточка «♠️ Покерная комната · 3/8 · [🃏 Открыть стол]»──▶ Группа
                      │
Кнопка ──t.me/<бот>/<приложение>?startapp=<код>──▶ Mini App (у каждого свой)
                      │                              ▲   │
                      └── WebSocket: состояние стола ─┘   └── FOLD / CALL / RAISE …
```

## Запуск

Mini App — это веб-страница, и Telegram открывает её **только по HTTPS**.
Поэтому кроме токена нужны две вещи: публичный HTTPS-адрес этого процесса и
регистрация приложения у @BotFather. Ниже — как сделать это на своём Маке за
10 минут.

### 1. Туннель: HTTPS-адрес для ноутбука

```bash
brew install cloudflared
cloudflared tunnel --url http://localhost:8080
```

В выводе будет адрес вида `https://something-words.trycloudflare.com` —
это и есть адрес стола. Окно с туннелем не закрывайте, пока играете.

### 2. Приложение у @BotFather

`@BotFather` → `/newapp` → выбрать своего бота → название, описание,
картинка 640×360 (любая) → GIF можно пропустить (`/empty`) →
**Web App URL** — адрес из туннеля → **короткое имя**, например `table`.

BotFather ответит ссылкой `t.me/<бот>/table` — значит, всё правильно.

### 3. `.env`

```bash
BOT_TOKEN=...                                   # от @BotFather, как раньше
WEBAPP_URL=https://something-words.trycloudflare.com
MINIAPP=table                                   # короткое имя из /newapp
```

### 4. Бот

```bash
npm install
npm run bot
```

В консоли: `стол: http://localhost:8080 → https://…trycloudflare.com` и
`long polling запущен`. В группе: `/newgame` → «🃏 Открыть стол».

**Бесплатный адрес cloudflared меняется при каждом перезапуске туннеля.**
Тогда: новый адрес → в `.env` (`WEBAPP_URL`) и у @BotFather (`/myapps` →
ваше приложение → изменить Web App URL), затем перезапустить бота. Постоянный
адрес дают именованный туннель cloudflared со своим доменом или хостинг.

Без `MINIAPP` всё тоже работает, но на шаг длиннее: кнопка в группе ведёт в
личку с ботом, и уже там бот даёт кнопку, открывающую стол (кнопки
мини-приложения Telegram разрешает только в личке).

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `BOT_TOKEN` | — | обязательна |
| `WEBAPP_URL` | — | публичный HTTPS-адрес; без него стол не откроется |
| `MINIAPP` | — | короткое имя из `/newapp`; без него — через личку |
| `PORT` | `8080` | где слушает сервер стола (туннель смотрит сюда) |
| `DB_PATH` | `./data/bot.db` | где лежат столы |
| `DRAW_INTERVAL_MS` | `1000` | как часто можно править карточку в группе |
| `TZ` | системная | часовой пояс в напоминаниях |

`.env` в git не попадает. На хостинге задайте переменные в настройках
сервиса — они важнее файла. **Токен никому не пересылайте и не
фотографируйте**; если он утёк — `@BotFather` → `/revoke`.

Privacy mode бота оставьте включённым: читать переписку группы боту не нужно.
Права администратора тоже не нужны.

## Как играть

1. В группе `/newgame`. Автор — хост. Бот присылает карточку комнаты.
2. Каждый жмёт **«🃏 Открыть стол»** → приложение открывается сразу на этой
   комнате → **«Сесть за стол»**. Код вводить не нужно.
3. Хост в приложении (⋯ → «Настройки стола») выбирает стек, блайнды, таймер
   хода и режим: **карты раздаёт бот** или **настоящие карты и дилер**.
4. Хост жмёт **«▶ Начать»**. Дальше всё в приложении.

За весь вечер в группе появляются **два сообщения**: карточка комнаты (она
правится по ходу игры: «раздача #5 · флоп · 👉 ход: Макс», итог раздачи) и
итоги в конце (`/finish`). Никакого спама после каждого хода.

Команды в группе: `/newgame`, `/table` (карточка вниз чата), `/finish`
(итоги, хост), `/cancel` (удалить стол, хост), `/help`.

### Стол

- **Свои карты** — всегда внизу, крупно, настоящими картинками (52 SVG).
  Под ними — название комбинации.
- **Чей ход** — подсвеченное место (и кольцо таймера, если он включён) у всех;
  у того, кто ходит, —
  «ВАШ ХОД», подсветка своих карт, другая панель и вибрация.
- **Панель**: FOLD · CHECK или CALL N · RAISE/BET. Когда чек бесплатный, FOLD
  спрятан — самый дорогой случайный тап. RAISE открывает шторку: +BB, ½ POT,
  POT (тап — и ставка сделана), ползунок для своей суммы. **ALL-IN — только со
  второго тапа.**
- **Стадия** — PRE-FLOP / FLOP / TURN / RIVER / SHOWDOWN в шапке.
- **Итог раздачи** — по центру стола; победители подсвечены, у проигравших на
  вскрытии — их карты или «НЕ ПОКАЗАЛ».
- **Выигрыш видно**: фишки летят из банка к победителю, банк тает, а его
  баланс на глазах докручивается до новой суммы — золотом, с «+N» рядом.
- **Движение рассказывает, что произошло**: карты разлетаются по кругу при
  раздаче, борд переворачивается по карте, ставка улетает фишками в банк,
  сброшенные карты уходят в центр, у того, чей ход, — вспышка по краям
  экрана и выезжающие кнопки; последние 10 секунд таймера — красным.
  Открыли стол посреди раздачи — он показывается спокойно, как есть, без
  повторной раздачи. Системная настройка «Уменьшить движение» выключает всё
  это.

### «Ваш ход» в личку

Только если **стол у игрока сейчас закрыт** (приложение свёрнуто) и он хоть
раз нажал Start у бота. В напоминании — раздача, сколько коллировать, банк и
кнопка открыть стол. **Когда ход прошёл, напоминание удаляется** — в личке не
копятся устаревшие «ваш ход». Карт в личке нет никогда.

### Режим дилера (настоящие карты)

Хост включает «Настоящие карты» и назначает **дилера** (⋯ → Хост → Роли).
Дилер сидит за столом, но карт не получает и не играет: он тасует и сдаёт
настоящую колоду, бот ведёт фишки, очередь и банк.

После вскрытия у дилера — **«🏆 Кто выиграл?»**: крупные плашки игроков,
тап — победитель, несколько тапов — делёж. Если банков несколько (сайд-поты),
он проходит их по очереди. Затем экран итога: кто сколько получит — и
**«✅ Подтвердить»**. Только после этого бот раздаёт фишки. Ошибся — хост
может отменить результат до следующей раздачи. Решает дилер; запасной
вариант — хост, чтобы севший телефон дилера не заморозил стол. Игрок сам себе
банк не присудит. (Настоящие карты без назначенного дилера — отмечает любой
сидящий за столом.)

Роль, назначенная посреди раздачи, начинает действовать со следующей.

## Два железных правила

### 1. Никто не ходит за другого

Mini App получает от Telegram `initData`, **подписанный токеном бота**
(HMAC-SHA256 по правилам Telegram). Сервер проверяет подпись при открытии
стола, и с этого момента человек в этом соединении — его настоящий Telegram id.
Это вся модель безопасности: ни паролей, ни кодов.

- **Тело сообщения ничего не решает.** `{t:'act', action:'fold'}` — это ход
  того, чей это сокет. id, место, имя в сообщении игнорируются — тест
  подкладывает их все.
- **Подделка, чужой бот, старая сессия** (старше суток) — стол не откроется.
  Проверка сверена с опубликованным примером подписи из документации tma.js,
  а не только с собственным подписывателем.
- **Комната — из подписи.** Код комнаты приходит как `start_param` внутри
  `initData`; страница не может подменить его другим.
- **Открыть стол ≠ сесть.** Смотреть может любой по ссылке, сесть — отдельное
  нажатие. Хост может удалить любого.
- **Отказ всегда озвучен** — всплывающим сообщением («Сейчас ходит Макс»).
- **Анонимные админы** не могут создать стол; **один аккаунт — одно место**,
  даже с двух телефонов.
- **Права хоста** (настройки, роли, докупка, удаление, пауза, итоги) — по id.
- **Единственное исключение — таймер хода**: когда время вышло, бот делает
  бесплатный ход — чек, если можно, иначе фолд. Фишки он не тратит никогда.

### 2. Никто не видит чужих карт

Сервер не рассылает общее состояние: **каждое окно получает своё**, собранное
для этого человека. В нём его две карты; борд — ровно столько, сколько уже
открыто; чужие карты — только тех, кто обязан показать их на вскрытии.
Колоды, будущих карт борда и чужих карманных в данных нет вовсе — их нельзя
выковырять даже из инструментов разработчика.

В группе и в личке карт нет никогда: карточка комнаты говорит только стадию
(«флоп»), а не борд.

Тесты проверяют это по **всему**, что каждое окно получило за игру, и по всем
сообщениям в группе, включая правки и удалённые.

## Карты

- **Колода** — Фишер–Йетс на `crypto.randomInt`. Сдача — по карте за круг с
  места слева от баттона.
- **Вскрытие** автоматическое; каждый банк — лучшей руке **среди своих
  претендентов** (короткий олл-ин с тузами берёт основной банк, сайд-пот —
  лучшая из остальных). Делёж и лишняя фишка — забота движка.
- **Кто показывает**: победитель спорного банка и все в олл-ине. Если против
  олл-ина остался максимум один игрок с фишками (олл-ин один на один,
  доигрывание борда) — открывают **все**, как в правилах TDA. Остальные
  проигравшие сбрасывают молча («НЕ ПОКАЗАЛ» — без карт и без названия
  комбинации): так бывает, когда за сайд-пот ещё торговались двое. Возврат
  неуравненной ставки победой не считается.
- **Олл-ин до ривера**: борд открывается по улицам — флоп, тёрн по полторы
  секунды, — карты игроков пока рубашкой вверх (свои вы видите всегда). С
  ривером все переворачивают карты, выигравшая пятёрка поднимается и
  загорается золотом, остальные карты гаснут — и только потом фишки уходят
  победителю. Пока борд открывается, ни карты соперника, ни стеки, ни итог
  не видны — ни на столе, ни в группе, ни в данных, пришедших на телефон.
- **Последняя раздача вечера** доигрывается на столе целиком — и только
  потом приложение показывает итоги (или раньше — кнопкой «🏁 Итоги вечера»).
- **Числа** — с точками: 1.000.000, везде — на столе, в группе, в итогах.

`server/game.js` (движок ставок, общий с веб-версией) не менялся.

### Таймер хода и автораздача

Выключены по умолчанию. Хост включает в настройках: 30 / 60 / 90 / 120 секунд.

- Время вышло — чек или фолд. Два таймаута подряд — игрок «пропускает»
  раздачи, пока сам не вернётся. Новая улица — новое время.
- Следующая раздача — сама через 10 секунд (кнопка — раньше; двух раздач не
  будет). В режиме дилера автораздачи нет: следующую начинает дилер (или
  хост), когда колода перетасована.
- Раздача, в которой никто не сходил сам, ставит стол на паузу — бот не
  раздаёт в пустую комнату.
- Пауза останавливает часы; рестарт бота не съедает время.

### Undo — только для действий хоста

Колоду держит бот, поэтому откат игры был бы эксплойтом (отменил фолд —
посмотрел флоп бесплатно). Любое игровое событие очищает undo. Хост может
отменить свою докупку, смену блайндов, удаление, передачу прав, роль — и,
в режиме дилера, результат раздачи до следующей сдачи.

## Ограничения Telegram и что с ними сделано

| Ограничение | Что сделано |
|---|---|
| Кнопка мини-приложения (`web_app`) — только в личке | в группе — URL-кнопка на прямую ссылку `t.me/<бот>/<приложение>?startapp=<код>`; без `MINIAPP` — `t.me/<бот>?start=t_<код>`, и бот отвечает в личке кнопкой `web_app` |
| Mini App — только HTTPS | `WEBAPP_URL` + туннель или хостинг; без адреса бот предупреждает при старте |
| Код комнаты должен дойти до приложения | `startapp` → `start_param` внутри подписанного `initData` |
| Бот не может написать первым | «ваш ход» в личку — только тем, кто нажал Start; остальным — ничего, и бот даже не пытается |
| ~20 сообщений в минуту в группу | одна карточка на игру, правки склеиваются и не чаще раза в секунду; окна приложения получают состояние мгновенно по WebSocket — там лимитов нет |
| `message is not modified` | текст и кнопки сверяются до отправки |
| Кнопки старой чат-версии в истории | на нажатие отвечают ссылкой на стол — без вечного спиннера |
| Пользователь заблокировал бота | больше не получает напоминаний |
| Группа → супергруппа меняет `chat.id` | стол переезжает, код комнаты и открытые окна продолжают работать |
| Люди выходят из группы | вышедшего складывают, олл-ин доигрывает; если остался один — банк его |
| Бота удалили из группы | стол удаляется, открытые окна получают «игру удалили» |

## Как устроено

| Файл | Что делает |
|---|---|
| `index.js` | запуск: `.env`, grammY (long polling), HTTP+WS-сервер |
| `app.js` | бот: команды группы, карточка комнаты, напоминания, таймеры |
| `hub.js` | WebSocket-сессии: проверка `initData`, действия игроков → комната |
| `server.js` | раздаёт `miniapp/`, `/ws`, `/health`; лимиты сообщений |
| `webapp-auth.js` | проверка подписи `initData` |
| `view.js` | состояние стола глазами одного человека (приватность здесь) |
| `room.js` | комната: игроки, роли, раздачи, победители, таймеры, undo |
| `cards.js`, `deck.js`, `eval.js` | колода, сдача, вскрытие, оценка рук |
| `render.js` | тексты для Telegram: карточка, «ваш ход», итоги |
| `store.js` | SQLite (`node:sqlite`): столы и кто нажал Start |
| `../miniapp/` | само приложение: `index.html`, `style.css`, `app.js`, `cards/*.svg` |

Приложение — без сборки и фреймворков: один JS-файл, работает в WebView
Telegram на iOS и Android. После обрыва связи переподключается само и
получает состояние целиком.

### Состояние и перезапуски

Комнаты в памяти, копия в SQLite при каждом изменении. После рестарта — та же
раздача, те же карты, тот же игрок на часах; открытые окна переподключаются.

### Честно о доверии

**Кто запускает бота, тот технически может прочитать базу** — там колода
текущей раздачи. Для компании друзей это обычное «кто-то хостит»; бот эти
данные нигде не показывает и в логи не пишет. В режиме дилера колоды в базе
нет вовсе.

### Хостинг

Процесс должен не засыпать и быть доступен по HTTPS. Ноутбук + cloudflared —
для вечера с друзьями; для постоянной игры — VPS или Fly.io с доменом
(`PORT` за HTTPS-прокси). Бесплатный Render засыпает через 15 минут тишины —
не подходит.

## Проверка

```bash
npm test          # всё: 60 тестов веб-версии + 175 тестов бота
npm run test:bot  # только бот
npm run preview   # скриншоты стола в preview/ (нужен Playwright)
npm run e2e       # три браузера играют две раздачи тапами (нужен Playwright)
npm run cards     # пересобрать 52 SVG-карты
```

Telegram заменён стабом (`tg-stub.js`), который не поддакивает: отказывает в
личке тем, кто не нажал Start (403), запрещает кнопку `web_app` в группе,
воспроизводит «message is not modified». Приложение в тестах — настоящий хаб
с настоящей проверкой подписи; время — фальшивые часы.

- **`webapp-auth.test.js`** — подпись: чужой пример из документации, подмена
  любого поля, чужой бот, старая сессия, мусор.
- **`identity.test.js`** — никто не ходит за другого: чужая подпись, чужая
  комната, не свой ход, id и место в теле сообщения, зритель, права хоста,
  дилер решает банк, одно место на аккаунт, каждый отказ озвучен.
- **`cards.test.js`** — чужие карты: всё, что получило каждое окно, и вся
  группа; кто показывает; борд по улицам; лучшая рука; делёж; сайд-поты;
  длинная сессия с докупками.
- **`dealer.test.js`** — режим дилера: роли, дилер без карт, выбор
  победителя, делёж, сайд-поты по шагам, подтверждение, отмена.
- **`timer.test.js`** — таймер хода, пропуски, автораздача, пауза, рестарт,
  олл-ин-борд по улицам без спойлеров.
- **`app.test.js`** — бот как лобби: ссылка ведёт в нужную комнату, за вечер

## Чего здесь нет

- **Выбора «показать / сбросить» на вскрытии** — правило фиксированное (см.
  «Кто показывает»): иначе вскрытие ждало бы каждого проигравшего.
- **Игры командами в чате.** Раньше ставки делались `/call`, `/raise 300`;
  теперь всё в приложении — одним тапом, без опечаток и без спама в группе.
- **Карт в личке.** Свои карты — на столе, приватно для каждого.
