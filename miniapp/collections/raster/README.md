# Растровое оформление

Север B — карта побережья, Обсидиан A — минеральный скол, Чертёж B —
сборочная схема. Для продолжения выбраны Терракота A — печные арки,
Орбита B — затмение, Фарфор B — ивовая ветвь. Исходники сделаны через
ImageGen. Отдельные спрайты выделены по альфа-каналу,
масштабированы и сжаты в WebP с сохранением прозрачности.

Рубашка используется в покере и UNOQ. Рамки аватаров, значки и два
талисмана на серию тоже используют WebP. Для столов и досок шести серий
теперь применяется `collections-surfaces.css` и текстуры из
`../surfaces/`. Игры сами рисуют клетки, координаты и клинья, поэтому
оформление не требует растягивать рамку поверх поля. Старые изображения
доступны по своим адресам для совместимости. Права и идентификаторы
предметов сохранены.
