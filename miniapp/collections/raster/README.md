# Растровое оформление

Север B — карта побережья, Обсидиан A — минеральный скол, Чертёж B —
сборочная схема. Для продолжения выбраны Терракота A — печные арки,
Орбита B — затмение, Фарфор B — ивовая ветвь. Исходники сделаны через
ImageGen. Отдельные спрайты выделены по альфа-каналу,
масштабированы и сжаты в WebP с сохранением прозрачности.

Рубашка используется в покере и UNOQ, контур доски — в четырёх настольных
играх. Рамка стола, рамка аватара, значок и два варианта талисмана
отдельны. Рабочие соответствия в `../raster.js`. Предыдущие SVG остаются
по старым адресам для совместимости. Доступ к предметам определяется
каталогом и сохранёнными правами, независимо от формата арта.
