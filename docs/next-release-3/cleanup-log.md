объединение WS-обновлений и разбиение модулей первой загрузки. Кэш потребовал бы

вообще нет мёртвого кода. Новые perf-инструменты и отчёты откатываются обычным
обратным коммитом этапа L; схему, записи и рабочее поведение они не меняют.
