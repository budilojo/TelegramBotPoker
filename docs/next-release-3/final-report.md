## Телефонный чек-лист — ещё не выполнен (4/5)

На **iOS и Android**, два аккаунта + второе устройство одной личности + зритель,
после отдельно разрешённой подготовки внешней среды:

1. Группа/личка → каталог кнопками и пальцем → лобби → семь игр; последнее место,
   несколько столов/групп, длинные имена, небольшой экран и увеличенный текст.
2. Telegram Back по слоям, профиль и настройки: ввод/курсор при обновлениях,
   настоящая клавиатура, safe-area у «домой», VoiceOver/TalkBack и reduced-motion.
3. Стол → раздел → тот же стол; обрыв сети/фон/возврат/перезагрузка, часы/место/
   карты/конец в фоне; обновлённый Mini App открыть заново. Пальцем drag/tap,
   расстановка/поворот/выстрел, режим «Крупно», shareMessage и меню команд.
4. Шахматный мат: победа/поражение обоим, одно сообщение в группе, «Ещё раз» →
   согласие второго; повтор после возвращения приложения.
5. Поддержка из настроек и покупок: правильный бот, сообщение→reply→ответ только
   автору. Пульт: ввод цены, два шага/края окна, подарок и отзыв как отдельное право.
6. Примерка/вид в поддерживаемых играх/история. **Только в официальном тестовом
   Telegram**: окно оплаты, успех/отмена/нехватка Stars/двойное нажатие, фон и поздний
   результат, выдача на двух устройствах, полный возврат/сообщение/история,
   остановка новых счетов при сохранении старых событий. Сохранить внешние доказательства.
7. Первое открытие, действие→ответ, боты/длительная партия, фон и нагрев. CPU×4
   и localhost не телефон и не ёмкость сервера.

Не проверены все настоящие iPhone/Android, планшеты, Telegram Desktop/Web,
официальный тестовый платёж и настоящая оплата/возврат. Chromium с подставленным
SDK не является ни устройством, ни тестовой средой Telegram.

   снять полную SQLite-копию. Оплаченные события обрабатываются и на обслуживании.
3. Только fast-forward без force/правок кода на сервере. Схема 5; pay_*, support_*,
   shop_* сохраняются. Установить зависимости из проверенного lock; не полагаться
   на старую фразу «новых зависимостей нет». SALES_MODE оставить off, демо выключено.
4. Проверить здоровье/восстановленные столы/часы/причины gate/закрытый рейтинг/

   инструкции. Состояние сервера сейчас неизвестно; этот план его не устанавливает.
5. Откат: остановленные новые продажи + ноль в пути + копия; старый код сохраняет

   сверка. Восстановление файла базы — только на остановленном процессе с устранением
   старых WAL/SHM по разрешённой инструкции. Боевые данные не удалять наугад.
6. Открытие продаж/рейтинга и продвижение main — отдельные действия владельца,
   не следствие зелёного M и не часть этого поручения.
