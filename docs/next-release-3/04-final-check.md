# M — независимая итоговая проверка всего

Проверяй **фактический код** шагов F–L и пакета 1, повторяя критические сценарии независимо от отчётов авторов.

## Выполнить
`npm test`; полный `npm run e2e`; `layout`, `kit`, `contrast`; `preview` с просмотром снимков; `colors`, если затронут UNOQ; профильные проверки приватности, платежей, восстановления, производительности (сравнить `perf-baseline.md` и `perf-after.md` — регрессии?).
Известная нестабильность: `preview` иногда падает по таймауту; `battleship.bot.test.js` — прежняя причина найдена в тесте (E), но **новый прогон не считать заведомо зелёным**. Нестабильное не скрывать.

## Проверить отдельно
1. Платёжная матрица B и возвраты — на заглушке; продажи закрыты (`gate()` называет причины); нет пути купить преимущество в игре; независимость источников права (покупка / выдача админом / тестер владельца); **бесплатный доступ владельца не стал бесплатной выдачей всем**.
2. Поддержка и админка магазина: отказ не-админу, чужая переписка недоступна, смена цены не меняет выставленные счета.
3. Откат старой версии на базе с новыми таблицами; восстановление из копии тестовой базы; незавершённые платежи.
4. Рейтинг остаётся закрытым; старые очки не пересчитаны; отдельный банк и Лига не появились.
5. Документы `legal/` и тексты бота совпадают с поведением; незаполненные реквизиты не выдаются за готовые документы.

## Итоговые документы
Обновить `docs/next-release/release-readiness.md`: решения «готово / не готово» отдельно для кода, бесплатных функций, открытия продаж, рейтинга; препятствия с доказательствами и условием снятия.

Не заявлять «всё законно», «оплата работает», «ошибок нет». Не выкатывать, не ходить на сервер, `npm audit fix --force` не запускать.
