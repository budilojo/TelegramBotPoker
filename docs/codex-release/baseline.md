## Первые замеры до правок

(2/3): 10/50/100/200 столов, 100 повторов syncClocks: 0,019 / 0,073 /
0,104 / 0,164 мс. 100 таймеров после удаления столов → 0; 301 подписка
после close → 1 (страница хоста); после forget → 0. Очередь 1000/1000 за 1 мс;
куча 8,9 → 9,1 → 9,1 МБ. Строка комнаты 1793 байт, с 200 записями истории
11882 байт. Это один разогревочный прогон одновременно с npm test, только
ориентир. Повторяемые изолированные измерения — `perf-baseline.md`.

Первый npm test без разрешения локальных сокетов упёрся в `listen EPERM`;
повтор запущен с разрешённым localhost. Это ограничение среды, а не доказанный
дефект приложения. Точные итоговые результаты — `reports/check2.md`.
