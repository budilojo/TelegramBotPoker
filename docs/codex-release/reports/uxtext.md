### Падения не скрыты

- Первый fetch без разрешения записи служебного FETCH_HEAD: Operation not permitted;
  повтор с разрешением прошёл, 0/0. Отказа автоматической проверки разрешения не было.
- Первый npm run e2e использовал унаследованный E2E_PORT=10080, Chromium отказал
  ERR_UNSAFE_PORT. Повторён с явным 8250; код порты не обходил. Первая новая
  попытка e2e-uxtext без разрешения localhost: listen EPERM; повтор разрешён.
- Прогон, начатый до UI-правок, читал меняющийся код: не считается чистым исходным
  замером. Остановился на e2e-nav: старый тест нажимал Escape, затем backdrop,
  рассчитывая, что Escape ничего не делает. Тест теперь проверяет закрытие по
  Escape, **снова открывает** и проверяет backdrop; обе проверки сохранены.
  e2e-settings вместо 30-секундного catch на исчезнувшем backdrop требует его
  ожидаемое исчезновение. Изменение ожидания теста названо отдельно.
- Черновики нового e2e: открытие train-ex без startRun не создавало упражнение;
  исправлена фикстура на экспортированный startRun. Async-предикат ожидания
  reconnect давал ложный положительный результат в Playwright; теперь проверяется
  синхронно новый открытый сокет и полученное состояние. Ошибочная диагностическая
  вставка сняла условие game!==colors с клика «Сохранить»; убрана, исходный контракт
  UNOQ «Готово»/мгновенные нажатия сохранён. Это ошибки нового теста, не продукта.
- Все отдельные красные воспроизведения дефектов перечислены выше; логи сохранены.
  Второй полный 31-файловый проход exit 0 был до последней доводки K; окончательный
  32-файловый проход включает сам новый e2e. Старые зелёные отчёты не зачтены.
- Исторический таймаут preview в текущих запусках не повторился. На снимках с
  соседней нагрузкой некоторые живые часы успели закончиться (видна законная
  отмена партии); это не доказательство неподвижного эталонного кадра. Живые
  доски дополнительно проверены игровыми e2e и первыми снимками этой сессии.
