# Выкатка в прод: что нажать и что отдать Claude Code

Сервер сейчас на `52524d0`. С тех пор накопилось: постоянный рейтинг и рейтинг
по группам, своя колода, хаб и экран рейтинга, стол дурака, кнопка «Бито/Пас»,
автозакрытие заброшенных столов и новая игра «Радуга».

**Схема базы не меняется** (остаётся v5), **новых зависимостей нет** —
`package-lock.json` не тронут. Выкатка чисто кодовая: ничего не мигрирует и
ничего не пересобирается.

## Шаг 1 — это делаете вы, в Telegram

Напишите админ-боту:

```
/pause Обновляемся — вернёмся через пару минут
```

Игра замрёт целиком: у всех, кто за столом, появится экран с этим текстом,
часы встанут и ничей ход не сгорит.

## Шаг 2 — это отдаёте Claude Code

Скопируйте всё, что ниже разделителя.

---

Нужно выкатить на сервер ветку `claude/bold-carson-kjswyx`. Обслуживание уже
включено мной через админ-бота — сам его не трогай и не снимай.

Факты, которые уже проверены, перепроверять не надо: схема базы не меняется
(v5), новых зависимостей нет, `npm test` локально даёт 505 тестов без падений,
e2e и вёрстка зелёные.

**1. Осмотрись, ничего не меняя.**

```
ssh <сервер>
systemctl is-active worldcard
sudo -u worldcard git -C /opt/worldcard log --oneline -1
ls -la /opt/worldcard/backups/ | tail -5
df -h /
```

Покажи мне, что увидел. Если текущий коммит не `52524d0` — остановись и
скажи: значит, на сервере что-то, чего я не знаю.

**2. Обнови.**

```
sudo /opt/worldcard/deploy/update.sh claude/bold-carson-kjswyx
```

Скрипт сам снимает бэкап базы, забирает ветку, ставит зависимости
(`npm ci --omit=dev`), **гоняет тесты на сервере** и только потом
перезапускает. Если тесты на сервере упадут — он не перезапустит бота; в этом
случае ничего не чини на ходу, покажи мне вывод.

**3. Проверь, что живое.**

```
systemctl is-active worldcard
journalctl -u worldcard -n 50 --no-pager
curl -s -o /dev/null -w '%{http_code}\n' https://<домен>/health
curl -s https://<домен>/health
curl -s -o /dev/null -w '%{http_code}\n' https://<домен>/colors/R5.svg
sudo -u worldcard sqlite3 /opt/worldcard/bot.db 'PRAGMA user_version;'
sudo -u worldcard sqlite3 /opt/worldcard/bot.db '.tables'
```

Чего жду: сервис active, в логах нет ошибок и исключений, `/health` отдаёт 200,
картинка карты «Радуги» отдаётся 200 (это новые файлы — если 404, значит
статика не доехала), `user_version` равен **5** — он не должен был измениться,
таблицы рейтинга (`ratings`, `ratings_group`, `rating_log`, `party_day`) на
месте.

**4. Доложи и остановись.**

Скажи мне: какой коммит теперь на сервере, сколько тестов прошло на сервере,
что в логах, что ответил `/health`. **Обслуживание не снимай** — его сниму я
сам, когда проверю бота руками.

**Если что-то пошло не так — откат:**

```
sudo -u worldcard git -C /opt/worldcard reset --hard 52524d0
sudo -u worldcard npm --prefix /opt/worldcard ci --omit=dev
sudo systemctl restart worldcard
```

База при этом не трогается: схема не менялась, старый код читает её как
читал. Бэкап всё равно лежит в `/opt/worldcard/backups/`.

Чего не делать: не создавать pull request, не переключать ветку на другую, не
открывать и не показывать `.env`, не снимать обслуживание, не править код на
сервере.

---

## Шаг 3 — снова вы

Когда Claude Code доложит, что всё поднялось:

```
/resume
```

И проверьте руками в группе, по порядку:

1. `/game` → в хабе **три** игры: Покер, Дурак, Радуга;
2. создайте стол «Радуги», сядьте вдвоём, сыграйте несколько ходов —
   посмотрите, что карты поднимаются и что подсказка не лезет на соперников;
3. откройте «Рейтинг» — экран открывается, своя строка видна;
4. старый покерный или дурацкий стол, если он остался с прошлой недели,
   должен открыться как раньше.

Если что-то не так — `/pause` обратно, и зовите меня: откат занимает минуту.
