# Профиль игрока: ник и аватар

Волна 2, агент T (2026-10-23). **Профиль — только то, как человека видно.**
Личность и права определяет Telegram (подписанный `initData`); ник «Хост» хостом
не делает, чужое имя не даёт чужих действий.

## Что есть

- Экран «Профиль» (`renderProfileSettings` в `miniapp/profile.js`): поле ника со
  счётчиком, отказ словами под полем, «Сохранить», «Сбросить к имени из Telegram»,
  сетка аватаров 4×3 («Без аватара» + 12), предпросмотр «Так вас увидят за столом»,
  строка про то, что ник видят все в группе.
- Сообщение страницы `{ t: 'profile', nickname?, avatar? }`: без полей — «покажи мой
  профиль». Кто — только из подписи страницы. Ответ — `{ t: 'profile', profile }` или
  `{ t: 'profile', error: { code, text } }` (отказ словами; тостом не дублируется).
- Сервер: `bot/profile.js` (правила ника, набор аватаров, частота, подгонка имён за
  столом), таблица `profiles` в `bot/store.js`.
- Круг игрока: `avatarEl(player, cls)` — картинка из набора, а нет её — инициал.
  В видах всех семи игр у игрока поле `avatar` (id из списка или `null`).

## Правила ника

2–16 символов после очистки (не 20: имя за столом везде режется до 16 —
`cleanName`); буквы любых алфавитов, цифры, пробел, `_ - .`, обычные смайлики;
подряд идущие пробелы схлопываются; пустой ник = имя из Telegram. Отказ (не тихая
правка) за: невидимые и управляющие символы (в том числе ZWJ, RTL-override), `@`,
`://`, `t.me`, `www.`, адреса вида `имя.ru`, ник из одних знаков. Смена — не чаще
раза в 10 секунд и 6 раз в час. Такой же ник, как у уже сидящего за столом (без
учёта регистра), получает « 2», « 3»… — сидящий дольше имя не теряет.

## Где показывается

За столом всех игр и в дуэлях (имя и аватар), в карточке и итогах в группе (имя —
оно **публично для группы**, экран настроек об этом предупреждает), в рейтинге (имя
и аватар берутся из профиля **на момент показа**; старая строка в таблице рейтинга
не переписывается). Чат (агент Q) берёт автора из вида стола: `name` и `avatar`.
При смене ника имена за столами человека (кроме законченных партий) меняются сразу.

## Хранение и откат

Таблица `profiles(user_id, nickname, avatar, updated_at)` создаётся `CREATE TABLE IF
NOT EXISTS`; **версия схемы осталась 5**. Проверено: старый код с сервера (`7afb285`)
открывает базу, где эта таблица есть, и не замечает её; новый код после этого читает
профиль как прежде. Откат релиза безопасен: профили просто перестанут показываться.

## Аватарки: как подключить настоящие

Сейчас — временные плоские значки зверей `miniapp/avatars/av01.svg … av12.svg`
(`node tools/build-temp-avatars.mjs`). Клиент берёт `.svg` (переключатель `AVATAR_PNG`
в `miniapp/ui.js` выключен: на PNG, которых нет, не стучится — иначе 404 в консоли),
при ошибке — инициал. Когда владелец сгенерирует картинки
(`docs/next-wave-2/images-avatars.md`): положить `av01.png … av12.png` в
`assets-incoming/avatars/` и сказать агенту «подключить аватарки» — он переложит файлы в
`miniapp/avatars/`, проверит вес (≤ 20 КБ, 128×128) и **поставит `AVATAR_PNG = true`**
(тогда сначала PNG, при ошибке — SVG, потом инициал).

частота по `FakeClock`, неизвестный аватар, права, двойник имени, все семь игр,

телефона, сохранение после перезапуска Telegram.
