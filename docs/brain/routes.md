# Выборочный контекст проекта

Основной инструмент — [Atlas](https://github.com/fkenmar/atlas), локальная карта
импортов и символов. Установлен **0.2.1-alpha** (предварительный релиз), Mac ARM64,
контрольная сумма архива сверена с файлом официального релиза. Бинарник в
`.tools/atlas-v0.2.1-alpha/atlas-aarch64-apple-darwin/atlas`, не входит в Git/продукт.
Дополнительные модели, API-ключи и сервер индекса не нужны.

## Порядок чтения

1. AGENTS.md полностью; 00-index.md и текущие части status/tasks до первой
   исторической записи. Последняя сессия — по заголовкам и итоговому состоянию;
   подробности и предыдущие сессии только по зависимости задачи.
2. Задание целиком. Выбрать маршрут ниже; читать перечисленные документы и код.
3. Карта показывает, где искать. Перед изменением читать реализацию и её
   потребителей. При недостатке карты расширять rg/чтение, включая динамические
   реестры, CSS/HTML/SVG и совместимость старых данных.
4. Обновить память и документы затронутой области. Никакого чтения всех старых
   пакетов «на всякий случай». Полные npm test перед коммитом и независимая
   итоговая проверка сохраняются.

## Маршруты

| Ключ | Задача | Начальные точки |
|---|---|---|
| shop | магазин, права, примерка, надеть | miniapp/collections, bot/collections, contracts и FINAL косметики v2 |
| art | графика и коллекции | v2-art, build-cosmetics-v2, дизайн-план |
| games | правила, приватность, часы, reconnect | bot/games, hub, harness, game-hub, duels |
| ux | меню, тексты, узкие экраны | nav/app/hub, redesign, scroll, MESSAGES |
| payments | Stars, выдача, возврат, поддержка | bot/payments, collections, store, support, payment-design |
| rating | закрытый рейтинг | rating/ranked, соответствующие планы |
| perf | замеры и нагрузка | hub/store/net/app, load-check/load-ws |
| deploy | разрешённая выкатка | next-deploy-prompt, prod, hosting |
| audit | общая независимая проверка | ядро + платежи + косметика; затем все области задания |

Команда без `--run` выводит текущую карту и ничего не запускает:

```sh
node tools/brain-context.mjs shop
node tools/brain-context.mjs shop --run "Исправь конкретную проблему магазина"
```

`--run` открывает обычный интерактивный Codex в этой копии. Модель и её усилие
берутся из настроек Codex; инструмент их не меняет. Завершённые пакеты агентов
не перезапускаются. Старые пакетные раннеры также получают карту автоматически.

Карта пересчитывается при каждом запуске из текущих файлов, а не хранится как
быстро устаревающая копия кода. Бюджет Atlas 1200 токенов; подсказки/правила/задача
идут дополнительно. Это лимит навигационной карты, а не всей работы агента.
Проценты экономии на нашем проекте пока не измерены.

## Установка в другой копии

С официальной [страницы v0.2.1-alpha](https://github.com/fkenmar/atlas/releases/tag/v0.2.1-alpha)
скачать архив Mac ARM64 и одноимённый `.sha256`, проверить `shasum -a 256 -c`,
распаковать в путь выше. На другой ОС адаптировать ATLAS в brain-context.mjs.
Установщик из сети автоматически не выполняется. Если бинарника нет/он сломан,
доступна таблица маршрутов, а в подсказке явно обозначено отсутствие карты.

`.atlasignore` исключает историю docs, секретные конфиги, данные, зависимости и
отдельный старый продукт server/public. Для задачи старого продукта искать его
явно: отсутствие в карте не означает отсутствие кода. Atlas не заменяет ревью
и не гарантирует полного распознавания динамических связей.
