# В вид попадает только публичное оформление

- **Дата:** 2026-10-27
- **Кто решил:** агент (server, пакет «Графит»); по контракту, без утверждения владельцем
- **Статус:** принято

## Что решили

В tableView покера и view дурака добавлены только look {v, table, backs[{seat,item,color}], dealNo} и players[].frame / results[].frame {item,color}. Ни id людей, ни owned/choice/pending, ни демо-флагов и цен там нет; личное состояние {t:'col'} уходит только владельцу.

## Почему

Правило проекта «никто не видит чужого»: рубашки привязаны к месту, а не к id; проверено тестом на всю историю сообщений трёх телефонов.
