# 094. Платежи — только Telegram Stars (XTR)

- **Дата:** 2026-10-27
- **Кто решил:** агент H (предложение; решает владелец)
- **Статус:** предложено

## Что решили

Любой цифровой товар продаётся только за Stars через бота; внешние платёжки исключены. Нужны `/paysupport`, `/terms`, возврат, хранение номера платежа.

## Почему

Проверено 2026-10-27 по core.telegram.org/bots/payments-stars и ToS §6.2: иначе Telegram скрывает приложение у мобильных пользователей.
