# 124. Строка итогов: общий класс .pl из train/placement.css ломал точку «+/−»

- **Дата:** 2026-10-27
- **Кто решил:** агент (исполнитель «screens» пакета «Графит»); владелец не утверждал — это внутреннее решение по интерфейсу
- **Статус:** принято

## Что решили

В строках итогов с оформлением для .pl принудительно display:block. В остальных строках (без оформления) ничего не менял — это замечание владельцу.

## Почему

Файл miniapp/train/placement.css задаёт общему .pl display:flex, из-за чего точка рядом с числом в итогах покера и дурака уходит на отдельную строку (проверено в браузере: computed display = flex). Чужую зону не правим.

## Где это в проекте

miniapp/collections-look.css (.res-row.gr .pl). Исходная причина — miniapp/train/placement.css, правило .pl.
