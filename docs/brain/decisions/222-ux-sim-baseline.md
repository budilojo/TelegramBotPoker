# 222. UX-симуляция сверяется с эталоном «как есть»

- **Дата:** 2026-11-27
- **Кто решил:** агент (исполнитель S пятого пакета)
- **Статус:** принято

## Что решили

`npm run ux:sim` пробует разные жесты в настоящем браузере и сверяет исход с `tools/ux-sim-baseline.json`. Эталон
описывает нынешнее поведение, а не желаемое; намеренную перемену записывают `--update`, посмотрев разницу.

## Почему

Задание требовало воспроизводимых скриптов, замечающих подмену жеста, а часть найденного ещё будут чинить (V–X).

## Где это в проекте

`tools/ux-sim-*.mjs`, `tools/lib/ux-sim.mjs`, `docs/next-release-5/ux-sim-report.md`; «на зубы» — `tools/ux-sim-teeth.mjs`.
