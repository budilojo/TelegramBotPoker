# 004. Боты — обычные игроки: решают по своему `view`, ходят через тот же `handle`

- **Дата:** 2026-10-17 (коммит `f047280` «игры с ботами…»)
- **Кто решил:** агент по просьбе владельца («игрок против бота», разные уровни);
  способ реализации выбрал агент
- **Статус:** принято

## Что решили

Партия с ботами — одиночный стол (`room.solo`), без группы, без рейтинга. Бот
получает свой `view` — ровно то, что увидел бы человек на его месте, —
выбирает ход и отдаёт его в тот же `handle` с теми же проверками.

## Почему

Из `docs/bots.md`: честность «по устройству, а не по договорённости» — чужих
карт в виде бота нет, поэтому знать их он не может; ход проходит все проверки
человека.

## Где это в проекте

`bot/app.js` (`createSolo`, `botAct`, `botWaits`), `bot/games/<игра>/bot.js`,
`docs/bots.md`.
