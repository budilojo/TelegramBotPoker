# 118. Выдача и выбор — только после ответа сервера; один запрос в пути; повтор с тем же req

- **Дата:** 2026-10-27
- **Кто решил:** агент (исполнитель client) в рамках задания
- **Статус:** принято (до проверки владельцем)

## Что решили

Клиент не «предполагает» владение и выбор: пока нет ответа, остаётся прежний вид, кнопка занята («Ждём ответ сервера…»), второй запрос не уходит. Ответ-отказ оставляет прежнее и объясняет словами (текст сервера), повтор после явного отказа идёт с новым `req`. Если ответа нет 8 секунд или связь оборвалась — запрос помечается «потерянным», показывается «Повторить», и повтор идёт с **тем же** `req` (сервер по контракту не удвоит). Экран «Получено» показывается только после ответа сервера. Получение само выбор не меняет.

## Почему

Контракт, раздел 2 (идемпотентность `req`) и раздел 8 («выбор сохранён только после ответа сервера»).

## Где это в проекте

`miniapp/collections/state.js` (`createStore`), `index.js`; тесты — `bot/collections.client.test.js`.
