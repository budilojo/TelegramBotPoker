# 061. Сообщение прогресса: что принимается, личность и лишние поля

- **Дата:** 2026-10-25
- **Кто решил:** агент V (волна 3), в рамках задания владельца
- **Статус:** принято

## Что решили

Личность — только из `session.user`; поля id/uid/userId/user/from в теле молча игнорируются; любое другое неизвестное поле — отказ словами. Проверяются известные направление/тема/навык, уровень 1…5, оценка 0…1, `ms` до часа, до 8 кодов ошибок, формат id задания. Время в сообщении не принимается.

## Почему

Железное правило проекта «никто не ходит за другого»; страница — только показ.

## Где это в проекте

`bot/train.js` (`FIELDS`, `IDENTITY`, `TRAIN_ERRORS`), `MESSAGES.md` раздел 19.
