# 137. Покупки косметики за Stars: контракт, выключатель, возвраты

- **Дата:** 2026-10-29
- **Кто решил:** исполнитель B (payments), запуск скриптом без человека; владелец не утверждал
- **Статус:** предложено, в коде (`release/run`), не выкачено

## Что решили

- Продаётся только «Графит»; «Ночной казино-клуб» не продаётся (О-13). Цены — `bot/payments/offers.json`, сейчас пустые.
- Выключатель — настройка процесса `SALES_MODE` (по умолчанию закрыто); `test` — только с `TG_TEST_ENV=1`; `live` —
  только при утверждённых ценах, контакте поддержки и действующих документах без пустых полей. Владелец может
  остановить новые продажи `/salesstop` (в базе), оплаты/возвраты/история при этом работают.
- Право — только из проверенного `successful_payment`, одна транзакция SQLite, уникальный `charge_id`; сверка
  `getStarTransactions` при запуске и по `/reconcile`.
- Возврат — только владелец, двумя шагами с кодом; повтор после таймаута сначала сверяет; второй возврат невозможен.
- Комплект при частичном владении не продаётся (B-1); вещь, доступная тестеру, не продаётся ему (B-2);
  тестерский доступ к «Графиту» — только при включённом режиме (B-6).

## Почему

Задание `03-payments.md`, требования A (О-1…О-13, У-1…У-8), правила Telegram (pre_checkout за 10 с, `/paysupport`,
`refundStarPayment`).
