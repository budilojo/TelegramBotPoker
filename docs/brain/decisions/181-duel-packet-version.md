# 181. Дуэли: задержавшееся действие связано с партией и позицией

- **Дата:** 2026-10-31
- **Кто решил:** исполнитель J, в разрешённом объёме исправления воспроизведённых дефектов
- **Статус:** принято

## Что решили

Текущий клиент добавляет к запросу версию стола seq и номер партии matchNo,
если партия есть; явные версии исходного действия не перезаписывает. Хаб
четырёх дуэлей отказывает STALE на чужой номер партии, а для move/fire/roll/end/undo
также на устаревшую версию позиции. Перечень positionActions объявляют
модули, а не ядро. Отказ словами и новый собственный вид.
Связанные place→ready и два согласия next могут исходить из одной позиции.

## Почему

До правки четыре теста через хаб показали: после двух повторов старое действие
с прежним ply/turn/shot=0 выполняется в новой партии. Счётчики ходов обнуляются,
seq стола монотонна. Первая слишком широкая проверка seq сломала связанное
place→ready в настоящем браузере; отдельный тест воспроизвёл регрессию.
Разделение версий сохраняет это нажатие и не меняет правил игры.

Поля версий не являются авторизацией: личность по-прежнему из подписи. Старый
протокол без полей сохраняется; старые клиенты требуют переоткрытия Mini App
для новой защиты межпартийных задержек. Смешанные версии в Telegram не проверены.
