# 116. Стол «Графит»: слой-картинка, растянутый на овал

- **Дата:** 2026-10-27
- **Кто решил:** агент
- **Статус:** принято

## Что решили
Орнамент — один SVG с `preserveAspectRatio="none"` и `vector-effect: non-scaling-stroke`, кладётся слоем в овал (`.felt`, `.dk-cloth`) под сиденьями; центр свободен, в раскладку не входит. Повторяющийся фрагмент не используем.

## Почему
Овал `.felt` имеет любые пропорции (`layoutTable`), плитка дала бы шов и муар; растяжение сохраняет толщину линий. Раскладку не трогаем — слой можно просто убрать.

`miniapp/collections/art/README.md`, раздел «Стол».
