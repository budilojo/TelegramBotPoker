# 027. Бот морского боя решает только по своему виду и не читает комнату

- **Дата:** 2026-10-21
- **Кто решил:** агент D волны по заданию владельца (`docs/next-wave/agent-D-battleship.md`: «бот стреляет только по своему виду»)
- **Статус:** принято

## Что решили

`decide` бота морского боя берёт только `view` (то, что увидел бы человек на
его месте) и уровень из своей записи. Комнату, которую ядро тоже передаёт в
`decide` (там лежат оба флота), бот не трогает. Ядро (`bot/app.js`) не менялось.
Пять уровней: Юнга, Матрос, Боцман, Капитан, Адмирал (наугад → добивание →
шахматная сетка → карта вероятностей → она же с «корабли не касаются»).

## Почему

Правило проекта «Никто не видит чужого» (AGENTS.md, правило 2) и решение 010
(тайна флота). Бот, подглядывающий в чужой флот, — нечестный соперник.

## Где это в проекте

`bot/games/battleship/bot.js`; тесты `bot/battleship.bot.test.js` (ловушка
вместо комнаты, перехват каждого вида, «один вид — один выстрел» при разных
флотах); «на зубы» — три поломки в `tools/battleship-teeth.mjs`; замеры уровней
— `docs/battleship.md`. Коммит `bc0379f`.
