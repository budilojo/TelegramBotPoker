# 101. Вид косметики живёт только на этом телефоне

- **Дата:** 2026-10-27
- **Кто решил:** агент M в рамках задания владельца
- **Статус:** принято

`miniapp/cosmetics/look.js`: вид (рубашка, сукно, рамка, эффект, звание, до трёх реакций набора) хранится в `localStorage`
(с try/catch, без него живёт до перезагрузки), принимает только вещи каталога и только в свою ячейку. На сервер не уходит,
другим игрокам не показывается. Реакция набора в примерке — пузырь «примерка» только у вас: серверный список реакций не менялся,
в сокет она не отправляется. Проверено: по сокету ни у Ивана, ни у соседей нет строк с `nc-` (`tools/e2e-look.mjs`).
