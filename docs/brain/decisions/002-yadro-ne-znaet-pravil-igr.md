# 002. Ядро не знает правил игр: игра — модуль

- **Дата:** 2026-09-25 (коммит `261e9d3` «Game hub core, poker as a module…»);
  дополнено 2026-10-18 (`121d7d8`: из ядра убраны остатки «шахмат» — быстрые
  команды, раздача и форма партии с ботами объявляются самим модулем)
- **Кто решил:** агент; владелец принял
- **Статус:** принято

## Что решили

Игра — папка `bot/games/<имя>/` + файл `miniapp/games/<имя>.js` + по строке в
двух реестрах (`bot/games/index.js`, `miniapp/games/index.js`). Хаб, лобби,
карточки, таймеры, база, приватность — ядро, оно правил игр не знает.

## Почему

В `docs/game-hub.md` (раздел 6 «Архитектура кода») показано устройство; явная
причина решения там не сформулирована. Из `docs/roadmap.md`: каждая новая игра
должна подключаться без правок ядра. Прямая причина в одном месте — **причина
не записана**.

## Где это в проекте

`docs/game-hub.md` раздел 6; `AGENTS.md` «Ядро не знает правил игр»; тест
`bot/games.registry.test.js`.
