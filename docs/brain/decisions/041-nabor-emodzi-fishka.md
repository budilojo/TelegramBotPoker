# 041. Набор эмодзи «Фишка»: из папки владельца, 128 px, PNG-8, манифест

- **Дата:** 2026-10-23
- **Кто решил:** агент R (по заданию владельца, пункт 3)
- **Статус:** принято

## Что решили

В приложение идут 16 смайликов из папки владельца «эмодзи фишки» (исходник 1254 px,
~750 КБ каждый) в виде `miniapp/emoji/<набор>/<id>.png`: обрезка по контуру, 128×128 с
полями 8 px, палитра 48 цветов, 3–5 КБ (набор — 56 КБ). Описание — `manifest.json`
(контракт с агентом Q). Наборы: «Реакции» (`universal`, 14 шт., 5 быстрых: `gg`, `haha`,
`wow`, `sad`, `think`) и «Покер» (`poker`: `allin`, `bluff`). Картинки не правились и не
перекрашивались.

## Почему

Исходники слишком тяжёлые для телефона. Сжатие — собственным скриптом без новых
зависимостей (ни `sharp`, ни `pngquant`), воспроизводимо: `tools/build-emoji.mjs` +
`tools/emoji-map.json`. «Быстрые» — самые частые в игре: итоги партии (gg), эмоции
(haha, wow, sad) и «думаю».

## Где это в проекте

`tools/build-emoji.mjs`, `tools/emoji-map.json`, `miniapp/emoji/`, `bot/emoji.manifest.test.js`,
`docs/emoji.md`.
