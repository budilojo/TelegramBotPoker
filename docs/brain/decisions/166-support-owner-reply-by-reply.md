# 166. Поддержка: ответ владельца — reply на сообщение бота, номер берётся из его первой строки

- **Дата:** 2026-10-30
- **Кто решил:** исполнитель G (support), запуск скриптом; владелец просил поддержку через бота словами, детали выбрали мы
- **Статус:** в коде (`release2/run`), не выкачено

## Что решили
Обращение приходит владельцу сообщением «📩 Обращение №N · id …». Ответ — reply на него (номер читается из первой строки сообщения самого бота, `from.is_bot`) или `/reply № текст`. Права — по `ADMINS` и `from.id` самого сообщения, трижды (админ-бот, основной бот, `ownerInput`). Один и тот же ответ (чат + message_id) помечается в `support_reply` и второй раз игроку не уходит. Игроку ответ идёт всегда через основного бота (админ-бот игрокам писать не может: у него нет Start).

## Почему
Текст игрока идёт после заголовка и не может подделать первую строку; повторная доставка апдейта и перезапуск не удваивают ответ.

## Где
`bot/support.js` (`ownerInput`, `answer`, `claimReply`), `bot/admin-bot.js`, `bot/app.js`.
