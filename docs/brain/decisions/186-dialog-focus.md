# 186. Фокус общих диалогов

31.10.2026, K. Принято и реализовано локально.

Общие шторки и коллекции — именованные dialog с aria-modal. Верхний слой
ограничивает Tab/Shift+Tab, Escape закрывает; фон inert. Шторка имеет кнопку
«Закрыть окно», возвращает фокус. При перерисовке шторки сохраняются поля и
кнопки, у коллекций — фокус после ответа сервера. Числовые поля покера и
ползунок именованы. Новых токенов/исключений оформления нет.
До изменения тесты не находили dialog/имя поля, ответ справки терял фокус.
После — положительные сценарии и временные поломки; uxtext/ux-matrix.
VoiceOver/TalkBack на устройствах не проверены, полный WCAG не заявляется.
