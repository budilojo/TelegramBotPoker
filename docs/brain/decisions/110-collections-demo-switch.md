# Демосреда коллекций включается только серверной настройкой

- **Дата:** 2026-10-27
- **Кто решил:** агент (server, пакет «Графит»); по контракту, без утверждения владельцем
- **Статус:** принято

## Что решили

Демо-получение предметов «Графита» работает только если процесс запущен с COLLECTIONS_DEMO ровно `1`; значение читается один раз в bot/index.js и передаётся в App опцией collectionsDemo (по умолчанию false). Сообщение страницы, права администратора и cosmeticsUnlocked демосреду не включают; демо-строки базы без неё игнорируются.

## Почему

Так записано в контракте (раздел 3): рабочий сервер не должен раздавать предметы без оплаты, а база могла быть скопирована из демосреды. Строгое сравнение с `1` исключает случайное включение значениями true/yes/пробелами.

## Где это в проекте

bot/index.js, bot/app.js, bot/collections/index.js (ownedItems, handle), .env.example; тесты bot/collections.test.js, проверка на зубы tools/graphit-server-teeth.mjs.
