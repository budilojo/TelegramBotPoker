# 026. Картинки смайликов подменяются файлами; выключатель — на телефоне

- **Дата:** 2026-10-21
- **Кто решил:** владелец (задание агента C), исполнил агент C
- **Статус:** принято

## Что решили

Картинка смайлика — `miniapp/emoji/<id>.png`. Пока файла нет, рисуется
запасной юникод-эмодзи из таблицы в `miniapp/reactions.js`; чтобы подключить
нарисованные «Фишки», достаточно положить 16 файлов (код не меняется; сервер
читает список файлов при старте — нужен перезапуск бота). Отсутствующую
картинку браузер запрашивает один раз за загрузку страницы (в консоли — 404).
«Не показывать смайлики» — пункт меню стола, хранится в `localStorage` этого
телефона: у выключившего нет ни кнопки, ни пузырей; другие его смайлики не
теряют.

## Почему

Задание: картинки генерирует владелец, подключает агент E во второй волне.
Выключатель — дело одного телефона, сервер о нём знать не должен.

## Где это в проекте

`face`, `reactMenuItem`, `reactionsOff` — `miniapp/reactions.js`; кнопка и пункт
меню — по строке в каждом `miniapp/games/*.js`.
