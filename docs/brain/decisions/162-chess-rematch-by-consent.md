# 162. Шахматы: «Ещё раз» — по согласию двоих людей

- **Дата:** 2026-10-30
- **Кто решил:** исполнитель F (chess); владелец просил «предлагало сыграть ещё раз»
- **Статус:** в коде, не выкачено

## Что решили
Первый нажавший «Ещё раз» только предлагает (`match.rematch`), второму приходит «Соперник зовёт ещё раз» и «Принять»; партия стартует, когда принял второй. Раньше любой из двоих мог начать новую партию один, без согласия. В партии с ботом — сразу, бот согласен.
## Почему
Предложение должно «приходить второму»; односторонний старт мог навязать партию тому, кто ещё смотрит доску.
## Где
`rules.js` (`askRematch`), `index.js` (`next`), `view.js` (`match.rematch`), `miniapp/games/chess.js`.
