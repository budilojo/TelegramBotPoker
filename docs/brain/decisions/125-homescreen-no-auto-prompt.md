# 125. Иконка на рабочий стол: только по кнопке, успех только по подтверждению Telegram

- **Дата:** 2026-10-27
- **Кто решил:** агент (с согласия владельца — по заданию пакета «Графит»)
- **Статус:** принято

## Что решили

Иконку предлагает только строка в «Настройках» по нажатию; автоподсказки нет. «Добавлено» — только по событию `homeScreenAdded` или ответу `added` повторной проверки статуса; по таймауту Telegram переспрашивается.

## Почему

Задание пакета и контракт, раздел 10: никакой навязчивости и никакого домысливания успеха. Событие отказа в официальной документации не найдено, а `homeScreenAdded` может не прийти — поэтому нужен таймаут и повторная проверка.

## Где это в проекте

`miniapp/homescreen.js`, `miniapp/homescreen-row.js`, `docs/homescreen.md` (там же предложение правила автоподсказки — не утверждено).
