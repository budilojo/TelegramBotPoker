## Что решили

Пять новых таблиц (`train_skill`, `train_result`, `train_topic`, `train_mistake`, `train_pass`) через `CREATE TABLE IF NOT EXISTS`; `meta.schema` остаётся 5. Прогресс получает только сам игрок (ответ на `get`/`result`), в вид стола, чат, рейтинг, карточку группы не идёт. «Сбросить мой прогресс» стирает только его строки. Админке — только число людей (`trainPeople`), без имён и пока не выведено.

## Почему

Как с `profiles` (решение 003): откат релиза безопасен. Проверено: код `7afb285` открывает базу с этими таблицами без ошибок, схема 5.
