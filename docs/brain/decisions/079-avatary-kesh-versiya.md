# 079. PNG-аватарки подключены с версией в ссылке (AVATAR_VER)

- **Дата:** 2026-10-26
- **Кто решил:** агент Z
- **Статус:** принято

## Что решили

`AVATAR_PNG = true`; ссылка `/avatars/<id>.png?v=AVATAR_VER`; заменили картинки — поднять число. SVG остаются запасом при ошибке загрузки.

## Почему

Сервер отдаёт картинки с `max-age=86400` под неизменным именем — без версии замена дошла бы до телефонов не раньше суток.

## Где это в проекте

`miniapp/ui.js`, `docs/profile.md`, `tools/e2e-profile.mjs` (любой 404 — провал).
