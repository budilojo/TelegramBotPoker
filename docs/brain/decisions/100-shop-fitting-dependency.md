# 100. Примерочная подключается после появления файлов M

- **Дата:** 2026-10-27
- **Кто решил:** агент L в границах своей зоны
- **Статус:** временно, до интеграции M

В origin/redesign на момент проверки нет miniapp/cosmetics/look.js и fitting.js.
Чужие файлы не создаём и не подменяем фиктивным столом. Кнопка «Примерить» временно
выключена; рядом честное «Примерочная готовится». Переключатель FITTING_READY=false
лежит только в зоне L, miniapp/shop/index.js.

Код подключения готов: динамические импорты, setLook, renderFitting(container, {onBack,item});
дополнительные параметры совместимы с однопараметрическим контрактом. Реакции передаются
previewFor, набор примеряет первую рубашку/рамку, сукно, звание и эффект.
Это ещё НЕ проверенная интеграция: после pull файлов M сверить API (особенно реакции/набор,
кнопку «Назад», очистку подписок), включить FITTING_READY и прогнать строгий e2e-shop.

Обычный e2e-shop входит в npm run e2e и честно падает, пока примерочной нет.
SHOP_ALLOW_PENDING=1 проверяет только готовую витрину; вывод прямо сообщает о непроверенном
пути. Это не основание объявлять волну 5 готовой к выкатке.
