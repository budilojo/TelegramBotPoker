`miniapp/cosmetics/art.js`: `REAL_ART = false` — берутся плоские TEMP-заглушки из `placeholder/`, настоящие PNG не запрашиваются
(нет 404). Команда «подключить косметику» кладёт файлы в `miniapp/cosmetics/night-casino/` и ставит `true`. Рамка-заглушка рисует кольцо
в 65 % картинки, поэтому для неё свой размер (`.cos-frame[src*='/placeholder/']`); у настоящей рамки (кольцо на весь холст 512×512) — `inset:-12%`;
если настоящий холст окажется другим — подправить только эти два числа. Текстура сукна подключается только с настоящим файлом.
