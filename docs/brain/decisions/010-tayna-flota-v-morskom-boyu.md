# 010. Морской бой: расстановка флота — тайна до конца партии, выстрел в два шага

- **Дата:** 2026-10-19 (план `docs/plan-battleship.md`; сервер — `612e9a5`;
  экран — `86ae225`, 2026-10-20)
- **Кто решил:** агент по просьбе владельца («добавить морской бой»); правила
  и состав флота — без владельца
- **Статус:** принято

## Что решили

Сервер хранит обе расстановки; страницам до конца партии уходит только свой
вид: свой флот, попадания по себе, результаты своих выстрелов (убитый корабль —
целиком). Выстрел на телефоне — в два шага: выбрать клетку, нажать «Огонь».
Поле 10×10, классический флот, попал — стреляешь ещё.

## Почему

Правило проекта «Никто не видит чужого» (`AGENTS.md`, правило 2). Два шага —
из плана: на ширине 320 px клетка ≈ 28 px, меньше зоны нажатия 44 px.
