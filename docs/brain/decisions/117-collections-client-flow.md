# 117. Коллекции в клиенте: слой поверх страницы, вход только из «Настроек» и только в демо

- **Дата:** 2026-10-27
- **Кто решил:** агент (исполнитель client) в рамках задания; владелец не утверждал отдельно
- **Статус:** принято (до проверки владельцем)

## Что решили

Экраны коллекций (витрина → карточка → примерка → получение → инвентарь) живут в одном слое `.col-root` поверх страницы, а не в маршруте. Открыть слой можно только строкой «Коллекции» в «Настройках», а строка есть только когда сервер прислал `enabled && demo`. Адреса, хэша и `localStorage` как путей входа нет; если сервер потом перестал присылать демо — слой закрывается, строка исчезает.

## Почему

Задание и контракт (разделы 3 и 8): вне демо точки входа нет, прямой маршрут ничего не открывает, демо решает только сервер. Слой с одним прокручиваемым узлом, который не пересоздаётся, не даёт «прыжков» (`docs/scroll.md`).

## Где это в проекте

`miniapp/collections/index.js`, `state.js` (`visible`), `settings-row.js`; проверки — `bot/collections.client.test.js`, `tools/e2e-collections.mjs`, `tools/graphit-client-teeth.mjs`.
