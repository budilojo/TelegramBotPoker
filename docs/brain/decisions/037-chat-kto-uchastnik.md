# 037. Кто участник чата

- **Дата:** 2026-10-23
- **Кто решил:** агент Q (по рекомендации промта)
- **Статус:** принято

## Что решили

Читают и пишут **сидящие за столом игроки** (в лобби — тоже, раз сели). Зритель, не
севший, вставший из-за стола (`seated: false`), ушедший и удалённый хостом — **ничего
не получают и получают отказ словами**. Автора определяет сервер по подписи страницы;
имя, место и id из тела сообщения игнорируются. **В партии с ботами чата нет** —
кнопка и пункт меню скрыты, сервер отвечает «В партии с ботами чата нет — говорить не
с кем».

## Почему

Чат для людей одного стола; зритель видит стол, но не разговор (иначе «никто не видит
чужого»). Проверка — та же `reactSeat`, что у реакций, — одна на оба входа.

## Где это в проекте

`bot/chat.js` (`chatSeat`, `chat`, `deliver`), `bot/chat.test.js` (зритель, чужой стол,
ушедший, удалённый, вставший, партия с ботами, подмена автора).
