# 043. Нижняя навигация: Игры · Рейтинг · Настройки, только на экранах хаба

- **Дата:** 2026-10-23
- **Кто решил:** агент S (по заданию владельца, п. 5)
- **Статус:** принято

## Что решили

Панель из трёх вкладок внизу (56 px + безопасная зона) стоит на «моих группах»,
хабе группы, «Играх с ботами» и таблице рейтинга. За столом (лобби, партия,
итоги), в пульте, под шторкой и при открытой клавиатуре её нет. «Игры» — тот экран,
который сервер уже показывает; «Рейтинг» и «Настройки» — экраны самой страницы
поверх него (сервер о них не знает), при смене «места» они закрываются.
Состав из трёх вкладок оставлен: структура приложения больше ничего не просит.

## Почему

Доска и кнопки действий не должны терять место; серверные состояния не плодим ради
вкладок. Клавиатура в заглушке не воспроизводится — прячем по сжатию `visualViewport`
и по фокусу в поле ввода.

## Где это в проекте

`miniapp/nav.js`, `miniapp/nav.css`, `miniapp/app.js` (подключение), `tools/e2e-nav.mjs`.
