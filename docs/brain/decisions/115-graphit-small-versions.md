# 115. Упрощённые версии для малых размеров

- **Дата:** 2026-10-27
- **Кто решил:** агент
- **Статус:** принято

## Что решили
Для игры — `cardback-small` и `frame-small`: толщины линий в 3–5 раз больше (5–8 вместо 1,5–3 в единицах viewBox), решётка реже, второстепенные линии убраны. Подробные версии — только для магазина.

## Почему
При ширине закрытой карты 18–60 px линия 1,5 из 200 даёт 0,14–0,45 px и пропадает или мерцает (муар). На контрольных листах малая версия читается с 24 px (ромб) и 32 px (решётка).

## Где это в проекте
`miniapp/collections/art/README.md` (какую версию брать), `tools/build-graphit-art.mjs` (`cardback`, `frame`).
