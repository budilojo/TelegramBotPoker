# 036. Чат и реакции — один вход внизу экрана

- **Дата:** 2026-10-23
- **Кто решил:** агент Q (по заданию владельца «один интерфейс, не два»; детали выбрал агент)
- **Статус:** принято

## Что решили

Кнопка смайликов в шапке стола убрана. Вместо неё — **одна круглая кнопка чата** внизу
экрана игры (с бейджем непрочитанных). Она открывает нижнюю панель: история, **быстрый
ряд реакций** (до пяти с пометкой `quick` из набора R + «ещё»), «ещё» раскрывает
**категории** (Реакции · Покер) сеткой 4×N, ниже — поле ввода. Тап по реакции отправляет
её: пузырь над аватаром остаётся как раньше (лимит 3 с / 6 в минуту, «подождите N с»), а
в историю чата она ложится **маленькой строкой** («Иван: 😂») и считается
непрочитанной для остальных.

## Почему

Задание владельца: вход в чат и реакции один, кнопка в шапке исчезает. Рекомендация
из промта (быстрый ряд + категории) принята как есть: не одна длинная лента на 16–30
значков. Пункт меню «Не показывать смайлики» заменён одним **«Не показывать чат и
реакции»** (ключ `localStorage` прежний — `reactions-off`: выбор людей сохраняется).
