# Оформление комнаты — снимок раздачи

- **Дата:** 2026-10-27
- **Кто решил:** агент (server, пакет «Графит»); по контракту, без утверждения владельцем
- **Статус:** принято

## Что решили

room.look собирается заново в лобби при каждой отправке вида, в начале раздачи (afterDeal, после успешной сдачи покера/дурака) замораживается и пересобирается только со следующей. Стол — выбор хоста на момент снимка, рубашки — каждого сидящего (покер), рамки — каждого. Предмет без права или не для этой игры в снимок не попадает (база). Игры с ботами считаются так же.

## Почему

Контракт, раздел 5: смена выбора посреди раздачи не должна менять стол и рубашки у других; хост и переподключения снимок не пересобирают. Старые комнаты без look читаются как база (look отсутствует → пересборка при первой отправке).

## Где это в проекте

bot/collections/index.js (build, freeze, settle), bot/app.js (draw, afterDeal), bot/collections/look.js, bot/view.js, bot/games/durak/view.js.
