# 098. Спрос: уникальные люди, закреплённая цена и удаление своих данных

- **Дата:** 2026-10-27
- **Кто решил:** агент L в рамках задания владельца
- **Статус:** принято

Вариант цены — по последней цифре Telegram id: чётная A, нечётная B. Его возвращает сервер;
другой вариант в запросе отклоняется. Личность только из подписанной сессии.
Одна строка на человека и вещь: просмотр и необязательное «Хочу». Повторы не увеличивают
счётчики, «Хочу» подразумевает просмотр. Это доля людей, а не доля кликов.
30 запросов в скользящую минуту на человека (все вкладки, чтение и сброс включены), по
часам приложения; лимит в памяти, перезапуск его обнуляет. Сброс требует confirm:true,
удаляет только свои строки, включая просмотры. Цена и лимит от сброса не меняются.
Пульт показывает только суммы по вещи/варианту, без id и имён; данные за весь срок с запуска
эксперимента, с учётом удалений. При малой аудитории проценты — лишь подсказка (§4 monetization).
Таблица shop_interest создаётся повторно без подъёма схемы 5.

Код: `bot/shop.js`, `bot/store.js`, блок `shop` в `bot/hub.js`.
