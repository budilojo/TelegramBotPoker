# 042. Эмодзи: специфических наборов для игр пока нет

- **Дата:** 2026-10-23
- **Кто решил:** агент R
- **Статус:** принято (до новых картинок)

## Что решили

Наборы только `universal` (для всех игр) и `poker` (две картинки). Для шахмат, шашек,
нард, морского боя, дурака и UNOQ в папке владельца картинок нет, и придумывать их
нельзя: эти игры пользуются «Реакциями». `fire` («В ударе») оставлен универсальным, а не
покерным: он не про покер. `cheers` («Ура!») — универсальный.

## Почему

Задание: «только те, для которых реально есть картинки». Сомнительные случаи (`fire`,
`allin` как универсальное «иду ва-банк») названы в отчёте владельцу.

## Где это в проекте

`tools/emoji-map.json` (достаточно перенести строку между наборами и пересобрать).
