# 099. Магазин — отдельный экран с карточками и возвратом

- **Дата:** 2026-10-27
- **Кто решил:** агент L в рамках задания владельца
- **Статус:** принято

Вход из «Настроек» после профиля и из самого профиля («Посмотреть косметику»).
Витрина и карточка — полные экраны, без нижней навигации. На 320 px две колонки;
звание рисуется текстом, набор перечисляет все десять вещей.
Скроллеры витрины и карточки живут до закрытия; серверные ответы меняют только текст
и состояние кнопок. Системная «Назад» Telegram возвращает к карточке/витрине/настройкам.
Удаление — шторка с подтверждением через общий showSheet.
Админский отчёт — карточки с двумя строками A/B: широкая таблица не нужна на телефоне.

Сейчас все изображения — явно обозначенные эскизы. Реальные PNG не запрашиваются,
поэтому отсутствующие картинки не создают 404. Подключение настоящего арта — отдельная
задача после файлов владельца, с проверкой веса.
Код: miniapp/shop/index.js, shop.css; точечные входы/маршрутизация в nav/profile/app/net.
