# 063. Матрица 13×13 на 320 px: клетка ≈ 20 px, нажатие 44 px — обходными путями

- **Дата:** 2026-10-25
- **Кто решил:** агент W (волна 3), без отдельного согласия владельца — выбор сделан самим и назван в отчёте
- **Статус:** принято

## Что решили

Клетка на 320 px — около 20 px, это не скрыто. Даны способы: режим «Крупно» (клетка ровно 44 px, прокрутка внутри матрицы, буквы рядов и столбцов закреплены), лупа над пальцем при рисовании, нажатие по букве ряда/столбца, готовые наборы, поле ввода строкой, отмена до 50 шагов. По умолчанию касание только нажимает и страница прокручивается (touch-action: pan-y); протяжка включается кнопкой «Рисовать» (touch-action: none только внутри матрицы). Мышь рисует всегда. В обычном виде в клетке «AK» без s/o (масть читается по положению и оттенку), в «Крупно» — «AKs». Автоматических проверок на 44 px для матрицы нет (kit-check смотрит только kit.html), поэтому исключение записано здесь; стиль лежит в miniapp/ranges.css, чтобы kit и contrast проверяли его по исходнику.

## Почему

Тест сетки 22 px × 13 нельзя довести до 44 px; молча нарушить правило нельзя (контракт 7 плана волны 3).

## Где это в проекте

miniapp/ranges.css, miniapp/train/widgets/range-grid.js, tools/e2e-ranges.mjs (проверяет 44 px в «Крупно»). Не проверено на телефоне: точность пальца, лупа, жесты Telegram.
