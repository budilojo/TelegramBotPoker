# 078. Сборка аватарок — своим скриптом, палитровый PNG

- **Дата:** 2026-10-26
- **Кто решил:** агент Z
- **Статус:** принято

## Что решили

`tools/build-avatars.mjs` + `tools/avatar-map.json`: чтение PNG, уменьшение до 128×128 усреднением по площади, медианное сечение до ≤256 цветов, свой кодировщик PNG; результат 12–14 КБ, повторный запуск даёт те же байты. Исходники в git не кладём.

## Почему

Обычный RGB 128×128 весит 28–34 КБ (> 20 КБ); на машине нет convert/pngquant, `pngjs` не объявлен в зависимостях. Картинки не правятся по содержанию.

## Где это в проекте

`tools/build-avatars.mjs`, `tools/avatar-map.json`, `miniapp/avatars/*.png`.
