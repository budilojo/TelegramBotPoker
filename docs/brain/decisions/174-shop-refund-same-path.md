# 174. Возврат из админки — те же функции и та же карта кодов, что /refund

- **Дата:** 2026-10-30
- **Кто решил:** исполнитель H (adminshop) по заданию («никаких новых путей к деньгам»)
- **Статус:** в коде (`release2/run`), не выкачено

## Что решили
Шаг 1 вынесен в `refundPrepare` (общий для `/refund` и админки), шаг 2 — прежний `refundConfirm`. Код, выданный на странице, принимает и команда `/refund <заказ> <код>`. Неудачный возврат страница показывает отказом, не «готово». Остановка продаж — общий `setStopped` с `/salesstop`.

## Почему
Один путь к звёздам — одна проверка и одни тесты «на зубы».

## Где это в проекте
`bot/payments/index.js`, `bot/payments/admin.js`.
