# 071. Журнал решений: только вперёд, только своё, 300 последних

- **Дата:** 2026-10-25
- **Кто решил:** агент Y (по заданию владельца «качество решений, не победы»)
- **Статус:** принято

## Что решили

В базе нет ни раздач, ни решений, поэтому «по истории игр» считать не из чего. Заводим таблицу `decision_log`
(без смены версии схемы): на каждое решение самого человека — его карты, открытый борд, банк, ставки, стек, позиция,
число соперников, действие, шанс выиграть. Чужих карт и исхода раздачи нет. Пишем и за столом с друзьями, и в партиях
с ботами (поле `kind`); бот за себя, школа и стол с настоящими картами — не пишутся. Хранятся последние 300 на игрока;
игрок может удалить всё («Удалить историю решений» и «Сбросить мой прогресс»).

## Почему

Рекомендация задания: решения с друзьями — это и есть «история игр». Срок хранения по времени не вводили: хватает предела по
числу (причина не записана, выбор агента — **предположение**, что 300 достаточно для оценки).
