# 227. Автоскан вёрстки: сцены preview, правила отдельно, красный честно (27.11.2026, шаг T)

- `npm run ui:scan` берёт сцены `tools/preview.mjs` через крючок `PREVIEW_HOOK` (без второго набора сцен) и добавляет свои
  в `tools/lib/ui-scan-hook.mjs`. Замеры (в странице) и разбор (чистая функция) — `tools/lib/ui-scan-rules.mjs`.
- Что не считается дефектом — только списком `ALLOW` с причиной у каждой строки.
- Команда выходит с кодом 1, пока есть находки серьёзнее косметики. Эталона «известных дефектов» нет: чинит шаг X,
  прятать нынешние находки под эталон не стали.
- В `npm test` — только разбор на выдуманных замерах (`tools/ui-scan.test.js`); браузерный обход и «на зубы»
  (`--teeth`) — отдельно, как `layout`.
