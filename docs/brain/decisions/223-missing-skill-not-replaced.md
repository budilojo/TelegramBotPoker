- **Дата:** 2026-11-27
- **Кто решил:** агент (исполнитель S пятого пакета)
- **Статус:** принято

## Что решили

Файла `.claude/skills/ux-ui-audit/SKILL.md` в git нет. Свой текст под этим именем не писать, тест не ослаблять;
в `.gitignore` добавить исключение `!.claude/skills/`. Оригинал должен вернуть владелец или подготовившая сессия.

## Почему

`.gitignore` (`.claude/*`) не пустил файл в коммит `ac9e9f4`. Тест пятого пакета в `tools/release-run.test.js`
проверяет наличие скилла и краснеет по делу; самодельная замена спрятала бы это.

## Где это в проекте

`.gitignore`, `tools/release-run.test.js`, `docs/next-release-5/reports/uxsim.md`.
