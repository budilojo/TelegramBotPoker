# 001. База — SQLite через встроенный `node:sqlite`, стол целиком одним JSON

- **Дата:** 2026-09-25 (коммит `44df7ad`, в нём файл `bot/store.js` появился впервые)
- **Кто решил:** причина записана в коде; кто именно решил — не записано
- **Статус:** принято

## Что решили

Хранить столы в SQLite; каждый стол — одна строка с JSON целиком; драйвер —
встроенный в Node `node:sqlite`, без внешних зависимостей.

## Почему

Из заголовка `bot/store.js`: бот живёт неделями, а не один вечер, и
перезапуск посреди раздачи не должен стирать стол; запись в SQLite атомарна и
синхронна — после сбоя нет состояния «файл записан наполовину»; `node:sqlite`
встроен в Node, значит ноль зависимостей. Стол — несколько килобайт и всегда
читается и пишется целиком, поэтому разбивать по таблицам смысла нет.

## Где это в проекте

`bot/store.js`; требование Node ≥ 22.5 — `package.json`.
