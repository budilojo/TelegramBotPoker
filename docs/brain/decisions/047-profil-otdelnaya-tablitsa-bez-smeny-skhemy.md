# 047. Профиль хранится в отдельной таблице `profiles`, версия схемы не меняется

- **Дата:** 2026-10-24
- **Кто решил:** агент T (по заданию владельца, пункт 6 волны 2)
- **Статус:** принято

## Что решили

Ник и аватар лежат в новой таблице `profiles` (`CREATE TABLE IF NOT EXISTS`). `meta.schema` остаётся `5`.

## Почему

Откат релиза: старый код открывает базу с лишней таблицей и её не замечает (проверено вручную: `bot/store.js` с сервера, коммит `7afb285`, открыл базу, созданную новым кодом; версия 5, таблицы на месте). Поднятие версии потребовало бы миграции и сделало бы откат опасным. Правило из решения 003.

## Где это в проекте

`bot/store.js` — `SCHEMA` (таблица), `getProfile`/`putProfile` (Store и NullStore); `bot/profile.test.js` — «таблица profiles…», «профиль переживает перезапуск»; `docs/profile.md`.
