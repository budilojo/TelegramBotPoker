# 023. Смайлики — закрытый набор из 16 реакций

- **Дата:** 2026-10-21
- **Кто решил:** владелец (задание `docs/next-wave/agent-C-reactions.md`), исполнил агент C
- **Статус:** принято

## Что решили

Во время игры можно слать только смайлик из фиксированного списка: `gg`, `wow`,
`haha`, `sad`, `think`, `fire`, `bluff`, `allin`, `thanks`, `sorry`, `hello`,
`angry`, `facepalm`, `cool`, `wait`, `cheers`. Страница присылает только id;
ни свободного текста, ни картинок от игроков. Смайлики шлют только сидящие за
столом (зритель, ушедший, удалённый — отказ словами); в игре с ботами — только
владелец партии.

## Почему

Задание владельца: «быстрые реакции», без чата. Закрытый набор нечем
злоупотребить (нет текста — нечего модерировать) и он не раскрывает ничего
тайного: в сообщении только место, id и время.
