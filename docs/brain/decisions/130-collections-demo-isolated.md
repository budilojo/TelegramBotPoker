# 130. Демонстрация коллекции изолирована от рабочего режима

- **Дата:** 2026-10-27
- **Кто решил:** агент (lead-integration, пакет «Графит»); по плану пакета, без утверждения владельцем
- **Статус:** принято

## Что решили

Всё, что даёт предметы «Графита» без оплаты, живёт только за переключателем `COLLECTIONS_DEMO=1` (решение 110). Выключено по умолчанию; в рабочем режиме нет входа в «Коллекции», `grant` отклонён, вкладка «Магазин» осталась «скоро» со счётчиком (решение 106). Платёжных вызовов в коде нет.

## Почему

Рабочий сервер не должен раздавать предметы бесплатно; цены, комплекты и оплата владельцем не утверждены.
