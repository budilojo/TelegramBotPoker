# 102. Примерочная — отдельная лёгкая раскладка, а не renderTable()

- **Дата:** 2026-10-27
- **Кто решил:** агент M в рамках задания владельца
- **Статус:** принято

`renderTable()` целиком живёт на состоянии сервера (`state`, `prev`, `dealOrder`, анимации раздачи, живой `#app`). Тащить в него
выдуманное состояние ради картинки значило бы гонять игровой код и рисковать столом. `miniapp/cosmetics/fitting.js` берёт те же
классы и те же функции вида (`backImg`, `frameOn`, `titleEl`, `winFx`), данные выдуманные, сервера нет. Обновление вида правит три
блока на месте (`replaceChildren`), прокрутка не прыгает (`assertNoJump`). Цена: раскладка стола в примерочной не совпадает пиксель в пиксель с живой.
