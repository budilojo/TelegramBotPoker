# 105. Вещи открыты администраторам и тестерам; «Надеть» вместо «Хочу»

- **Дата:** 2026-10-27
- **Кто решил:** владелец (задание), реализация агент L
- **Статус:** принято

Кто открыт — решает сервер: `app.cosmeticsUnlocked(id)` = администратор (`ADMINS`) или id из `COSMETICS_TESTERS`
(по умолчанию пусто). Ответ `{t:'shop', …, unlocked}` строится по подписанной сессии; `unlocked`, `admin`, `user_id`
в теле сообщения ничего не значат (тест + поломка защиты ловится). У открытых вместо цены «Открыто для вас», вместо «Хочу» —
«Надеть»/«Снять» (`look.setLook`, вид хранится на телефоне, применяется M в покере и дураке, включая игры с ботами).
Их просмотры и «Хочу» **не пишутся** в счётчики: владелец не искажает собственный замер спроса. Остальные игроки — как раньше.
Это не покупка и не оплата; платежей нет. Права по-настоящему «выдаются» только на этом телефоне и только как вид.
