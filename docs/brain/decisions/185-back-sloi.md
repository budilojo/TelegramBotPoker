# 185. Back закрывает верхний экран

31.10.2026, K. Принято и реализовано локально.

Telegram Back: шторка → шаг коллекций → экран тренировки с его подтверждением
ответа → локальная вкладка → хаб. Кнопка синхронизируется и без нового состояния
сервера. Локальный переход не отправляет hub и не меняет место/часы/банк.
Основание: e2e-uxtext до правки не видел Back в настройках; после проверяет
ступени и несохранённый ответ. Поломки показателя/обработчиков ловятся тестами.
Живой Telegram и устройства не проверены; отчёт uxtext, ux-matrix.
