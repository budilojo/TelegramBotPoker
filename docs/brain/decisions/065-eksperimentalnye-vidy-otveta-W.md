# 065. Виды ответа в упражнениях W

- **Дата:** 2026-10-25
- **Кто решил:** агент W (волна 3), без отдельного согласия владельца — выбор сделан самим и назван в отчёте
- **Статус:** принято

## Что решили

range — массив кодов рук (на ур. 5 — объект { рука: частота }); slider — число; table — { action, to }; pick — id. Режим flag («найди ошибку») — решение в разборе: массив неверных клеток. Виджет range-grid.js принимает value/onChange/disabled/result по контракту V. Подключения видов range/slider/table в экране Тренировки — на стороне V/X.

## Почему

Контракт V (docs/poker-training.md §3) оставляет вид ответа за упражнением.
