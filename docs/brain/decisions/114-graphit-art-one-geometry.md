# 114. Графика «Графита»: одна геометрия, цвет только ролями

- **Дата:** 2026-10-27
- **Кто решил:** агент (с согласия владельца: SPEC требует одинаковую геометрию в четырёх цветах)
- **Статус:** принято

## Что решили
Каждый вид нарисован один раз списком фигур с ролями `bg`/`ink`; палитра подставляется при записи. SVG пишет только `tools/build-graphit-art.mjs`, руками файлы не правятся.

## Почему
SPEC: «одна геометрия, одинаковые толщины, меняются только цвета». Так различие цветов в структуре невозможно, а тест сравнивает файлы после замены HEX на роли побайтно.

## Где это в проекте
`tools/build-graphit-art.mjs`, `miniapp/collections/art/`, `bot/collections.art.test.js`.
