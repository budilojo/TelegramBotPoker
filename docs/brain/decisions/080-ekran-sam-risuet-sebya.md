# 080. Экран, который рисует сам себя, помечается «data-self» — app.js не отдаёт его содержимое чужому узлу

- **Дата:** 2026-10-26
- **Кто решил:** агент K
- **Статус:** принято

## Что решили

Корневой `.lobby` экрана, который сам перерисовывает своё содержимое (курс «Обучение», выбор уровня), помечается `data-self`. Если после обновления с сервера тот же экран уже на странице — старый узел остаётся живым, новый выбрасывается; если другой — новый ставится на место старого.

## Почему

Решение 076 (`adoptLobby`) переносило содержимое нового `.lobby` в старый узел, а нажатия внутри курса «Обучение» писали в старый корень по замыканию — в узел, уже вынутый из страницы. Итог для игрока: нажатие на урок «ничего не делает», диагностика не стартует. Нашли браузерными проверками (e2e-learn, e2e-solo, e2e-scroll-train).

## Где это в проекте

`miniapp/app.js` (`adoptLobby`), `miniapp/train/screens.js` (`learnScreen`, `home`), `docs/scroll.md`. Правило для новых экранов: пишешь в свой корень позже — ставь `data-self`.
