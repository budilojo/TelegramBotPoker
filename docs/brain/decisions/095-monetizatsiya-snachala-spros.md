# 095. Сначала проверка спроса («ложная дверь»), потом косметика, потом Клуб группы

- **Дата:** 2026-10-27
- **Кто решил:** агент H (предложение; решает владелец)
- **Статус:** предложено

## Что решили

Рекомендация: две недели «ложной двери» без денег (порог ≥15 % активных нажали), затем косметика за Stars, затем Клуб группы; подписку и расширения тренировки отложить.

## Почему

Малая аудитория, один сервер, нет поддержки платежей; косметика — самая дешёвая и самая честная. Оценка спроса при <~100 активных — только подсказка.
