# 028. «Кто стреляет первым» выбирают только в партии с ботом; в группе — жребий

- **Дата:** 2026-10-21
- **Кто решил:** агент D волны (форма «как у шашек» из задания; граница — без владельца)
- **Статус:** принято

## Что решили

В форме «Игры с ботами» у морского боя вместо цвета — «Кто стреляет первым:
Я / Бот / Жребий». Выбор кладёт в стол только `bot.prepare` (партия с ботом).
При создании стола в группе поле со страницы не читается — там первый выстрел
всегда по жребию сервера. Подписи формы — от игры (`solo.sideLabel`,
`solo.sides`), правку в `miniapp/solo.js` сделал агент B по просьбе D.

## Почему

Первый выстрел — заметное преимущество; в группе партии идут в рейтинг, и
хост не должен выбирать его себе. С ботом рейтинга нет — пусть человек выбирает.

## Где это в проекте

`bot/games/battleship/rules.js` (`FIRSTS`, `firstSide`), `bot/games/battleship/bot.js`
(`prepare`), `bot/games/battleship/index.js` (`create` без `first`),
`miniapp/games/battleship.js` (`solo`); тест «кто первый не берётся из лобби в
группе» в `bot/battleship.bot.test.js`.
