# 182. Публичный счёт дуэлей не содержит Telegram id

- **Дата:** 2026-10-31
- **Кто решил:** исполнитель J, по правилу приватности AGENTS.md
- **Статус:** принято

## Что решили

В шахматах, шашках, нардах и морском бое отправлять score без поля id.
Внутренний score правил, запись результатов и рейтинг не меняются.

## Почему

Новые тесты всего потока показали id игроков даже у зрителя в лобби:
четыре view напрямую отдавали score(room), где внутренний id нужен для
подсчёта. Клиентские таблицы счёта используют имя, числа и флаги, id не читают.
После фильтрации те же тесты проходят; обратная поломка каждой игры поймана.
Это минимизация данных по контракту проекта, не новое правовое заключение.

## Где это в проекте

`bot/games/{chess,checkers,nardy,battleship}/view.js`,
`bot/multiplayer.test.js`, `tools/e2e-multiplayer.mjs`,
`tools/multiplayer-teeth.mjs`; отчёт J.
