# 050. Аватар — только id из набора av01…av12; png → svg → инициал; пока значки временные

- **Дата:** 2026-10-24
- **Кто решил:** агент T (по заданию владельца, пункт 6 волны 2)
- **Статус:** принято

## Что решили

Сервер принимает только `av01`…`av12`, в вид игрока уходит `avatar` (id или `null`). Клиент строит адрес только для шаблона `av` и двух цифр: сначала `/avatars/<id>.png`, при ошибке `.svg`, потом инициал. Временные значки зверей нарисованы скриптом `tools/build-temp-avatars.mjs`.

## Почему

Из задания: загружать свои картинки нельзя, только выбирать. Пути из данных не строятся. Настоящие PNG владелец сгенерирует отдельно (`docs/next-wave-2/images-avatars.md`).

## Где это в проекте

`bot/profile.js` — `AVATARS`, `avatarId`; `bot/view.js` и `bot/games/*/view.js` — поле `avatar`; `miniapp/ui.js` — `avatar`; `miniapp/profile.js` — `avatarEl`; `miniapp/avatars/`.
