# 091. Внедрение Лиги этапами: теневой режим, пересчёт из журнала, без изменений задним числом

- **Дата:** 2026-10-27
- **Кто решил:** агент G (волна 4) — предложение; решает владелец
- **Статус:** предложено

## Что решили

Сначала невидимая «теневая Лига» (новые таблицы `league*` через `CREATE TABLE IF NOT EXISTS`, версия схемы 5 не меняется), пересчёт истории из `rating_log` (группировка по игре и партии), калибровка весов на настоящих партиях, затем замена «скоро» на экран Лиги; старые очки остаются архивом без изменений. Рейтинговые группы и жетоны — отдельные этапы.

## Почему

Правила начисления у людей не меняются задним числом: рейтинг закрыт, старые таблицы не трогаются, Лига считается параллельно. Старый код открывает базу с лишними таблицами (решение 047).
