## Важно для всех агентов волны

Агенты B, C, D работают в **одной папке** (`/Users/.../TelegramBotPoker`), A — в
своей (`TelegramBotPoker-A`). Чужие незакоммиченные файлы видны в `git status`;
коммитить только свои пути (`git commit -- <пути>`), тесты гонять в отдельной
копии (`git worktree`), иначе чужая недописанная работа ломает прогон.
`git pull --rebase origin redesign` в этой папке пишет «Cannot rebase onto
multiple branches» — работает `git fetch` + `git rebase origin/redesign` (не
разбирал).
