# 07.11.2026 — три дополнительные серии и проверка исходного промта

Существующие карточки «Терракоты», «Орбиты» и «Фарфора» теперь имеют свои
быстрые фильтры. В URL те же ключи. В «Цифрах» отдельная популярность по
всем шести сериям v2, «Графит» доступен в общей подборке. Изображение
вариантов показано в чате для утверждения перед заменой арта.

Турнир можно создать с экрана игр или из настроек. Список своих турниров
включает последние итоги. Операция возврата сверяет участие по подписанному
аккаунту. По приглашению, как и раньше, можно смотреть турнир и занять
место до его старта. Автораздача сверяет время уровня даже при одинаковых
сроках после перезапуска.

Проверены серверные требования исходного промта, включая срок ребая,
перезапуск, автоматические итоги, выдачу и доступ к скрытой витрине.
Дополнительный браузерный сценарий «Дурака» измеряет положение талисмана
относительно карт стола, руки и кнопок. У остальных игроков его нет.

Временные откаты проверок гонки таймеров, участия для возврата и разбивки
популярности ловятся тестами. Полный `npm test` 1657/1657.

Форма создания хранит введённые значения при новом состоянии хаба. Это
проверено браузером, включая временный откат сохранения названия.
`npm run layout`, `npm run kit` и `npm run contrast` прошли.
