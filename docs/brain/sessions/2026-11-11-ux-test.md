## Результат

- `npm run ux`: отдельный бот, фиксированный `data-ux/ux.db`, отдельный `.env.ux`.
  Основной `.env` не загружается; DB_PATH и токен основной среды не наследуются.
  Проверяются разные ID ботов, метка существующей базы до её открытия на запись,
  отсутствие ссылки на каталог/базу. Прямой UX-запуск мимо launcher блокируется.
- Подготовлены Dockerfile и Compose: read-only приложение, пользователь node,
  отдельный том, без production-базы, секретов в образе и production-монтирований.
- Сброс только своего профиля после проверки подписанного Telegram initData
  и списка UX_TESTERS; личность и цель из тела запроса не принимаются.
  Участие в незавершённой комнате/собственное незавершённое лобби блокирует сброс.
  Для продолжения нужно штатно выйти или закончить игру. Очистка в транзакции,
  общие данные и чужие строки сохраняются, собственный кэш очищается.
- Панель: сброс, первый запуск, локальная очистка, сведения о среде и экспорт.
  Общего onboarding в проекте нет. Клиентские ключи UX отделены префиксом;
  обычные ключи production сохраняют прежние имена и значения.
- Добровольная запись шагов: согласие, остановка с серверным запретом дальнейшей
  записи, удаление своей сессии, экспорт исследователю. Только известные события,
  время сервера, UUID, экран и известный game ID; без произвольных данных и секретов.
- Новые серверные и браузерные тесты, воспроизводимые проверки временными поломками.
  Игровой движок server/game.js не изменялся. Секреты не читались и не коммитились.
