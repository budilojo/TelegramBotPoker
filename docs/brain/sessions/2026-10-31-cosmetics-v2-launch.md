# Подготовка однокомандного запуска косметики v2

Исходный c544815, ветка redesign, дерево чистое при старте. Запрос владельца:
такой же терминальный запуск, как с Claude, и более подробная новая косметика.
Составлены docs/cosmetics-v2/00-plan.md, 01-design.md и пять заданий. Шесть серий,
54 самостоятельных предмета + 6 комплектов, магазин нижней панели/Мои вещи,
публичный вид и поддержка семи игр. Базовый зелёный стол не объявлен дефектом;
источник рамки/КРУПЬЕ и старых рубашек агент A исследует до удаления.

tools/cosmetics-run.mjs использует проверенный контроллер через профиль; его
общий механизм расширен без изменения старого CLI/состояния I–M. Состояние и
отчёты нового пакета отдельные, lock общий. Перед push каждой ступени полный
npm test на точном коммите. Защита server/public/deploy/.env и контроллера
сохранена, wrapper защищён. Текущая подготовка не запускает агентов/SSH/прод.

Навык orchestrator: карта зависимостей/общих файлов и последовательная очередь.
Его игровые 3D-инварианты не применимы. Модель Codex наследуется из настройки CLI.

Проверки: node --test tools/codex-release-run.test.js — 30/30. Новые тесты:
независимое состояние/пять этапов/проверки до push/повтор, общий lock, запрет
правки wrapper, красные тесты, dry-run, существование заданий и новый prompt.
Временная поломка общего lock уронила целевой тест Missing expected rejection;
исправление восстановлено. CLI --dry-run успешен: A–E pending, исполнители,
fetch/test/push не запускались.

Полный npm test перед коммитом: первый запуск в sandbox — exit 1 из-за
listen EPERM localhost в сетевых тестах. Повтор с разрешённым localhost:
exit 0, 1577/1577, fail/cancelled/skipped/todo=0, 38,28 с. Логи локально:
/private/tmp/cosmetics-v2-npm-test{,-unrestricted}.log. Это проверка неизменённого
приложения и нового контроллера, не реализация/приёмка новой косметики.
