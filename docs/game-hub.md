# Игровой хаб: покер + дурак — проект

Покер был одной игрой на группу. Теперь это **хаб**: в группе `/play` →
мини-приложение → «Покер» или «Дурак» → лобби с карточкой в группе → друзья
садятся → партия → итоги в группу. Покер при этом не меняется ни в чём, что
видит игрок: те же кнопки, те же тексты, та же ссылка `startapp=<код>`.

Документ написан **до кода** — как задание самому себе. Где решение принято
без вас, это сказано прямо (раздел 9).

---

## 1. Путь от группы до партии

```
 Telegram-группа                        Бот (один процесс)                         Mini App
 ───────────────                        ──────────────────                         ────────
 /play ────────────────────────────▶ знает группу по chat.id,
                                      у группы — свой случайный код g7h2k…
 ◀── «🎮 Во что играем?» ─────────── карточка хаба
     [🎮 Выбрать игру] ── t.me/<бот>/table?startapp=g_g7h2k… ──────────────▶ ХАБ ГРУППЫ
                                                                              «Покер» · «Дурак»
                                                                              открытые лобби
                                      ◀── {t:'create', game:'durak', …} ──── «Создать лобби»
                                      создаёт комнату, код q4m8…
 ◀── «🃏 Дурак · Игроков 1/6» ─────── карточка лобби (своя у каждой игры)
     [🃏 Присоединиться] ── t.me/<бот>/table?startapp=q4m8… ────────────────▶ ЛОББИ ДУРАКА
                                      ◀── sit / start ─────────────────────── «Сесть», «Начать»
 ◀── карточка правится ─────────────  «Партия #2 · Иван ⚔ → Макс 🛡»
 личка: «👉 Ваш ход» ◀──────────────  только если приложение закрыто
 ◀── итоги серии ───────────────────  одно сообщение в конце
```

**Что открывает ссылка — решает префикс `startapp`:**

| `startapp` | Что открывается | Откуда ссылка |
|---|---|---|
| `g_<код группы>` | хаб этой группы: выбор игры и её открытые лобби | карточка `/play` |
| `<код комнаты>` | конкретное лобби или стол (покер или дурак) | карточка игры, `/newgame` |

Коды случайные, из `[a-z2-9]`, 10 знаков, не связаны с id чата. В коде
комнаты нет `_`, поэтому `g_…` с ним не спутать, а **старые ссылки на покерные
столы открываются как раньше**.

`start_param` приходит внутри подписанного `initData`, ему можно верить. Сам
Mini App не знает, из какой группы его открыли, — поэтому группу несёт код в
ссылке, а какому чату он принадлежит, знает только сервер.

**Переход «хаб → лобби» внутри приложения.** Из хаба человек жмёт
«Присоединиться» или «Создать лобби» — сессия переезжает в эту комнату без
перезапуска приложения. Разрешено **только** в комнату той же группы, что
подписана в `initData`. Кто открыл приложение по ссылке на конкретный стол,
в хаб группы не попадает — видит ровно то, что видел раньше.

## 2. Что куда пишет бот

| Событие | Mini App | Группа | Личка |
|---|---|---|---|
| `/play` | — | **новое** сообщение: карточка хаба (прежняя теряет кнопку) | — |
| лобби создано (из хаба) | переход в лобби | **новое** сообщение: карточка этой игры | — |
| `/newgame` | — | **новое** сообщение: карточка покера — как раньше | — |
| сел / встал / настройки | сразу | правка карточки игры | — |
| ход, карта, «бито», «взял» | сразу, анимацией | правка карточки (кто атакует, кто отбивается) | «👉 Ваш ход» — только закрытому приложению, удаляется после |
| конец партии дурака | итог партии, счёт | правка карточки: «дурак — Макс», счёт серии | — |
| конец игры (`/finish` или кнопка хоста) | экран итогов | **новое** сообщение: итоги | — |

За вечер одной игры в группе — **два новых сообщения**: карточка и итоги.
В одной группе может идти сколько угодно игр одновременно (ограничение —
10 незавершённых), у каждой — своя карточка, все правятся независимо и не
чаще раза в секунду на группу.

**Команды в группе:**

| Команда | Что делает |
|---|---|
| `/play` | карточка хаба «🎮 Во что играем?» |
| `/newgame` | покерный стол — как раньше (если в группе уже идёт покер — подскажет `/table` и `/play`) |
| `/table` | заново выложить карточки идущих игр внизу чата |
| `/finish` | завершить игру, которую вы ведёте (хост), и выложить итоги |
| `/cancel` | удалить игру, которую вы ведёте (хост) |
| `/help` | как играть |

Если у человека несколько своих игр, `/finish` и `/cancel` берут самую новую;
остальные завершаются кнопкой в приложении (⋯ → «Завершить»).

## 3. Экраны хаба

```
┌──────────────────────────────────────┐
│ 🎮 Во что играем?                     │
│ Покер по пятницам                     │  ← название группы
│ ┌──────────────────────────────────┐ │
│ │ ♠️   Покер                    →  │ │  большие карточки игр:
│ │      Техасский холдем, фишки      │ │  иконка, одна строка,
│ │      2–8 игроков                  │ │  число игроков
│ └──────────────────────────────────┘ │
│ ┌──────────────────────────────────┐ │
│ │ 🃏   Дурак                    →  │ │
│ │      Подкидной или переводной     │ │
│ │      2–6 игроков                  │ │
│ └──────────────────────────────────┘ │
│  ОТКРЫТЫЕ ИГРЫ В ГРУППЕ               │
│ ┌──────────────────────────────────┐ │
│ │ 🃏 Дурак · Макс     2/6  ждут     │ │
│ │ Макс, Дима        [Присоединиться]│ │
│ ├──────────────────────────────────┤ │
│ │ ♠️ Покер · Иван     4/8  идёт игра │ │
│ │ Иван, Лена, …           [Открыть] │ │
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

- Тап по игре → лист **«Новое лобби»** с короткими настройками → **«Создать
  лобби»**. Создатель — хост.
  - Покер: стек, блайнды, таймер хода, карты (бот / настоящие) — как сейчас.
  - Дурак: **подкидной / переводной**, таймер хода (выкл / 30 / 60 / 90 с).
- У кого уже есть своё несобранное лобби в этой группе, второго не создаёт —
  приложение открывает ему его лобби (иначе двойной тап = две карточки в группе).
- Список открытых игр обновляется сам, пока хаб открыт.
- Из лобби, в которое пришли из хаба, есть «← Все игры» (и системная кнопка
  «Назад» Telegram).

## 4. Стол дурака (телефон, портрет)

```
┌──────────────────────────────────────┐
│ ПАРТИЯ 2 · подкидной   ♦ козырь    ⋯ │  ← партия, вариант, козырь, меню
├──────────────────────────────────────┤
│   (Дима)        (Саша)       (Лена)   │  соперники по дуге сверху,
│   🂠🂠 4         🂠🂠 6 ⚔ ХОДИТ   🂠🂠 6 │  по часовой от вас: рубашки
│                                      │  и число карт, роль — плашкой
│ (Макс 🛡 ОТБИВАЕТСЯ)                  │
│                                      │
│  ┌──┐┐        ┌────┐ ┌────┐  ┌────┐  │  колода: число карт и
│  │12││6♦     │ 7♠ │ │ 7♥ │  │ К♣ │  │  козырь под ней;
│  └──┘┘        │  9♠│ │    │  │    │  │  стол — пары «атака/защита»;
│  сброс 8      └────┘ └────┘  └────┘  │  сброс — рубашки, только число
│    «Саша ходит на Макса · можно подкинуть»
├──────────────────────────────────────┤
│  ВЫ ПОДКИДЫВАЕТЕ                      │  ← ваша роль, крупно
│   ╭──╮╭──╮╭──╮╭──╮╭──╮╭──╮            │  ваши карты веером, крупно;
│   │6♣││7♦││9♥││Д♠││Т♠││8♦│            │  что можно сыграть — ярко,
│   ╰──╯╰──╯╰──╯╰──╯╰──╯╰──╯            │  остальное приглушено
├──────────────────────────────────────┤
│        [ ПАС ]                        │  ← только возможные кнопки
└──────────────────────────────────────┘
```

**Кто что делает — видно сразу.** У атакующего плашка «⚔ ХОДИТ», у
отбивающегося — «🛡 ОТБИВАЕТСЯ» и зелёная рамка, когда ждут его; кто уже
сказал «пас» — «ПАС»; вышедший из партии — «ВЫШЕЛ»; дурак прошлой партии —
🤡. Внизу крупно ваша роль: **ВЫ ХОДИТЕ / ВЫ ОТБИВАЕТЕСЬ / МОЖНО ПОДКИНУТЬ /
ВЫ БЕРЁТЕ / ВЫ ВЫШЛИ**.

**Свои карты** — веером, отсортированы по мастям, козыри справа. Карты,
которые сейчас можно сыграть, яркие, остальные приглушены. **Тап — выбрать**
(карта приподнимается), **второй тап — сыграть**. Отбивающийся выбирает карту
и тапает по карте на столе, которую кроет; если покрыть ею можно только одну —
хватает второго тапа по своей карте. Много карт (взял большой отбой) — веер
сжимается, при нужде в два ряда.

**Кнопки** — большие и только возможные:

| Кто | Когда | Кнопки |
|---|---|---|
| отбивающийся | есть непобитые карты | **ВЗЯТЬ** (+ **ПЕРЕВЕСТИ** в переводном, если можно) |
| главный атакующий | всё побито | **БИТО** |
| остальные атакующие | всё побито или отбивающийся берёт | **ПАС** |
| атакующий | отбивающийся берёт | **ПАС** («подкинуть вдогонку» — тапом по карте) |
| любой за столом | партия кончилась | **СЛЕДУЮЩАЯ ПАРТИЯ** |

**Движение** — как у покера: раздача разлетается от колоды по кругу, карта
атаки летит от того, кто её положил, карта защиты ложится поверх со сдвигом,
«бито» — стол уезжает в сброс рубашками, «взял» — стол летит к взявшему,
добор — карты из колоды к каждому по очереди, козырь уходит последним.
У того, чей ход, — вспышка по краям и вибрация. «Уменьшить движение»
выключает всё это.

**Итог партии** — посередине стола: «🤡 Дурак — Макс» (или «Ничья!»), ниже
счёт серии. **Итоги серии** (после «Завершить»): кто сколько раз был дураком,
сколько партий сыграно.

**Всё решает сервер.** Кнопки и подсветка — только подсказка. Чужой картой,
не той мастью, лишней картой сверх предела, не в свой черёд — сервер
отказывает и говорит почему: «Эта карта не бьёт 10♠: нужна старшая пика или
козырь», «Подкидывать можно только 7 или 9 — они уже на столе», «Больше не
подкинуть: у Макса всего 3 карты».

## 5. Правила дурака

Источник — pagat.com (John McLeod), статьи
[Durak](https://www.pagat.com/beating/durak.html),
[Podkidnoy Durak](https://www.pagat.com/beating/podkidnoy_durak.html),
[Perevodnoy Durak](https://www.pagat.com/beating/perevodnoy_durak.html).
**Оговорка:** сеть окружения, где писался код, pagat.com не пускает
(`www.pagat.com` заблокирован прокси; википедия тоже). Правила сверены по
тому, что известно об этих статьях, и по поисковой выдаче pagat
(«подкидывать можно, только если карт атаки не больше, чем карт у
отбивающегося», «сначала добирает главный атакующий, потом остальные по
часовой, отбивающийся последним», «если после последнего отбоя карт нет ни у
кого — ничья»). Чтобы перепроверить по первоисточнику дословно, разрешите в
настройках окружения домен **`www.pagat.com`**.

По умолчанию — **подкидной**; **переводной** хост включает в настройках. 2–6
игроков. Каждое правило ниже — отдельный тест в `bot/durak.rules.test.js`.

1. **Колода** — 36 карт: 6, 7, 8, 9, 10, В, Д, К, Т четырёх мастей; туз
   старший.
2. **Раздача** — по одной карте, по кругу, начиная с игрока слева от
   сдающего, пока у всех не будет по 6. Сдаёт в первой партии хост, дальше —
   дурак прошлой партии («дурак тасует»).
3. **Козырь** — следующая после раздачи карта: её открывают и кладут под
   колоду лицом вверх, она достаётся последней. Вшестером колода раздаётся
   целиком: последняя карта (она же козырь) показывается всем и остаётся у
   сдающего.
4. **Первая партия** — первым ходит игрок с **младшим козырем**. Если козыря
   нет ни у кого — первый ход у случайного игрока (честный жребий сервера).
5. **Следующие партии** — «**под дурака**»: первым атакует сосед справа от
   дурака, дурак отбивается первым. После ничьей (дурака нет) — снова младший
   козырь.
6. **Атака** — атакующий ходит на соседа слева любой картой.
7. **Подкидывать** можно карты тех достоинств, что уже есть на столе (в атаке
   или в защите). Подкидывают все, кроме отбивающегося, и только после
   первого хода.
8. **Предел** — в одном отбое не больше 6 карт атаки и не больше, чем было
   карт у отбивающегося в начале отбоя.
9. **Отбиться** — старшей картой той же масти или козырем (если атака не
   козырь). Козырь бьётся только старшим козырем. Одна карта защиты кроет
   одну карту атаки.
10. **Бито** — когда всё побито и никто не подкидывает (все атакующие
    сказали «пас»/«бито» или подкинуть уже нельзя по пределу): карты уходят
    в **сброс рубашкой вверх**, его не видит никто. Следующим ходит
    **отбившийся**.
11. **Взять** — отбивающийся может взять вместо защиты. Атакующие ещё могут
    подкинуть «вдогонку» (в пределах правила 8), затем он забирает **все
    карты со стола**. Ход переходит к **следующему после взявшего** — тот,
    кто взял, пропускает ход.
12. **Добор до 6** — после каждого отбоя: сначала главный атакующий, потом
    остальные по часовой, отбивавшийся — последним. Козырь из-под колоды
    уходит последним.
13. **Колода кончилась** — кто остался без карт, вышел из партии (он не
    дурак). Если он должен был ходить или отбиваться — очередь переходит к
    следующему по кругу, у кого есть карты.
14. **Дурак** — последний, у кого остались карты. Если последние карты ушли
    у всех одновременно — **ничья**, дурака нет.
15. **Переводной**: пока ни одна карта атаки не побита, отбивающийся может
    **перевести** — положить карту того же достоинства; теперь отбивается
    следующий слева, против всех карт на столе. Нельзя, если у него меньше
    карт, чем окажется на столе. Переводить дальше можно так же.
16. **Серия** — партия за партией; счёт «кто сколько раз дурак»; итоги — в
    группу одним сообщением.

**Правила приложения** (у pagat их нет — это про телефоны):

- **Пас.** Раз подкидывать может каждый, приложение не может «само» понять,
  что подкидывать больше нечего: авто-пас выдал бы соперникам, что у вас нет
  семёрок. Поэтому «пас» говорит каждый сам. Автоматически пасует только
  то, что и так видно всем: предел отбоя исчерпан, у игрока нет карт.
  Новая карта на столе снимает все «пасы» — можно подкинуть к ней.
- **Таймер хода** (выключен; хост включает: 30 / 60 / 90 с). Время вышло:
  отбивающийся **берёт**, подкидывающие **пасуют**, а если нужно начать
  отбой — бот ходит **младшей некозырной** картой (младшим козырем, если
  других нет). Это единственный ход, который бот делает за человека, и его
  включает хост.
- **Кто-то ушёл посреди партии** (вышел из группы, хост удалил) — партия
  прерывается и не засчитывается: его карт никто не видел, отдать их некуда.
  «Встать» посреди партии нельзя — только между партиями.
- **Что видит каждый**: свои карты; у соперников — только число карт;
  колоду — числом; козырь — всем; стол — всем; сброс — только числом.
  Взятые со стола карты все видели, но приложение их отдельно не помнит.
- **Главный атакующий после перевода** — тот, кто перевёл: он добирает
  первым (у pagat про это не сказано явно).
- **В карточке группы нет заметок, называющих карту** («младший козырь 7♦»,
  «бот сходил 6♠»): в приложении они видны, в группе — нет.

Не используются вариации: «в первом отбое не больше 5 карт», перевод
показом козыря, игра парами.

## 6. Архитектура кода

### Ядро и модули

```
bot/
  app.js         ядро: Telegram, группы, комнаты (много на группу), карточки,
                 «ваш ход» в личку, таймеры, итоги — через модуль игры
  hub.js         ядро: WebSocket-сессии, initData, хаб группы, переходы
  store.js       ядро: SQLite — rooms (по коду, с полем game) и groups
  games/
    index.js     реестр игр: { poker, durak } — ядро знает только его
    poker/index.js   модуль покера: тонкая обёртка над room.js, view.js,
                     render.js, cards.js — их код и 254 теста не тронуты
    durak/
      rules.js   правила: чистые функции над комнатой
      view.js    состояние глазами одного игрока (приватность здесь)
      render.js  тексты: карточка, «ваш ход», итоги серии
      index.js   модуль: действия из приложения, таймер, связь с ядром
miniapp/
  app.js         ядро: оболочка и роутер экранов (хаб / покер / дурак)
  net.js         ядро: WebSocket, переподключение, «один запрос за раз»
  ui.js          общее: DOM, числа 1.000.000, анимации, листы, тосты, часы
  hub.js         экран хаба
  games/poker.js стол покера (перенесён из app.js без изменений поведения)
  games/durak.js стол дурака
  hub.css, durak.css  стили хаба и стола дурака (style.css — общий и покерный)
```

**Модуль игры** — объект с одинаковым набором частей; ядро зовёт только их:

| Часть | Что делает |
|---|---|
| `id`, `title`, `icon`, `blurb`, `minPlayers`, `maxPlayers` | для хаба и карточек |
| `create({chatId, title, host, settings})` | новая комната (`room.game = id`) |
| `handle(app, session, room, msg)` | действия из приложения — со своими проверками |
| `view(room, viewerId)` | что видит один человек; кроме своего — ничего |
| `card(room, {link})`, `results(room)` | карточка в группе, итоги |
| `waiting(room)`, `pingText(room, player)` | кого ждём — для «ваш ход» в личку |
| `clocks(app, room, now)` | таймеры игры; ядро их взводит и снимает |
| `summary(room)` | строка для списка лобби в хабе |
| `markLeft`, `endGame`, `serialize`, `deserialize` | уход из группы, конец, база |

**Общее для всех комнат** (ядро на это полагается): `code`, `chatId`,
`game`, `title`, `status` (`lobby` / `playing` / `paused` / `finished`),
`hostId`, `players[]` с `{id, tgId, name, dm}`, `ui` (id карточки, последний
текст, пинги).

**Новая игра = новая папка `bot/games/<имя>/` + экран `miniapp/games/<имя>.js`
+ строчка в двух реестрах.** Ядро не меняется.

### Покер переезжает без изменения поведения

- Файлы покера (`room.js`, `view.js`, `render.js`, `cards.js`, `deck.js`,
  `eval.js`) остаются где были — их тестируют 254 теста, и переименование
  ничего бы не дало, кроме риска. Модулем покер делает `games/poker/index.js`.
- Из ядра в модуль покера переезжает всё покерное: список действий хаба,
  пошаговое открытие борда, таймер хода, автораздача. Код тот же — меняется
  только адрес.
- `server/game.js` не трогается.
- Проверка: все старые тесты зелёные **без правок**; старые ссылки
  `startapp=<код>` открывают столы; `npm run e2e` и `npm run layout` для
  покера проходят как раньше.

### Хранение

- Было: `rooms(chat_id PRIMARY KEY, …)` — одна игра на группу.
- Стало: `rooms(code PRIMARY KEY, chat_id, game, …)` и
  `groups(chat_id PRIMARY KEY, code UNIQUE, …)`.
- **Старая база переносится сама** при первом запуске: каждый стол получает
  строку по своему коду, `game = 'poker'`. Ничего делать руками не нужно.
- Группа стала супергруппой — переезжают и игры, и код хаба; открытые окна
  продолжают работать.
- Завершённые игры живут, пока их итоги кому-то нужны: удаляются через
  30 минут, когда в группе создают новую игру, и через сутки — при запуске.

### Безопасность — те же два железных правила

1. **Никто не ходит за другого.** Личность — только из подписанного
   `initData`. В хабе и в дураке, как в покере, id и места в теле сообщения
   игнорируются. Переход «хаб → лобби» — только в комнату той группы, что
   подписана в ссылке. Анонимные админы игр не создают.
2. **Никто не видит чужих карт.** Каждому — своё состояние. В данных дурака
   нет чужих рук, порядка колоды и сброса — только числа. Тесты проверяют
   **всё**, что получил каждый телефон за партию, и все сообщения в группе.

## 8. Чего здесь нет

- Командной игры (2×2), «Дурака с погонами», других вариантов раздачи.
- Ставок на деньги, рейтингов между группами.
- Игры в чате командами — всё в приложении, как у покера.

## 9. Решения, принятые без вас (поправьте, если не так)

1. **Пас каждый говорит сам** (раздел 5) — иначе приложение выдаёт, у кого
   нет нужных карт.
2. **Ушёл посреди партии — партия не считается.**
3. **Таймер хода в дураке** есть, выключен по умолчанию; когда включён,
   бот может начать отбой за человека младшей картой.
4. **Порядок мест** — по порядку, в котором садились; атака идёт по кругу
   «налево» — к следующему в этом порядке.
5. **Покерная карточка не меняется** («♠️ Покерная комната · 🃏 Открыть
   стол»), даже если покер создан из хаба: тесты и привычка важнее единообразия.
6. **`/newgame`** по-прежнему один покер на группу (второй — через `/play`):
   так команды `/table`, `/finish`, `/cancel` остаются однозначными.
