  Вторая находка: у `w-preflop-size-3` (`kind: 'table'`) в `setup.hero` лежит **строка** позиции (`'UTG'`), а

## Что сделать

1. **Показ диапазона и ситуации — довести.** Примени заготовку, добейся, чтобы **в каждом задании всех восьми
   направлений** игрок видел то, о чём спрашивают: свои карты, позиции, банк/стек, борд, а где речь о диапазоне —
   матрицу (в задании или в разборе). Пройди **все зарегистрированные упражнения** (скриптом:
   `allExercises()` × несколько seed; в браузере — по одному на вид) и составь таблицу «упражнение → что видно».
   Дыры закрой. Проверь, что разбор диапазонных упражнений (`range`, `flag`) показывает верный диапазон и
   расхождения (пропущено/лишнее) — на экране, а не только в тексте. На 320 px: нет горизонтального скролла,
   матрица читается, зоны нажатия ≥ 44 px (для матрицы — исключение с причиной, `docs/poker-training.md`).
2. **Больше интерактива и понятной обратной связи.** Сначала **предложи** владельцу (в отчёте и `decisions/084`)
   список из 6–8 идей с оценкой «польза / сложность», потом **реализуй 3–4 самые полезные**. Кандидаты (выбери
   и обоснуй, можно свои):
   - **Нажми на клетку в разборе:** тап по руке на показанной матрице отвечает «AKs: 4 комбо, входит/не входит,
     почему» (данные уже есть в `ranges/data.js`);
   - **Серия и подход:** индикатор «3 верных подряд», точки по заданиям подхода (верно/неверно), небольшая
     обратная связь вибрацией (`haptic`) и сменой подписи кнопки; итоговый экран с разбором «где ошибались»;
   - **Скоростной раунд «Fold или Raise»:** руки появляются по одной, ответ — тапом/свайпом, в конце матрица
     с вашими ответами против эталона (тепловая карта) — сильная обратная связь;
   - **Расставить по порядку** (вид `order` есть в списке `KINDS`, виджета нет): комбинации по силе, руки по
     эквити — перетаскивание пальцем **и** кнопки вверх/вниз (доступность);
   - **«Какая рука победит?»** на борде: нажать на победителя, разбор подсвечивает лучшие пять карт;
   - **Подбор числа ползунком с живым результатом:** ползунок размера ставки сразу показывает pot odds/нужное
     эквити на шкале (без «проверить»), чтобы игрок чувствовал зависимость;
   - **Повторить ошибку своими руками:** «Повторить это» после разбора с подсказкой, что изменилось;
   - **Игра раздачи с разбором после каждого решения** — только **предложить** (это уже отдельная волна).
   Каждая реализованная идея — через общий контракт упражнения/виджета (`docs/poker-training.md`), с тестами и
   проверкой «на зубы».
3. **Не прыгать.** Все новые нажатия правят DOM на месте (контракт 6 волны 3, `docs/scroll.md`); для новых
   экранов — `assertNoJump` из `tools/lib/scroll-probe.mjs`. Скролл руками не возвращать.
4. **Тесты («на зубы»).** Узловой тест (без DOM): каждое упражнение с `setup.grid` режима `readonly` имеет
   непустой `ref`; каждое упражнение с `reveal` даёт разбор с диапазоном; `setup.hole` совпадает с `setup.hand`
   (масть и ранги); `make(seed)` по-прежнему детерминирован. Браузерные (в `npm run e2e`): сцена (ряд позиций,
   карты) видна в префлопе; матрица в `readrange-3` видна **до** ответа; после ответа раскрывается диапазон с
   обведённой рукой; новые виды интерактива. Сломай каждую защиту — тест падает (отчёт). Тексты — в `MESSAGES.md`.
5. **Проверки:** `npm test`, `npm run e2e`, `layout`, `kit`, `contrast`, `preview` — **посмотри** все направления
   на 320 и 390 px.
