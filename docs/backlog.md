## Морской бой (просьба владельца)

**План готов:** `docs/plan-battleship.md`; промт для Claude Code — `docs/next-battleship-prompt.md`. Ниже — исходные заметки.

Игра на двоих, как шашки и нарды (`maxPlayers: 2`, часы, рейтинг, бот из
лички, `/battleship`). Главное отличие от всех прежних дуэлей — **скрытая
информация**, то есть правило «Никто не видит чужого» работает здесь сильнее,
чем где-либо:

- Флот каждого игрока — тайна. **Сервер хранит обе расстановки; чужую
  страница не получает ни в каком виде до конца партии** (тест, как в покере:
  проверять всё, что получил каждый телефон за всю партию).
- Игроку уходит: свой флот и попадания по нему; про чужое поле — только
  результаты его собственных выстрелов («мимо», «ранил», «убил»). Убитый
  корабль открывается целиком (как на бумаге — с обводкой клеток вокруг),
  живые — нет.
- Расстановку проверяет сервер (корабли в границах, не касаются друг друга,
  нужный набор). Страница расстановку предлагает, решает сервер.
- Выстрел принимается только у того, чей ход; повторный выстрел в ту же
  клетку отклоняется словами; ходит за себя только сам игрок (личность из
  `initData`).
- В конце партии открываются оба флота — для просмотра и проверки честности.

Решения, которые надо принять до старта (с рекомендацией):

| Вопрос | Рекомендация |
|---|---|
| Поле и флот | классика: 10×10, четыре однопалубных, три двухпалубных, два трёхпалубных, один четырёхпалубный; корабли не касаются |
| Ход после попадания | русский вариант: попал — ходишь ещё; мимо — ход соперника |
| Расстановка | кнопка «Расставить случайно» + ручная (тап по клеткам, поворот); готовность — «Я готов», бой начинается, когда готовы оба |
| Часы | как в шахматах, на ход; на расстановку — свой короткий срок |
| Бот | расстановка случайная, но по правилам; выстрелы: новичок — наугад, дальше — «добивает» раненого по линии, шахматная сетка поиска, у сильного — вероятностная карта по оставшимся кораблям (считает только по тому, что видел сам) |
| Рейтинг | победа/поражение, ничьей нет |

Честность бота: решает **только по своему виду** (свои выстрелы и их
результаты), чужого флота в его данных нет — как у покерных ботов. Тест:
перехватить всё, что видит бот за партию, и убедиться, что чужих кораблей
там нет.

Что нельзя проверить без живого телефона: стрельба тапом по мелким клеткам
(размер зоны нажатия от 44 px на поле 10×10 при ширине 320 px — клетка около
28 px; нужен приём вроде увеличения/сначала выбрать клетку, потом «Огонь»).
Это заложить в экран с самого начала.

## Отложенное из прежних планов

- Шашки: международные (10×10) и поддавки — вариантами.
- Нарды: короткие; серия партий с очками за «марс».
- Покер: таймер роста блайндов по числу раздач (сейчас — по времени).
- Рассылка в группы: бот узнаёт только группы, где был стол или куда его
  добавили после этого обновления; остальные — нет (Telegram не даёт списка).
