# P — пустые места за столом: «Пригласить» и карточка для пересылки

## Цель (пункт 2 владельца)
Свободное место в лобби (`preview/01-lobby-host.png`: пунктирные круги «свободно») должно быть кнопкой «Пригласить»: нажал → выбрал чат → друг получает **готовую карточку** со ссылкой на стол (ориентир — «Пригласить» на пустых местах и карточка «Жду тебя в Уно, заходи!» у конкурента).

## Что сделать
1. **Сначала изучи, что уже есть:** шеринг в шахматах и дуэлях (`docs/duels.md`), `Telegram.WebApp.shareMessage` / подготовленные сообщения бота, ссылки-приглашения, карточка лобби в группе. Не изобретай второй механизм: расширь существующий на все игры через реестр.
2. Кнопка «Пригласить» на пустых местах **в лобби** и на карточке стола между раздачами; во время идущей раздачи — не загромождать стол. Место, где приглашать нельзя (стол полон, игра идёт без свободных мест), кнопку не показывает.
3. **Карточка для пересылки:** короткий понятный текст («<Имя> зовёт в <игру> — заходи») и кнопка/ссылка на стол; картинка — только своя, с нашего сервера (ничего с внешних доменов), без чужого бренда и без талисмана конкурента; если нужна новая картинка, сделать простую плоскую в стиле проекта и объяснить в отчёте.
   Проверить по официальной документации Telegram, что именно поддерживается для Mini App (shareMessage, openTelegramLink, switchInlineQuery) и на каких клиентах; **не обещать неподдерживаемого**.
4. Безопасность: ссылка ведёт на конкретный стол, без секретов; присоединиться по ссылке можно только по обычным правилам (место, пароль/группа, личность из `initData`); чужие закрытые данные не раскрываются; нет спама — повторное нажатие не плодит сообщений.
5. Если пересылка недоступна (старый клиент, нет прав) — понятный запасной путь: скопировать ссылку; словами объяснить, что произошло.
6. Тексты — `MESSAGES.md`. Дизайн-система, 320 px, ≥ 44 px.

## Проверки
Тесты через стенд (кто видит кнопку, кто нет; ссылка не даёт лишнего; полный стол; повтор), e2e лобби, `layout`, `kit`, `contrast`, `preview` — снимки смотреть. «На зубы». Не проверено в живом Telegram: сама пересылка, превью карточки, поведение на iOS/Android — написать прямо.
