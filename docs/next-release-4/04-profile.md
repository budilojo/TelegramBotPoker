# Q — вкладка «Профиль» и заметная «Поддержка»

## Цель (пункт 3 владельца)
Сейчас в нижней панели «Настройки». У конкурента «Профиль»: аватар, имя, ID, значок поддержки и шестерёнка сразу сверху (`design/competitor/`). Нужно, чтобы игрок за одно касание находил **себя, свои вещи, поддержку и настройки**.

## Что сделать
1. Переименовать вкладку и экран в «Профиль» (`miniapp/nav.js`, `miniapp/settings-rows.js`, `miniapp/profile.js`): сверху аватар и имя (из подписанного `initData`/профиля, как сейчас), **свой** ID с кнопкой «Скопировать» (только свой, никому чужой), заметная кнопка «Поддержка».
2. **Поддержка** — вход в бота (`?start=support`, шаг G пакета 2): использовать существующий механизм из «Мои покупки»; проверить по официальной документации Telegram, как открыть личку бота из Mini App, и **не обещать неподдерживаемого**; если не открылось — понятный запасной путь.
3. Ниже — прежние разделы: «Мои вещи»/коллекции, настройки (звук и др., как сейчас), «Добавить на рабочий стол», «Магазин»-связи, всё, что сейчас под «Настройками». Ничего не потерять и не спрятать глубже; старые ссылки/пути (в т. ч. из текстов бота и e2e) должны вести на новый экран.
4. Не раскрывать ничего чужого и не показывать служебное (токены, внутренние id комнат).
5. Тексты — `MESSAGES.md` («Настройки» → «Профиль» везде, где это название вкладки). Дизайн-система, 320 px, ≥ 44 px, без «прыжков».

## Проверки
Тесты и e2e навигации/профиля/поддержки, `layout`, `kit`, `contrast`, `preview` — снимки смотреть. Проверка «на зубы»: чужой ID не показывается; кнопка поддержки не требует лишних прав. Не проверено в живом Telegram: открытие бота из приложения, буфер обмена на iOS/Android.
