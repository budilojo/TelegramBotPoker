# R — независимая проверка четвёртого пакета

Проверяй **фактический код** шагов N–Q, повторяя сценарии независимо от отчётов.

## Выполнить
`npm test`; полный `npm run e2e`; `layout`, `kit`, `contrast`; `preview` со просмотром снимков (хаб, лобби, покер в режимах `virtual` и `live`, дурак, профиль) на 320/360/390/430; `colors`, если затронут UNOQ.
Известная нестабильность: `preview` иногда падает по таймауту — повторить и записать, не скрывать.

## Проверить отдельно
1. **Баг стола (N):** борд по центру и целиком в экране на 320–430 px для `live` и `virtual`, со сбросом, на всех сериях стола; подсказка о сбросе — ровно одна. Не сломаны турнирный стол, анимации, чат.
2. **Главная (O):** возврат к столу, «Стол группы», карточки из реестра (0/1/много), «Турниры», нижняя панель, плоский стиль, нет горизонтального скролла.
3. **Приглашение (P):** кто видит «Пригласить»; ссылка ведёт на нужный стол и не даёт лишнего; полный стол; повторное нажатие; приватность.
4. **Профиль (Q):** «Настройки» нигде не осталось как название вкладки; все прежние разделы доступны; свой ID виден только себе; «Поддержка» ведёт в бота; старые ссылки работают.
5. **Не сломано прежнее:** покупки закрыты (`SALES_MODE`), цены 75/50/100/175, админка магазина, рейтинг как был, права на косметику, часы и места при переходах.
6. Тексты в `MESSAGES.md` совпадают с поведением; нет английских названий в русском интерфейсе, кроме покерных слов.
