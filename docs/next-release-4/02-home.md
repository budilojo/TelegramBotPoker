# O — главная: «продолжить» и крупные карточки игр

## Цель (пункт 1 владельца)
Главная (вкладка «Игры» хаба, `miniapp/hub.js`) должна за секунду отвечать «во что играть сейчас». Сегодня: заголовок «Выберите игру из группы», затем длинный список строк
(`preview/11-hub.png`). Ориентир — структура конкурента Cardbox (`design/competitor/`): одно главное действие сверху, ниже крупные карточки игр с картинкой.

## Что сделать
1. **Верхняя часть:** если у игрока есть незавершённый стол — крупная заметная кнопка «Вернуться к столу · <игра>» (она уже есть — сохранить её смысл и состояния); если в группе есть открытый стол
   (лобби/идёт игра) — карточка «Стол группы» с числом игроков и кнопкой «Присоединиться»; если ничего нет — короткая подсказка «Выберите игру» без лишнего текста.
2. **Игры — крупными карточками с картинкой** (иконки/арт игр уже есть в `miniapp/`; не рисовать новый бренд и не вводить талисмана). Карточка: картинка, название, одна строка описания, «сейчас открыто: N». Список строится **из реестра игр**
   (`miniapp/games/index.js`), не зашивать семь игр; при 0/1/многих играх и длинных названиях — корректно; постраничность/перелистывание из прежнего каталога (кнопки и жесты, индикатор, возврат на ту же позицию) сохранить.
3. «Турниры», нижняя панель, «Рейтинг», «Магазин», «Вернуться к столу» (в том числе во время партии), бейджи — сохранить работу. Не менять смысл кнопок и маршруты; старые тесты и e2e не ослаблять.
4. Дизайн-система: плоско, токены, один зелёный акцент, **без градиентов, свечения и глянца**; картинки игр — содержание игры, их не перекрашивать палитрой. От 320 px, кнопки ≥ 44 px, без горизонтального скролла, без «прыжков» экрана при загрузке.
5. Тексты — по-русски, в `MESSAGES.md`. Заголовок «Выберите игру из группы» заменить более коротким и понятным вариантом (предложить «было → стало»).

## Проверки
Тесты каталога (0/1/много, длинные названия), `layout`, `kit`, `contrast`, `e2e` хаба и навигации, `preview` на 320/360/390/430 — снимки посмотреть глазами. Новые защиты «на зубы». Честно: тач-прокрутка в живом Telegram не проверена.
