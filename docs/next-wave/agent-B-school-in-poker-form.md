## Что хочет владелец (его слова)

«Убрать снизу выбора игр **обучение** и добавить его в покер — там, где ты выбираешь
уровень сложности, **блайнды** и т.д.» К сообщению приложены скриншоты: экран
«Игры с ботами» (внизу карточка «Школа покера — Азбука и уроки с наставником»)
и форма «Покер — с ботами» (блоки «Уровень», «Соперников», «Характеры соперников»,
кнопка «▶ Играть»).

## Что сделать

1. **Убрать карточку «Школа покера» с экрана «Игры с ботами»** (`schoolCard` в
   `miniapp/solo.js`). Кнопка «▶ Продолжить: …» (возврат в начатую партию, в том
   числе в школе: `bot.label` в `bot/games/poker/index.js`) — **остаётся и
   работает**.
2. **В форме «Покер — с ботами»** (шторка `solo-form`, `showSheet('solo-form')`)
   добавить **выбор режима сверху**: «Партия» | «Обучение». Режим «Обучение»
   открывает то, что раньше открывала карточка: азбука, шесть уроков, свободная
   игра (`openSchool` из `miniapp/school.js`) — либо прямо в этой шторке, либо
   переходом из неё; реши сам, как удобнее на телефоне, и назови выбор. В режиме
   «Обучение» уровня, числа соперников и характеров нет (там один наставник).
3. **Блайнды и «и т.д.» в форме партии.** Сейчас стол с ботами всегда 10.000
   фишек, блайнды 50/100, рост каждые 10 минут (`bot.settings`). Добавь в форму:
   - **Блайнды:** 25/50 · 50/100 (по умолчанию) · 100/200 · 200/400;
   - **Стартовый стек:** 5.000 · 10.000 (по умолчанию) · 20.000;
   - **Рост блайндов:** «Растут» (по умолчанию, раз в 10 минут) | «Не растут».
   Значения со страницы — **недоверенные**: `bot.settings(raw)` принимает только
   значения из этих наборов, остальное заменяет умолчанием (тест на «подсунули
   чужое число»). Серверная форма правил стола не меняется (`server/game.js` не
   трогать — `AGENTS.md`, правило 5).
4. **Тексты** — по-русски, числа с точками; обновить `MESSAGES.md`.
5. **Тесты и проверки:** `bot/poker.bot.test.js` / `bot/poker.school.test.js`
   (настройки из формы доходят до стола; чужие значения отклонены), обновить
   `tools/e2e-solo.mjs` (путь к школе теперь — через форму покера), обновить сцены
   в `tools/preview.mjs`, `npm run layout`, `npm run kit`, `npm run contrast`,
   `npm run preview` — **посмотреть**: экран «Игры с ботами» и форма покера на
   320 и 390 px; форма не должна прокручиваться горизонтально, кнопки ≥ 44 px.
   «На зубы»: убрать проверку допустимых значений — тест «подсунули чужое» падает.

## Важно

- **Подсказки выключены** (`docs/brain/decisions/016`, `bot/hints.js`): школа
  остаётся без советов и «шанса выиграть»; не включай. Названия вроде «Свободная
  игра с подсказками» не возвращать.
- Прогресс уроков (`localStorage` `school.done`) должен сохраниться.
- «Игра против бота из лички» для других игр устроена так же (форма берётся из
  `solo` модуля игры) — не сломать шахматы, шашки, нарды, дурак, UNOQ.
