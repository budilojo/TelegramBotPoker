## Что сделать

1. **Сначала экран.** Разберись с «Огонь» на 320×568: измерь, **почему** на 2 px
   ниже края (отступы, высота панели, шрифт); если дело только в шрифтах
   песочницы — докажи (замер с другим системным шрифтом) и всё равно добавь запас,
   чтобы кнопка была видна целиком с запасом ≥ 8 px. Проверка `npm run layout` и
   `tools/e2e-battleship.mjs` — зелёные.
2. **Бот** — по плану, «Этап 3»: расстановка случайная по правилам; **стреляет
   только по своему виду** (свои выстрелы и результаты — чужого флота в его
   данных нет; тест перехватывает всё, что видит `decide`); пять уровней: 0 —
   наугад; 1 — охота и добивание; 2 — шахматная сетка; 3 — вероятностная карта;
   4 — то же с учётом «корабли не касаются». Ход идёт через тот же `handle`, что у
   человека («никто не ходит за другого»). Подключение — как у шашек
   (`bot/games/checkers/bot.js`, поле `bot` модуля, `docs/bots.md`).
3. **Тесты:** бот ходит только законно (тысячи партий бот-против-бота без отказа
   сервера); **уровни значат** (замером в тесте: каждый следующий в среднем
   выигрывает у предыдущего за меньшее число выстрелов); приватность бота;
   «на зубы» — подсунуть боту чужой флот в `view`: тест обязан упасть;
   `node tools/battleship-teeth.mjs` по-прежнему красный на сломанном и зелёный на целом.
4. **Клиент:** `export const solo` в `miniapp/games/battleship.js` (форма: уровень,
   цвет/очерёдность, часы — как у шашек); «Сыграть ещё» против бота работает (см.
   исправление в `bot/hub.js` ветка `again` для `room.solo`).
5. **e2e в браузере:** партия против бота (расстановка → бой → итоги) в
   `tools/e2e-battleship.mjs`, на 390×844 и 320×568.
6. **Документы:** `docs/battleship.md` (правила и принятые решения, как проверена
   приватность, бот и замеры уровней), строки про морской бой в `docs/duels.md`,
   `docs/bots.md`, `MESSAGES.md`, `AGENTS.md` (список игр, таблица документов).
7. `npm test`, `npm run layout`, `npm run kit`, `npm run contrast`,
   `npm run preview` (**посмотреть** экраны расстановки, боя, итогов).
