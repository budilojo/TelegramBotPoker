## Сначала почини то, что нашла твоя же проверка

`npm run kit` падает на 320×568: «страница шире экрана на 11px — button.k-btn
до 331px». В отчёте по фазе 1 было сказано, что все проверки зелёные, — это не
так, и я проверил у себя на чистой ветке.

Виновата длинная подпись в призрачной кнопке («Дополнительные настройки →»):
кнопка не ужимается и не переносит текст. Почини в ките, а не в витрине:
подпись любой длины — обычное дело, а кит должен держать 320 пикселей. После
починки прогони `npm run kit` ещё раз и покажи вывод.

И впредь: «зелёное» — это вывод команды, а не память о том, что она проходила
час назад.

## Ответ на твой вопрос про Placeholder

Отдельного токена не заводи. Я вынул пиксели из макета: образец Placeholder в
ките — это `#1B2D34`, то есть с точностью до единицы **приподнятая поверхность**
`#1D2D35`, которая уже есть. Пустое место (слот карты, пустое сиденье) —
`--k-elevated` как фон и `--k-text-2` как значок внутри.

Попутно важное: пиксели образцов в ките **не совпадают с подписанными под ними
hex** — «Выключено» подписан `#41545C`, а нарисован `#263C44`. Значит источник
истины — подписи, а не цвет пикселя. Нигде не пипеткой с картинки.

## Что делает фаза 2

Общие компоненты — те, что живут во всех трёх играх и на всех экранах. Экраны
по-прежнему **не трогаем**: компоненты собираются в ките и показываются на
витрине.

Открой перед работой: `00-ui-kit-final` (разделы 5, 8, 10–16, 19),
`01-home`, `31-poker-tables`, `34-poker-game-player-turn`, `13-durak-game-state`.

1. **Шапка экрана** и **шапка игры** — заголовок, подзаголовок, кнопка назад,
   кнопка «ещё». Две вариации одного компонента, а не два компонента.
2. **Аватар.** Размеры 48 / 40 / 32 / 24, группа аватаров с «+N», пустое место.
   **Правило, принятое заранее:** своё фото — настоящее, из `initData`; у
   остальных буква с цветом от имени. Кружок у всех одинаковый — тот же размер,
   та же обводка, то же место; отличается только содержимое.
3. **Строка игрока** (имя, пометка «Вы», «Хост») и **строка рейтинга** (место,
   имя, очки со знаком). Зелёный плюс, красный минус — и ничего больше красным.
4. **Строка стола** — аватары участников, сколько из скольких, состояние,
   шеврон. Номера вида «#1846» не делай: у нас короткие коды, сквозная
   нумерация появится вместе с рейтинговыми группами.
5. **Место за столом** (покерное) — аватар, имя, стек, ставка, значки D/SB/BB,
   кольцо таймера с числом, состояния: обычное, со ставкой, сбросил, активный
   ход, победитель. Это один компонент с состояниями, а не шесть.
6. **Индикатор состояния** — четыре точки из кита (нейтральный, активный,
   успех, выключен).
7. **Статус-бар игры** — некликабельная полоса «Ход Марии · Ожидание действия».
   Высота по содержимому.
8. **Зона действий игры** — три кнопки в ряд, средняя главная. По-русски:
   «Сбросить · Уравнять N · Повысить».
9. **Липкая зона действий** — та, что прижата к низу экрана, с учётом
   безопасной зоны.

Всё это добавь на витрину `kit.html` во всех состояниях и расширь
`tools/kit-check.mjs`: он должен проверять не только ширину страницы, но и что
у каждого интерактивного компонента палец попадает — **минимальная зона
нажатия 44 пикселя**.

## Чего фаза 2 не делает

Не трогает ни один экран приложения и сервер. Не делает нижнюю навигацию — у
нас не вкладки, а группы. Не изобретает компонентов, которых нет ни в ките, ни
в списке выше.

## Правила

- Ни одного нового значения цвета, отступа, скругления и шрифта сверх шкалы.
- Компонент с состояниями — один компонент. Если тянет завести второй, сначала
  скажи мне почему.
- `server/game.js` не трогать, `.env` не открывать, на сервер не выкатывать,
  pull request не создавать.
- `npm test` (526), `npm run e2e`, `npm run layout`, `npm run colors`,
  `npm run kit` — все зелёные, и покажи вывод каждой.
