# Промт на редизайн: фаза 1 — токены и примитивы

Фазы идут по одной. Этот промт — только первая. Следующий дам, когда увижу
результат: игровой экран слишком дорог, чтобы менять его вслепую.

Копировать всё, что ниже разделителя.

---

Делаем редизайн интерфейса по макетам. **Это первая фаза из восьми, и она
намеренно маленькая: ни один экран в ней не меняется.**

Сначала:

```
git fetch origin claude/bold-carson-kjswyx
git checkout -b redesign origin/claude/bold-carson-kjswyx
npm test
```

**Работаем в новой ветке `redesign`.** Ветка `claude/bold-carson-kjswyx` — это
то, что крутится в проде; если у живых людей вылезет баг, его надо будет
выкатить, а с перепаханным интерфейсом это невозможно.

## Прочти в таком порядке

1. `docs/redesign.md` — решения и границы. **Это закон.** Там сказано, что
   берём из макетов, что в них неверно, и чего нельзя потерять.
2. `design/mockups/00-ui-kit-final.png` — сам кит. Открой и смотри, а не
   пересказывай описание.
3. `docs/game-hub.md` — как устроен продукт.

## Что делает первая фаза

Только основание. Экраны не трогаются совсем.

1. **Токены** — цвета, отступы, скругления, типографика из `docs/redesign.md`,
   раздел 2, в CSS-переменные. Один источник, рядом с остальными стилями.
2. **Типографика** — семь размеров, ровно те, что в ките. Ни одного
   восьмого.
3. **Примитивы** — кнопка (основная, вторичная, призрачная, выключенная),
   поле ввода, числовое поле со степпером, сегментный переключатель,
   переключатель-тумблер, ползунок, разделитель, иконочная кнопка, шторка
   снизу.
4. **Страница-витрина** `tools/kit-check.mjs` по образцу `tools/colors-check.mjs`:
   поднимает все примитивы во всех состояниях в настоящем Chromium на пяти
   размерах экрана и снимает. Нужна, чтобы кит было видно глазами, а не
   только в коде.

## Чего первая фаза НЕ делает

Не трогает ни один экран. Не меняет разметку хаба, рейтинга, покера, дурака и
UNOQ. Не трогает сервер. Не переименовывает существующие классы ради красоты.

Старые стили остаются работать как есть. Новые токены ложатся рядом — экраны
переедут на них в следующих фазах, по одному.

## Правила

- **Шрифт Inter подключать нельзя из сети.** Telegram Mini App грузится на
  плохом мобильном интернете; шрифт с чужого домена — это и задержка, и ещё
  одна точка отказа. Либо кладём файлы шрифта в `miniapp/` и подключаем
  локально, либо берём системный стек. Реши и объясни, что выбрал.
- **Токены — переменные, а не числа в разметке.** Если в макете 13 px, а в
  шкале 12 — ставим 12. Расхождение в пару пикселей — артефакт генерации, а не
  новый размер.
- **Ни одного нового размера шрифта, отступа и скругления** сверх шкалы.
- `server/game.js` не трогать. `.env` не открывать. На сервер не выкатывать.
  Pull request не создавать.
- **526 тестов, `npm run e2e`, `npm run layout`, `npm run colors` должны
  остаться зелёными.** Если что-то покраснело — неправ новый код, а не тест.

## Что показать в конце

Снимки витрины, числа по тестам, и список: какие значения кита ты положил в
токены, где макет расходился со шкалой и как ты это решил. Закоммить по частям
понятными сообщениями и запушить в `redesign`.
