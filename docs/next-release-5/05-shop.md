# W — магазин: понятный и приятный (ориентир — структура Cardbox)

Прочитай скилл `ux-ui-audit` (раздел 4) и скриншоты `design/competitor/` (магазин: вкладки Рамки/Карты/Эмодзи/Коины, крупные карточки, окно подтверждения «ПОДТВЕРДИТЕ ПОКУПКУ»).

## Что не так сейчас (по снимкам `docs/cosmetics-v2/reports/shop-screens/`, 390 px)
- Три выпадающих списка («Игра», «Категория», «Коллекция») вместо понятных вкладок; «Найдено: 64» — служебный язык.
- Каталог — один столбец карточек с мелким превью и кнопкой «Можно примерить»; картинка не главное.
- Строки вроде «Ваши вещи · покупки пока закрыты», «Доступ владельца · новые вещи бесплатно», «Цена не утверждена» — жаргон, не для игрока.
- Карточка вещи: нет ясной главной кнопки; «Примерить» и «Уже в вашей коллекции» выглядят одинаково.

## Что сделать (структура и ясность, не копия)
1. **Вкладки категорий** сверху (рубашки, столы/сукно, рамки, значки и талисманы, наборы — по реальному каталогу) вместо выпадающих списков; фильтр «игра» — компактные чипы (горизонтальная прокрутка) или одна шторка; коллекции — в самой сетке (заголовки секций) или чипами.
2. **Сетка в две колонки** (на 320 px — тоже две, с кеглями из шкалы) с **крупным превью**; под ним название, одна строка и **одна** понятная кнопка/статус: «Примерить» / «В коллекции» / цена в ⭐ / «Скоро» (продажи закрыты → «Скоро», без «Цена не утверждена»).
3. **Карточка вещи** (шторка/экран): большое превью, состав набора, что даёт (в каких играх видно), главная кнопка; «Примерить» всегда доступна и не выдаёт прав. Окно подтверждения покупки (снизу): название, превью, цена, «Купить»/«Отмена» — без реальных платежей (путь оплаты закрыт; логику покупок не менять).
4. **Мои вещи** по слотам с крупными превью, «Надето» заметно, «Снять»/«Надеть» одной кнопкой; пустые состояния с понятным шагом («Загляните в каталог»).
5. Жаргон убрать из игрового интерфейса; владельцу (ADMINS) — отдельная небольшая метка «владелец», не шум для всех.
6. Дизайн-система: плоско, токены, без градиентов/свечения/золота; игровой арт не перекрашивать. Картинки конкурента, талисман и его тексты не копировать. Цены — только из `offers.json`/админки (не придумывать), продажи закрыты, `SHOP_ENABLED`/`SALES_MODE` не менять.
7. Тексты — в `MESSAGES.md`. Права, выдачу, снимки вида и платёжный код **не менять**; сохранить все существующие тесты (`e2e-cosmetics-shop`, `e2e-collections*`, `e2e-payments`, `e2e-admin-shop`).

## Проверки
Тесты и e2e магазина, `layout`, `kit`, `contrast`, `preview`; снимки 320/390/430 **смотреть глазами**: каталог, карточка, примерка, «Мои вещи», пусто/загрузка/ошибка, длинные названия. «На зубы»: защита от «Примерить даёт право», от показа цены при закрытых продажах. Честно: живой Telegram и телефон не проверены.
