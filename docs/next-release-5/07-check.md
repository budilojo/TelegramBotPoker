# Y — независимая проверка пятого пакета

Проверяй **фактический код** шагов S–X, повторяя сценарии сам, а не по отчётам. Прочитай скилл `ux-ui-audit`.

## Выполнить
`npm test`; полный `npm run e2e`; `layout`, `kit`, `contrast`; `ui:scan` и `ux:sim` (повторить и убедиться, что они воспроизводимы и действительно падают при поломке — «на зубы»); `preview` со просмотром снимков глазами (хаб, лобби и стол всех семи игр, итоги, магазин, профиль, рейтинг) на 320/390/430; `colors`, если затронут UNOQ.

## Проверить отдельно
1. **Дурак:** второй тап покрывает единственную цель; при нескольких целях подсвечиваются подходящие; перетаскивание работает; правила отбоя (решение 221) не нарушены; перевод работает.
2. **Магазин:** вкладки категорий, сетка с крупным превью, карточка, примерка, «Мои вещи»; продажи **закрыты**, цены не изменены и не придуманы, права/выдача не тронуты, жаргона нет; 320 px без выездов.
3. **Вёрстка и текст:** `ui:scan` чисто; нет обрезанных букв, наложений, горизонтальной прокрутки; глазами.
4. **Не сломано прежнее:** жесты других игр, приватность (`view`), часы/места при переходах, рейтинг как был, платежи закрыты.
