# U — красота, стиль и единообразие (ревью по снимкам)

Прочитай скилл `ux-ui-audit` (раздел 3). Ты — придирчивый дизайнер: **смотри снимки глазами**.

## Что сделать
1. Сними набор экранов (`npm run preview`, e2e-снимки, при необходимости свои сцены) на 320/390/430: хаб, лобби и стол каждой из семи игр, итоги, магазин (каталог, карточка вещи, примерка, «Мои вещи»), профиль, рейтинг, шторки, чат, приглашение.
2. Оцени и опиши по каждому экрану: иерархия (что главное), отступы и выравнивание по сетке, единообразие карточек/кнопок/заголовков между экранами и играми, плотность и читаемость текста, иконки, пустые состояния, «технический» язык, лишние слова. Отдельно — «что выглядит дёшево или сломано».
3. Сравни структуру с образцом `design/competitor/` (только ясность и порядок, не стиль и не картинки) и скажи, где у нас менее понятно.
4. Результат: `docs/next-release-5/visual-review.md` — оценка по экранам, находки (ID, экран, что не так, почему, **предложение в рамках дизайн-системы**), топ-10 самых заметных улучшений по пользе/риску, что нельзя менять (игровой арт, запрещённые приёмы).
5. Код не меняй (чинит X); новых картинок/брендинга не вводи.

Проверки: `npm test`; указать, какие экраны смотрел, а какие нет.
