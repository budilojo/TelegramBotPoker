## 1. Как повторить

```
npm run ui:scan                        # 155 экранов × 320/360/390/430 × обычные и длинные имена, ~6 мин
node tools/ui-scan.mjs --widths=320 --only=hub --out=preview/scan-look
node tools/ui-scan.mjs --teeth         # нарочно ломает вёрстку 7 способами
```

Выход — `preview/scan/report.json` (экран, ширина, селектор, координаты, что не так, снимок) и снимки в
`preview/scan/<ширина>-<normal|long>/`: `*.png` — как открылся, `*.end.png` — прокручено вниз, `*.marked.png` — с
рамками вокруг серьёзных находок. Папка `preview/` в git не входит. Высоты окна: 568, 640, 844, 932.

Сцены — все из `npm run preview` плюс добавочные (`tools/lib/ui-scan-hook.mjs`): пустой и забитый хаб, профиль с
ошибкой ника, рейтинг (закрыт и открыт), магазин глазами владельца и гостя, покер на 8 со ставками в сотни миллионов,

«Длинные имена» — 16 широких букв (предел имени) и длинное название группы.

Команда **сейчас красная** (код 1): настоящие дефекты есть. Это ожидаемо, пока X их не исправит. В `npm test` входит
только проверка правил разбора без браузера (`tools/ui-scan.test.js`).

## 4. Ложные срабатывания и что отсеяно (10.395 за прогон)

Правила и причины — `ALLOW` в `tools/lib/ui-scan-rules.mjs`:

| Что | Почему не дефект |
|---|---|
| клетки доски и пункты нард мельче 44 px | 8–12 в ряд на 320 px по 44 px не помещаются; это игровое поле (основная масса отсеянного) |
| веер карт: перекрытие и мелкая открытая полоса | так устроена рука |
| колода, бита, козырь за краем стола | нарочно подрезаны (это же проверяет `npm run layout`) |
| ряды-листалки (фильтры магазина, страницы каталога игр) | листаются вбок по замыслу |
| значок числа карт поверх аватара; подпись под закреплённой кнопкой в прокручиваемой шторке | так нарисовано |

В первом прогоне казалось, что в рейтинге пояснение «Места в таблице…» налезает на блок своей строки; это обычный
список, срезанный краем прокрутки, — дефектом не считаю (номер T-09 свободен).

Отсеяно по ходу доработки самого скана: «закрыто нижней панелью» у того, что докручивается (админка, магазин) — теперь
скан сначала подводит элемент в середину списка; «налезает» на текст, уже срезанный родителем.

Оговорка по шторкам: пока открыта шторка, чат или магазин, меряется только верхний слой.
