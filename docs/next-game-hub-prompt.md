# Задача: игровой хаб для друзей в Telegram — покер (уже есть) + дурак

Ты продолжаешь проект `budilojo/TelegramBotPoker`. Сейчас это покер в Telegram
Mini App для компании друзей. Его надо превратить в **игровой хаб**: в Mini App
человек выбирает, во что играть — **покер** или **дурак** (дальше будут и
другие игры), — в группе создаётся лобби, друзья из группы заходят в него.
Покер при этом сохраняется целиком и становится одной из игр.

## 0. С чего начать (важно)

- Весь готовый покер — в ветке **`claude/telegram-poker-bot-r42kp5`**, в
  `main` его может не быть. Начни свою ветку **от неё**:
  `git fetch origin claude/telegram-poker-bot-r42kp5` и создай/перебазируй
  свою рабочую ветку на `origin/claude/telegram-poker-bot-r42kp5`.
- Прочитай: `bot/README.md` (как всё устроено и запускается),
  `docs/miniapp-ux.md` (UX-решения стола), `ENGINE-NOTE.md`,
  `bot/rules.test.js` (официальные правила покера тестами).
- Прогони `npm test` — должно быть 254 зелёных теста. Это точка отсчёта.

## 1. Что уже есть

- Node 22.5+, ESM, без сборки. grammY (long polling) + HTTP/WebSocket-сервер
  для Mini App в одном процессе (`bot/index.js`, `bot/server.js`, `bot/hub.js`).
- Личность игрока — только из подписанного Telegram `initData`
  (`bot/webapp-auth.js`, HMAC по токену бота). Сервер шлёт каждому своё
  состояние (`bot/view.js`): свои карты — только ему.
- Группа — лобби и доска объявлений: одна карточка комнаты с кнопкой
  «🃏 Открыть стол» (прямая ссылка `t.me/<бот>/<приложение>?startapp=<код>`),
  правится по ходу игры; итоги — одним сообщением в конце. «Ваш ход» в
  личку — только если приложение у игрока закрыто, удаляется после хода.
- Mini App (`miniapp/`): стол, анимации (раздача, фишки, счётчики, «+N»),
  раскладка без наложений на любом экране (`npm run layout`), режим дилера.
- Проверки: `npm test`, `npm run e2e` (браузеры играют тапами),
  `npm run preview` (скриншоты), `npm run layout`.

Пользователь не программист, запускает всё у себя на Маке:
`~/Desktop/TelegramBotPoker`, бот **@All_InPoker_bot**, туннель
`cloudflared tunnel --url http://localhost:8080`, в `.env` — `BOT_TOKEN`,
`WEBAPP_URL` (адрес туннеля), `MINIAPP=table` (короткое имя приложения из
@BotFather `/newapp`). Обновляется командами `git pull` и `npm run bot`.
Объясняй ему шаги просто, по-русски, по одному.

## 2. Что нужно сделать

### 2.1. Хаб: выбор игры
- В группе команда **`/play`** (и пункт в меню команд бота) → бот присылает
  карточку «🎮 Во что играем?» с кнопкой, которая открывает Mini App **для
  этой группы**.
- Первый экран Mini App — **выбор игры**: большие карточки «Покер» и «Дурак»
  (иконка, 1 строка описания, число игроков). Ниже — **лобби, которые уже
  открыты в этой группе**, с кнопкой «Присоединиться».
- Выбрал игру → короткие настройки (для покера — как сейчас, для дурака —
  см. 2.3) → «Создать лобби». Создатель — хост лобби.

### 2.2. Лобби в группе
- Созданное лобби бот **публикует в группе** карточкой: «♠️ Покер · Лобби ·
  Игроков 2/8 · [Присоединиться]» / «🃏 Дурак · Лобби · 3/6 · [Присоединиться]».
  Кнопка открывает Mini App сразу **в этом лобби** (код в `startapp`).
- Друзья жмут кнопку → видят лобби → «Сесть». Хост жмёт «Начать».
- Дальше — как сейчас у покера: карточка правится (идёт игра, чей ход, итог),
  итоги — одним сообщением, «ваш ход» в личку — только при закрытом
  приложении. Никакого спама в группе.
- В одной группе может быть несколько лобби/игр одновременно (у каждой своя
  карточка). `/newgame` продолжает создавать покер, как раньше.

### 2.3. Дурак
По умолчанию — **подкидной**, **переводной** — настройкой хоста. 2–6 игроков.
Сверь правила с официальным источником (например, pagat.com — «Durak»,
«Podkidnoy Durak»; если сайт заблокирован сетью окружения — скажи
пользователю, какой домен разрешить) и запиши их в документ. База:
- 36 карт (6–A). По 6 карт каждому. Козырь — открытая нижняя карта колоды,
  она лежит под колодой и достаётся последней.
- Первая партия: первым ходит игрок с младшим козырем. Следующие — «под
  дурака»: первым атакуют проигравшего прошлой партии.
- Атака — любой картой; подкидывать можно карты тех же достоинств, что уже
  на столе; подкидывают все, кроме отбивающегося. В одном отбое — не больше
  6 карт и не больше, чем карт на руке у отбивающегося.
- Отбиться — старшей картой той же масти или козырем (козырь бьётся только
  старшим козырем).
- «Бито» — карты уходят в сброс рубашкой вверх, отбившийся ходит следующим.
  «Взять» — все карты со стола в руку, ход переходит к следующему после
  взявшего.
- Добор до 6: сначала атаковавший, потом остальные подкидывавшие по часовой,
  отбивавшийся — последним.
- Колода кончилась: кто остался без карт — вышел. Последний с картами —
  **дурак**. Вышли последние одновременно — ничья.
- Переводной: пока ни одна карта не побита, отбивающийся может перевести
  атаку картой того же достоинства — если у следующего хватает карт.
- Серия партий: счёт «кто сколько раз дурак», итоги — в группу.

**UX дурака** — в духе покерного стола: свои карты внизу веером, крупно,
тап — выбрать/сыграть; на столе пары «атака/защита»; колода с числом карт и
козырем под ней; соперники по кругу с числом карт (рубашки); ярко видно,
**кто атакует, кто отбивается, кто может подкидывать**; большие кнопки
«Бито» / «Взять» / «Пас» / «Перевести» — только когда они возможны; анимации
как у покера. Всё решает сервер: нельзя сыграть чужой картой, покрыть не той,
подкинуть лишнее — отказ с понятным сообщением.

### 2.4. Покер остаётся
Всё, что есть, должно работать как сейчас. Старые ссылки на столы
(`startapp=<код>`) должны открываться. Все 254 теста — зелёные.

## 3. Ограничения Telegram (уже проверены — не трать на них время)
- Кнопка `web_app` работает **только в личке**. В группе — только URL-кнопка
  на прямую ссылку `t.me/<бот>/<короткое_имя>?startapp=<параметр>`.
- Mini App **не знает, из какой группы его открыли**: `initData` не содержит
  id чата. Поэтому группу нужно передавать в `startapp`: карточка `/play`
  несёт случайный код группы (не id чата!), сервер знает, какой группе он
  принадлежит. `startapp` — до 64 символов `[A-Za-z0-9_-]`; различай
  префиксом, что открыто: хаб группы или конкретное лобби.
- `start_param` приходит внутри подписанного `initData` — ему можно верить.
- Бот не может написать человеку первым: «ваш ход» в личку — только тем, кто
  нажал Start.
- Mini App — только по HTTPS (туннель/хостинг). Короткое имя приложения у
  @BotFather менять не нужно: `table` остаётся, меняется только то, что
  открывается по параметру.

## 4. Архитектура (рекомендация, можешь улучшить — но объясни)
- Общее ядро: вход по `initData`, WebSocket-хаб, лобби и места, хост и права,
  карточка в группе, уведомления, таймеры, хранение (SQLite, у комнаты есть
  `game: 'poker' | 'durak'`), выдача каждому своего состояния.
- Каждая игра — модуль: `games/<имя>/` на сервере (правила, действия,
  `view` для одного зрителя, тексты карточки) и на клиенте (экран стола).
  Новая игра = новый модуль, ядро не трогаем.
- Покер переносится в эту схему **без изменения поведения** — тесты это
  подтверждают.
- **`server/game.js` не трогать** (движок покера общий с веб-версией).

## 5. Железные правила (действуют и дальше)
- **Никто не ходит за другого**: личность — только из подписанного
  `initData`, id и места в теле сообщения игнорируются; отказ всегда
  объясняется.
- **Никто не видит чужих карт**: каждому — только его состояние; сброс
  дурака — закрыт; тесты проверяют всё, что получил каждый телефон.
- Если тест падает — по умолчанию неправ продакшен-код, а не тест. Никогда
  не ослабляй ассерт ради зелёного прогона.
- Язык интерфейса — русский, числа с точками: 1.000.000.
- Токен бота никогда не спрашивай и не показывай; `.env` в git не попадает.
- Коммить в свою ветку с понятными сообщениями, пушь; PR не создавай без
  просьбы.

## 6. Порядок работы
1. **Сначала продумай и опиши** (в `docs/`): схему «группа → `/play` → хаб →
   лобби → игра», правила дурака со ссылкой на источник, экраны хаба и стола
   дурака, что куда пишет бот. Только потом — код.
2. Ядро хаба и перенос покера — все старые тесты зелёные.
3. Дурак: правила сервером + тесты «по правилам» (как `bot/rules.test.js` у
   покера: одно правило — один тест), приватность, никто за другого.
4. Экран дурака и хаба; `e2e` (браузеры играют партию в дурака тапами),
   `preview`-скриншоты, `layout`-проверка без наложений для 2–6 игроков.
5. Инструкция пользователю, что обновить и как проверить.

## 7. Готово, когда
- В группе `/play` → Mini App → выбор «Покер»/«Дурак» → лобби в группе →
  друзья присоединяются → партия играется до конца → итоги в группе.
- Покер работает как раньше, старые ссылки открываются.
- Все тесты зелёные (старые + новые), `e2e` и `layout` проходят.
- Скриншоты хаба, лобби и стола дурака показаны пользователю.
