# Демонстрационная среда коллекции «Графит»

Демо нужна, чтобы **посмотреть и потрогать** витрину, примерку, получение, инвентарь и вид за столом без оплаты. Платежей в проекте нет:
предметы «выдаются для демонстрации», цены на экране — демонстрационные (79 / 99 / 199 / 249 Stars), кнопок «Купить» нет.

> **Не включайте демосреду на рабочем сервере.** Там она обязана быть выключена: иначе любой участник получит предметы бесплатно.

## Как включить (только на своём компьютере / тестовом боте)

1. В `.env` тестового бота добавьте строку `COLLECTIONS_DEMO=1` (в образце `.env.example` она закомментирована). Токен бота никуда не копируйте и не показывайте.
2. Перезапустите бота (`npm run bot` или `npm run go`).
3. Значение читается **один раз при запуске** и только как ровно `1`. `true`, `yes`, `1 ` с пробелом и всё остальное — это «выключено».
   Включить демо нельзя ни сообщением со страницы, ни правами администратора, ни записью в базе.

## Что включается

* В «Настройках» появляется строка «Коллекции» с подписью «Демонстрация · Без оплаты».
* Витрина «Графит» (рубашка, стол, рамка и знак, комплект), карточки, примерка (в ней — «Так видят друзья»), «Получить для демонстрации», экран «Получено», инвентарь.
* Применённый вид (рубашка у места, стол хоста, рамка и знак в лобби и итогах) действует **со следующей раздачи**; в начатой раздаче вид не меняется.
* Вид — только оформление: ходы, часы, рейтинг и шансы от него не зависят.

## Чем отличается от рабочего режима (демо выключено)

| | Демо включена | Рабочий режим |
|---|---|---|
| Строка «Коллекции» в «Настройках» | есть | нет, адреса `#collections` ничего не открывают |
| Запрос `grant` (получить) | выполняется | отклоняется (`COL_DEMO_OFF`) |
| Остальные запросы коллекций | работают | отклоняются (`COL_OFF`) |
| Вкладка «Магазин» | «скоро» и счётчик нажатий (решение 106) | то же — не менялась |
| Демо-строки в базе | действуют | **игнорируются** (база могла быть скопирована из демо) |

## Как убедиться, что демо выключена

* В «Настройках» нет строки «Коллекции».
* `git grep COLLECTIONS_DEMO` — в коде переменная читается ровно в одном месте (`bot/index.js`), в `.env.example` закомментирована.
* На сервере: `grep -c '^COLLECTIONS_DEMO=1' .env` должно дать `0` (значение не печатайте и `.env` целиком не открывайте).
* Проверки: `node --test bot/collections.test.js` (выключено → `COL_DEMO_OFF`, строки в базе игнорируются), «на зубы» — `node tools/graphit-server-teeth.mjs`.

## Что не проверено

Всё это проверено на заглушке Telegram в Chromium, а не в живом Telegram: вид на телефоне, рамка и малая рубашка на узких экранах — смотреть руками.
Картинки пока генерируются (`tools/build-graphit-art.mjs`), это не окончательный арт.
