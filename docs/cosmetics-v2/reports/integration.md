# C — права, слоты и публичное оформление семи игр

Статус **done: локальное задание C выполнено**. Attempt
`2193dc78-bab0-422e-a0bd-12457c01a75d`. Исходный коммит `fb60273`, ветка
`redesign`, дерево при старте чистое. Версия результата — коммит этого отчёта
(контроллер проверяет именно его); приложение package.json **1.0.0**.
Система: **macOS 26.6.2 (25G83), arm64; Node 24.12.0, npm 11.6.2;
Chromium 153.0.8010.12, Playwright 1.63.0**. Все HTTP/WS и данные — локальные,
Telegram и платёжный API — только заглушки. Живые телефоны этим не проверены.

## Реализовано

- Общий runtime-каталог: прежние четыре id Графита + **54 самостоятельных
  предмета и 6 комплектов** шести коллекций B. Метаданные/состав/пути буквально
  сравниваются с manifest B; readiness=integrated, новые price=null. Арт B,
  source.approved=false, старые одобренные SVG Графита не изменены.
- Девять независимых новых/расширенных слотов и прежний парный profile Графита.
  Карточные рубашки — по месту в покере; table — общий для покера/дурака;
  frame/badge — свои у каждого во всех семи играх; доски/панель четырёх дуэлей
  и закрытая стопка UNOQ — выбор хоста. У дурака персональная рубашка не обещана.
- Публичный look v2 содержит только разрешённые item/color, seat и номер партии:
  table/backs/board/deckBack; frame/badge в players/score/results. Никаких owned,
  источников, заказов, Telegram id, произвольных URL, чужих карт, флота или ходов
  другого человека. Внутренний исходный hostId snapshot не публикуется.
- Лобби живое; начало партии (в морском бое — уже расстановка) замораживает вид.
  Для покера номер handNo, для остальных gameNo. Выбор во время игры откладывается;
  смена/уход хоста, ход, reconnect/reload и restart не перекрашивают начатую партию.
  Со следующей партии берётся тема нового хоста. Отзыв последнего источника
  удаляет украшение из frozen-снимка; независимый источник сохраняет его.
- Проверенный ADMINS даёт отдельный вычисляемый **owner** для 54 новых вещей,
  даже при off; он не записывается как purchase/admin/demo. COSMETICS_TESTERS,
  хостство, тело запроса и публичная видимость такого права не дают. Прежний
  staff Графита не расширен на новые вещи. Примерка не выдаёт права.
- apply/clear проверяют подписанную личность, предмет, слот, цвет, право и
  поддерживаемую игру. Личный выбор нехоста разрешён для его будущего стола;
  look текущей комнаты всё равно берётся только от хоста. Адресные room/code
  в личной операции отклоняются COL_OP, изменить чужой стол этим путём нельзя.
  apply-bundle проверяет все девять прав до записи и применяет состав/req одной
  SQLite-транзакцией; авария записи откатывает и выбор, и маркер повтора.
- Витрина/примерка/свои вещи доступны при закрытых продажах. SELLABLE теперь
  явный whitelist только четырёх товаров Графита: новые null не становятся
  тестовой ценой 1 Star. **60/60 новых позиций** не создают счёт/заказ даже при
  открытом тестовом gate на заглушке. `offers.json` и рабочие overrides не менялись:
  утверждённые цены Графита **75/50/100/175**. Исторические demo-цены каталога
  по-прежнему не являются реальной ценой. Продажи и рейтинг не открывались.
- На клиенте src разрешается только из каталога; игровые файлы отдельно от
  подробных lazy preview. Ошибка SVG запоминается, слой удаляется/карта становится
  классической без цикла повторных загрузок; декор не перехватывает нажатия.
  Доски/координаты/фигуры/цвета открытых карт/хитбоксы прежние. Внешняя рамка
  сверху/снизу обрезана возле строк игроков и часов; центральный бар нард также
  не перекрывает игровые знаки. Новых UI-токенов/внешних доменов нет.
- Собственный профиль обновляет frame/badge по серверному appearance сразу
  после ack. Снятие frame не возвращает неожиданно старый Graphit profile:
  явный base-frame/base-badge хранится отдельно; profile сохранён для rollback.
  Повторное применение прежнего profile атомарно включает его пару обратно.
- v1-запросы Графита сохранены, v1-live snapshot не пересобирается до следующей
  партии. Старый сервер не получает новые apply/grant/clear/apply-bundle от
  клиента v2; версия доступна D в snapshot().v. Неизвестные id/слоты/версии
  отображаются классикой и не удаляются из хранения.

Код C дополнен минимальным показом новых descriptors/preview/слотов в прежних
экранах, чтобы каталог не создавал пустые карточки. **Полный новый магазин D
не объявляется готовым:** нижняя вкладка, Каталог/Мои вещи, фильтры, выбор игры
в примерке и путь возврата к столу — его отдельное задание. Договор и API для D
дополнены в contracts.md; утверждённые 00-plan/01-design/04-integration не менялись.

В браузерном тесте только первая серия партии приходит с настоящего сервера;
остальные пять игровых вариантов дополнительно подставляются **локальными
синтетическими view** в те же реальные игровые рендеры, не выдавая права и не
меняя комнату. В лобби все шесть комплектов также применяются через сервер.
Это честно отделяет проверку всех 54 файлов/вёрстки от проверок полномочий.
После локальной сцены reload возвращает исходный frozen look сервера.

Поломки: динамический SELLABLE, бесплатный owner всем, личность из тела,
обход owns/slot/color, неполный bundle, отсутствие транзакции, пересборка
frozen, неверный номер партии, удаление unknown, spread внутреннего look,
пересборка v1, потеря явной classic, снятие независимых слотов через clear profile и обход asset-slot. Сценарий проверяет
настоящий AssertionError, а не принимает произвольный crash. Контроль зелёный.

SQLite-тест сравнивает строки, включая shop_offer/refund/log/req; новый DDL
не нужен. После осмысленного dropUnowned удаляется только известный profile
демонстрации без активного права; все строки источников/покупок неизменны. Перед readonly `.backup` только временная фикстура checkpoint-ится в
DELETE: системный sqlite3 на Mac не может первым создать WAL-sidecars при
read-only открытии закрытой node:sqlite базы. Старый runtime показывает классику
для v2 snapshot, права не стирает. На rollback нельзя запускать старый cleanup
возвратов над неизвестными слотами — это прежнее ограничение контракта A.

## Ограничения и передача

Нет субагентов/запускаторов, push/PR, reset/clean/stash, SSH/deploy/сервера,
реальных счетов/оплат/возвратов, открытия продаж/рейтинга. `.env`/секреты не
читались; server/public/deploy/контроллер и его тест не редактировались.
Работа предыдущих этапов сохранена; архивный визуальный слой A не возвращён.

Новое одобрение арта остаётся решением владельца, не присвоено по старому
одобрению SVG Графита. Живой Telegram/iOS/Android, реальные сети/телефонные
safe-area, пальцевые жесты, production/кэш конкретного устройства **не проверены**.
Владелец после разрешённой будущей выкатки переоткрывает Mini App и сверяет
двумя телефонами/зрителем семь игр, смену темы между партиями, рамки/значки,
рубашки и читаемость краёв. Это не разрешение на выкатку или продажи.

Блокеров локального C нет. Далее контроллер проверяет точный коммит и пушит
только redesign; **D реализует новый магазин**, затем E проводит независимую
приёмку всего пакета и телефонный остаток. Новый магазин/полный e2e всего
пакета/общий performance-бюджет E этим отчётом не подменяются.
