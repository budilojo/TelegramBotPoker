## Реализация

- Нижняя панель сохраняет четыре раздела. «Магазин» открывает настоящий каталог
  при закрытых продажах; внутри остаётся панель с активным «Магазином».
  Покупки/примерка/применение не требуют заходить в настройки. Прежний вход
  «Коллекции» в настройках также работает. Для старого сервера без магазина
  сохранён честный fallback, неизвестные права показывают загрузку/повтор.
- Один общий каталог A–C: **64 позиции** — три предмета и комплект Графита,
  54 новых предмета и шесть комплектов. Фильтры игры, категории и коллекции;
  категории Карты/Столы/Доски/Профиль/Комплекты, неподходящие пустые варианты
  не предлагаются. Состояние фильтров, позиция списка и фокус карточки
  восстанавливаются при возврате. Число результатов не использует атрибут часов.
- «Мои вещи» показывает текущие слоты, только свои предметы и бесплатную классику,
  фильтр игры, источники права и разделение личного вида/общей темы хоста.
  Можно сочетать коллекции. «Надеть», «Снять», смена цвета, атомарное
  «Надеть комплект» используют существующий серверный контракт. После ack —
  «Надето»/«Комплект надет», до него — ожидание; ошибки и offline не дают успеха.
  Снятие одного слота не стирает остальные, парный профиль Графита учитывается.
- У владельца явно написано «Доступ владельца · новые вещи бесплатно» и
  «Доступ владельца · бесплатно». Покупка/подарок/демо/служебный доступ названы
  отдельно; источники не меняются. Посетитель при off может смотреть/примерять,
  но не надевать не принадлежащее и не создавать счёт.
- Крупная примерка с выбором поддерживаемой игры: профиль с аватаром/значком,
  шахматы с 32 фигурами, шашки с простыми/дамкой, нарды с шашками/кубиками,
  два образца полей морского боя, стол с лицевыми картами, рубашка UNOQ рядом
  с неизменной открытой картой. **Это подписанные статические вымышленные
  образцы**, они не импортируют net/состояние текущей комнаты и ничего не шлют.
  Графит и его четыре цвета сохранили прежние образцы; добавлен выбор игры.
- Подробный SVG грузится по открытию карточки/примерки, маленькая витрина
  использует game-ресурс с lazy loading. Ошибка запоминается: нейтральная
  миниатюра, а на доске/аватаре остаётся классика без лишней метки поверх фигур.
  Повторной загрузки неисправного файла после перерисовки нет.
- Во всех семи меню есть «Магазин и мои вещи». «Вернуться к столу» доступно на
  каждом слое, включая карточку/примерку/ошибку, и из хаба с текущим столом.
  Открытие не посылает hub/stand/leave, часы продолжают идти. Выбор посреди
  партии честно сообщает «Применится со следующей партии»; текущий frozen-look
  не меняется. Обновление списка хаба обновляет и кнопку возврата. Фокус после
  закрытия возвращается на новый экземпляр кнопки меню/навигации.
- Telegram Back/Escape снимают по одному слою. Старые `?collections=1`,
  `#collections`, `#/collections/showcase`, `#collections/item/<id>`, fit/inventory
  и прежние программные входы ведут в этот магазин. Смена hash в уже открытом
  приложении также работает. URL с demo/admin/owned не выдаёт прав.
- История, документы, согласие до покупки и поддержка через бота используют
  прежний flow. Покупка Графита проверена от нижней вкладки только на заглушке;
  скрытый владельцем товар не покупается через старый item-вход или pay.buy.
  Новые price=null, продажи/рейтинг не открывались. MESSAGES обновлён.

## Матрица экранов

| Экран/путь | Что проверено локально |
|---|---|
| Каталог | 64 позиции, все игры/коллекции/категории, off и владелец, фильтры, scroll/focus |
| Карточка | крупный art, игры, цена не утверждена, источник, надеть/снять/комплект |
| Примерка | выбор игры; личный/общий образец семи игр; ноль запросов и выдач |
| Мои вещи | выбранные независимые слоты, классика, только owned, фильтр игры, сочетания |
| Ожидание/ошибка/offline | сохранён предыдущий выбор, повтор/отмена, реальный reconnect |
| Пусто/длинное имя/SVG | пустой инвентарь, перенос названия, fallback без цикла загрузки |
| Покупки/документы/поддержка | прежние суммы/условия/подтверждение; нижняя вкладка; скрытый товар |
| Меню → магазин → стол | семь игр × 320/390, личная рамка + общий слот, frozen/pending/место/часы/фокус |

Новые native select имеют подписи; кнопки — имена и фокус, фильтры доступны
клавиатурой. Состояния подписаны словами, не одним цветом. Проверяются ширины
**320×568 и 390×844**, hit targets ≥44×44, отсутствие горизонтального выхода,
кегли/радиусы из шкалы, отсутствие градиентов/теней, reduced motion. Это
проверка DOM/Chromium; VoiceOver/TalkBack и реальная телефонная клавиатура не
заменяются автоматическими проверками.

Изменение магазина не требует миграции или удаления старых данных.

Ранние красные результаты не скрываются как external:

- sandbox запретил listen localhost (EPERM); разрешённый локальный запуск прошёл;
- ранняя правка одноразового скрипта обновления тестов остановилась на
  `s.index` вместо `indexOf` до записи; исправлена, чужие файлы не потеряны;
- старый браузерный стенд подменял только ответы на запросы, а initial col уже
  приходит до state: v1-фикстура исправлена также для первого пакета;
- новый тест источников поймал `__proto__` как `[object Object]`: заменён lookup
  на Map, ассерты не ослаблены;
- переход hash внутри открытого приложения не открывал новый item: добавлен
  обработчик, свежая ссылка с URL-подменами тоже проверяется;
- полный npm test сначала 1610/1611: старый исходниковый тест запрещал любой
  URL в оболочке. Теперь разрешён только маршрутизатор index; запреты URL в
  state/экранах и запреты storage/initDataUnsafe сохранены, дополнительно
  браузер проверяет отсутствие прав из demo/admin/owned в URL;
- первая шестая поломка счётчика дала timeout отсутствующего селектора вместо
  AssertionError: добавлен точный assert наличия атрибута; повторные поломки
  действительно ловят assert. Проверка поломок никогда не принимает crash за успех.

Субагенты/запускаторы агентов, сервер/SSH/deploy, реальные деньги/счета/возвраты,
.env/секреты, открытие продаж/рейтинга, push/PR/reset/clean/stash не использовались.
