# Пакет косметики v2 — подготовка 31.10.2026

Запрос владельца: убрать устаревшую косметику со скриншота IMG_4367.PNG, добавить
много вариантов для всех режимов, показывать выбранное оформление соперникам,
перенести покупку в понятный магазин нижней панели и упростить применение.
Это пакет для исполнения Codex, а не отчёт о готовой реализации.

## Запуск

Из корня этой рабочей копии: `caffeinate -i node tools/cosmetics-run.mjs`.
Проверка без запуска: `node tools/cosmetics-run.mjs --dry-run`.
Статус: `node tools/cosmetics-run.mjs --status`.
Повтор той же команды продолжает сохранённый этап; лимит/ошибку изучить в
`.release-run/cosmetics-v2/`, не удалять lock при живом процессе.
Старый tools/codex-release-run.mjs запускает прежний релиз I–M; для этой задачи
он не подходит. Два запускатора делят lock и не работают одновременно.
Оба требуют ветку redesign, чистое дерево и обычный push после полного npm test.
Состояние I–M не сбрасывается. Текущий запуск не делает выкатку на сервер.

## Факты и границы

Скриншот: базовое зелёное сукно, рубашки с красно-белой эмблемой, круговая рамка
профиля и подпись «КРУПЬЕ». Он доказывает видимый результат на телефоне, но не
причину: возможны старый косметический путь, выбор из базы, снимок раздачи,
необновлённая страница. Не объявлять весь зелёный стол и стандартные аватары
устаревшими и не удалять базовое оформление ради удаления косметики.
Новый арт «Графита» и его права сохраняются. Арт одобрен владельцем в чате;
это решение не одобряет автоматически новые коллекции. Состояние production
не выяснять через SSH в рамках пакета. Если нужна внешняя проверка версии,
записать конкретный безопасный шаг владельцу.

Продажи и рейтинг закрыты; реальные операции запрещены. Публичная витрина,
примерка и свои вещи доступны при off, кнопка реальной покупки заблокирована
с понятной причиной. off не выдаёт платные вещи. Владелец сохраняет отдельный
бесплатный доступ ко всему новому ассортименту: только проверенный owner/admin
из серверной конфигурации, никаких прав по id из браузера. Подарок, покупка,
доступ владельца учитываются отдельно. Цена новых вещей не назначается.
Права и покупки не стирать и не превращать старые покупки в другой товар молча.

«Видно всем» = публичное оформление в состоянии партии для соперников/зрителей,
не бесплатное владение для всех. Примерка локальная, видна только примеряющему.
Карты, флот, законные ходы и платёжные данные не раскрываются через оформление.

сессию памяти и коммит после npm test. Цепь не считает незавершённый код partial.
После красного теста — остановка до исправления, не переход дальше.

## Приёмка

Шесть коллекций, целевой ассортимент 54 самостоятельных предмета + 6 комплектов
(варианты цвета не считаются отдельным предметом). Поддержаны все семь игр,
конкретные слоты и видимость — 01-design.md. Предметы реально отображаются,
совпадают с превью, сохраняют права/reconnect и читаемость игрового содержания.
Нельзя выполнить план одними записями в каталоге или картинками в отчёте.
Если слот нельзя реализовать без изменения правил, обосновать блокер, не менять
механику и не заявлять полный ассортимент готовым.

E самостоятельно запускает npm test, полный e2e, layout, kit, contrast, colors,
preview; смотрит картинки 320×568 и 390 px; проверяет права, старые данные,
источники прав, возвраты на заглушке, снимки раздачи, часы и приватность всего
потока двух игроков и зрителя. Измеряет размер арта и загрузку до/после, lazy
loading и отсутствие фоновых циклов/лишних подписок. Тестовый SQLite backup и
откат без потери покупок обязательны при изменении хранения.
Финал: перечень предметов/игр, причина старого вида, снимки до/после, результаты
команд, внешние ограничения и один список решений владельца. Никакой выкатки.
