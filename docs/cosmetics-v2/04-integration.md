# C — права, каталог и отображение

Реализуй A contracts + B assets + 01-design во всех семи играх. Общие файлы
app/hub/store, коллекции и профиль сейчас принадлежат тебе. Минимально расширь
существующий контракт, журнал заказов и источники права сохраняются.
Новые 54 предмета/6 комплектов имеют price=null, не попадают в продаваемые
предложения до утверждения. Графит по прежним id и ценам; не переписывай живые
overrides БД. Публичная витрина и локальная примерка отделены от покупки.

Владелец имеет отдельный бесплатный доступ; обычный игрок не получает новых прав.
Сервер проверяет каждое надевание/снятие/комплект, роль хоста, слот/игру, права,
подписанного пользователя. Предпросмотр не меняет чужой вид. Клиент не выбирает
чужого владельца. Публичный look не содержит историю покупок, Telegram id,
закрытые карты, флот и законные ходы другого человека.
Тема общего стола/доски от хоста по спецификации, freeze на партию/раздачу,
объявление отложенного применения, сохранение после restart/reconnect. Личные
рамка и значок не выдаются всем от хоста. Ошибка asset — читаемая классика.
Не обещай публичную рубашку в игре, чей вид закрытых карт этого не поддерживает.

Пройдись по 7 клиентским экранам: preview соответствует реальной игре. Правила
игр и server/game.js не менять. Старые сохранения/id загружаются, неизвестное
оформление не роняет игру. Отзыв одного источника права не снимает независимый.
При изменении хранения проверь backup, старый код, возврат новой версии.
Новый слот не должен переиспользовать id чужого слота или молча пересчитать цены.

Тесты: два игрока/зритель и весь поток для семи игр; forged equip, unowned,
unsupported, host смена/уход, frozen look, повтор действия, restart, fallback,
partial комплект. Защиты временно сломать и вернуть; профильный e2e и npm test.
