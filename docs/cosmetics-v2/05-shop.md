# D — магазин и установка

Реализуй UX из 01-design.md в нижней вкладке «Магазин». Изучи nav/app/hub,
нынешние collections и платёжный flow. Работай поверх A–C, без второго каталога.
Полный каталог/фильтры, «Мои вещи», крупная примерка по игре, надеть/снять,
причина применения позже и комплект. Покупка не требует входить в настройки.
Старые deep links ведут на корректный новый экран, не на пустую страницу.
Владельцу понятен его бесплатный доступ; посетитель не получает платные права.

Off закрывает реальные покупки, не скрывает публичные preview и инвентарь.
При тестовой оплате используй только существующие временные fixtures и заглушку.
Ни новый price, ни удаление незаполненных документов/ослабление gate не разрешены.
Рейтинг «скоро», место и часы сохраняются при просмотре магазина и возврате.
Предметы, скрытые владельцем, не должны продаваться старым deep link.

Надевание подтверждает сервер, ошибка/нет сети не показывает ложный успех;
фильтры/скролл сохраняются, Telegram Back закрывает верхний слой предсказуемо.
32/44 px различать: текст/миниатюры могут быть малыми, hit target минимум 44.
Проверь 320×568/390, клавиатуру, длинные названия, screen-reader names, фокус,
reduced motion, загрузку/пусто/ошибку asset. UI на токенах, тексты в MESSAGES.

Профильный e2e от нижней панели до предмета/примерки/надевания/снятия/возврата
в стол; личный и хостовый вид минимум в 7 играх. layout/kit/contrast/colors,
preview с визуальным просмотром и npm test. Матрица реализованных экранов,
до/после, внешний чек-лист телефона и оставшиеся owner/external в отчёте.
