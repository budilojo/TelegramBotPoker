# Волна 5 (2026-10-27): косметика «Ночной казино-клуб» — каталог, примерочная и «ложная дверь»

Составлено по ответам владельца на предложения волны 4 (`docs/monetization.md`, `docs/rating-bank.md`): косметика
должна быть такой, чтобы её **хотелось купить**; первая тема — **«Ночной казино-клуб»**; плоскость для платного арта
смягчена (`docs/brain/decisions/096`). Общие правила и память проекта — `docs/next-wave/00-plan.md`; папки агентов и
пуш — `docs/next-wave-2/00-plan.md`, п. 6. **Одна буква — одно окно** (`tools/wave5-launch.sh` откажется открыть второе).

## Что делаем и чего НЕ делаем

**Делаем (без денег):** набор из 10 вещей одной темы; **примерочная** («Посмотреть за столом» — вещь применяется на
вашем телефоне, как будет выглядеть); **«ложная дверь»:** экран «Магазин» с ценами в Stars, кнопкой «Хочу» и
счётчиками нажатий, **без оплаты**; цены в двух вариантах (A/B) для проверки спроса; админка видит только суммы.
**Не делаем:** платежи, счета, `sendInvoice`, покупки, подарки, подписку, «Клуб группы», рейтинг и банк (владелец
по ним ещё не ответил — раздел «Вопросы» в `docs/rating-bank.md` §6 и `docs/monetization.md` §7). Вещи других игроков
пока не показываются: примерка — только на своём телефоне.

## Контракт (L ↔ M)

**Вещь каталога** (`miniapp/cosmetics/catalog.js`, владелец L; **L пушит первым** — M читает):

```js
{ id: 'nc-back-1', set: 'night-casino', kind: 'cardback' | 'felt' | 'frame' | 'reaction' | 'effect' | 'title' | 'bundle',
  title: 'Чёрный бархат', blurb: 'Тёмная рубашка с неоновой каймой',
  file: '/cosmetics/night-casino/back-1.png',   // нет файла — берётся заглушка из placeholder/
  tokens: { felt: '#4a0f1f' },                  // для felt: цвет заливки; для остальных не нужен
  stars: { a: 50, b: 100 },                     // два варианта цены для проверки спроса
  free: false }                                 // true — выдаётся за ранг, не продаётся (в этой волне нет таких)
```
`id` — латиница, дефисы, как в таблице выше; **не переименовывать** (на них будут ссылаться покупки). Новые вещи
добавляются в каталог строкой; экраны и вид стола ничего не знают о конкретных вещах.

**Вид** (`miniapp/cosmetics/look.js`, владелец M): `getLook() → { cardback, felt, frame, effect, title }` (id вещей
или `null`), `setLook(patch)`, `clearLook()`, `onLook(fn)`, `previewFor(item)` — применить вещь на 10 секунд и
вернуть, `lookClass()` — служебное для CSS. Хранится в `localStorage` (с try/catch), **только на этом телефоне**; на
сервер не уходит; другим игрокам не показывается. Шлёт `onLook`, экраны перерисовывают точечно (без прыжков,
`docs/scroll.md`).

**Примерка:** кнопка «Примерить» в карточке вещи (L) вызывает `look.setLook({ [kind]: id })` и открывает **стол-образец**
(экран примерочной, M даёт `renderFitting(container)`: настоящий покерный стол с тремя игроками без сервера, с картами,
банком, борд; рубашка, сукно, рамка и эффект применены) — игрок видит вещь «как будет за столом». Кнопка «Снять» —
`clearLook()`. Живой стол во время партии тоже следует `getLook()` (чтобы игрок мог проверить на настоящем столе), но
только у себя.

**Спрос:** сообщения страницы `{ t:'shop', op:'interest', item, action:'view'|'want', variant:'a'|'b' }` (L): личность
из `initData`; известные `item` из каталога (серверный белый список), `variant`, `action`; частота (`app.clock.now()`);
хранится в новой таблице (без смены версии схемы); игрок видит **только своё** «Вы нажали „Хочу“»; админка — только
суммы по вещи и варианту без имён. Оценка «сколько нужно»: см. `docs/monetization.md` §4.

## Порядок

1. **L** — первым пушем каталог (`catalog.js` + заглушки в `placeholder/`) и таблица/сообщения спроса; **M** — первым
   пушем `look.js` с API (пусть пока без применения).
2. Дальше параллельно: L делает экраны магазина, M — применение вида и эффект победы. Согласуйте точки подключения
   через `ListAgents`/`SendMessage`.
3. Когда у владельца будут настоящие картинки — `подключить косметику` (одна команда агенту L или M): файлы кладутся
   в `miniapp/cosmetics/night-casino/` под именами из таблицы, проверяется вес и размер, заглушки не используются.

## Проверки и «не проверить без Telegram»

`npm test`, `npm run e2e`, `layout`, `kit`, `contrast` (для экранов магазина; арт набора исключён по решению 096),
`preview` — смотреть глазами на 320 и 390 px. Не проверить без телефона: как выглядят рубашки и эффект в WebView,
плавность анимации на слабых телефонах, нажатия пальцем. Chromium с эмуляцией — не WebView.
