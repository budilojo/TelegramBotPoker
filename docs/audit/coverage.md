## C. Приватность (фаза 2)

Метод — **невмешательство** (`tools/fuzz-privacy.mjs`, короткий прогон в
`bot/audit.privacy.test.js`): партии целиком через хаб, за столом только
боты (ходят по своему виду). На каждой перерисовке, для каждого игрока и
зрителя, копия стола с перемешанным скрытым обязана дать побайтно тот же
вид. Тем же проверяются карточка в группе, строка хаба, личное «ваш ход»
и итоги.

| Игра | Что перемешивается (скрыто от смотрящего) |
|---|---|
| покер | чужие карманные (кроме вскрытых), вся колода, неоткрытая часть борда; во время вскрытия по улице — названия, сила и «лучшие пять» рук, борд в истории; руки и колода в снимках отмены |
| дурак | чужие руки, колода (кроме козыря под ней), сброс |
| UNOQ | чужие руки, колода, сброс под верхней картой (и «только что взятая» у ходящего) |
| морской бой | у соперника (у зрителя — у обоих) корабль без попаданий переставляется на другое законное место, не задевающее ни одного выстрела |
| шахматы, шашки, нарды | скрытого нет: подсказки ходов — только ходящему (`legal`), будущие кубики не хранятся (бросок — в момент `roll`) |

Проверка фаззера «на зубы» — пять внесённых утечек, каждая поймана во всех
прогонах: длина колоды дурака по первой карте; «кнопка» покера по чужой
карте; весь борд во время вскрытия (поймано после включения вскрытия по
улице в фаззере — до этого фаззер был слеп к нему); длина колоды UNOQ по
цвету верхней карты; «осталось кораблей» по координате чужого корабля.

Отдельный тест C-01 (олл-ин, кончающий игру) — **находка, исправлена**.

Каналы, проверенные чтением: тексты отказов не различают «чужая карта» и
«нет карты» (дурак, UNOQ проверяют только свою руку; морской бой отказывает
лишь по своим выстрелам и известной пустоте вокруг потопленных); пульт и
админ-бот — без имён (существующие тесты); логи ошибок — без карт и
`initData`; шеринг — только игроку и только по итогам.

Объём длинного прогона — в фазе 7 (итог).

## D. Правила и целостность (фаза 3)

**Фаззер через хаб** — `tools/fuzz-games.mjs` (все 7 игр). Шаг — одно из:
законный ход того, кого ждёт игра (решение бота по его виду; в шахматах и
шашках — случайный ход из `legal`), «правдоподобный» ход (свои настоящие
карты, верный `seq`/`ply`, но случайные цели и клетки — проходит входные
проверки и упирается в сами правила), враждебный мусор (любой тип, `NaN`,
`Infinity`, отрицательные, дробные, строки, массивы, `__proto__`, чужие
поля «кто»), событие среды (часы до 5 минут вперёд, перезапуск через
сохранение, обслуживание вкл/выкл, выход из группы, переподключение,
действия хоста: пауза, отмена, передача, удаление, докупка, настройки,
«завершить», новый стол). После **каждого** шага:

| Игра | Инварианты |
|---|---|
| все | вид каждого (игроки, зритель) строится; в виде, карточке и состоянии нет `NaN`, `Infinity`, «undefined», «[object Object]»; вид после «сохранить → поднять» тот же (кроме часов и окна «UNOQ!», которое перезапуск закрывает по замыслу); в логе нет исключений |
| покер | стеки + банк = всё купленное (докупки учтены); стеки целые и ≥ 0; олл-ин без фишек; ни одна карта не в двух местах; борд ≤ 5 |
| дурак | ровно 36 разных карт (руки + колода + сброс + стол); не ходит на себя; ≤ 6 на столе; каждая побитая карта действительно бьёт |
| UNOQ | состав всех карт = свежая колода 108 |
| шахматы | по одному королю; пешек на крайних нет; сходивший не под шахом; **повтор всех ходов с начала** генератором доски сходится с позицией |
| шашки | только тёмные поля; ≤ 12 у каждого; простая на последней горизонтали не остаётся; **повтор всех ходов** сходится |
| нарды | по 15 шашек у каждого (доска + снятые); целые; кубики 1…6 |
| морской бой | флот законен по правилам расстановки; в одну клетку не стреляют дважды |

Проверка фаззера «на зубы»: докупка без учёта (`stats.buyIn`) — поймано;
дурак принимает небьющую карту — поймано; шахматы принимают незаконный ход —
поймано. **Первые версии фаззера оба первых мутанта пропускали** (враждебные
ходы отсекались устаревшим `seq` до правил) — после добавления
«правдоподобных» ходов ловятся.

**Оценка рук покера** — `bot/audit.eval.test.js`: независимый эталон
(оценка семи карт сразу, без перебора пятёрок) против `eval.js`; совпадают
категория, решающие ранги, победители и дележ. Каверзные доски (колесо,
стрит-флеш колесом, два сета, три пары, флеш и стрит сразу, борд играет,
каре с тройкой на борде). Порча колеса в `eval.js` ловится.

**Случайность** — `bot/audit.dice.test.js`: хи-квадрат по 36 парам кубиков
нард (360 тыс. бросков) и по первой карте тасовок покера, дурака и UNOQ (по
60 тыс.). Все колоды и кубики — `crypto.randomInt`; `Math.random` только в
жребии цвета дуэлей и паузах ботов (там нет секрета). Кубик, дающий шестёрку
на 2 % чаще, ловится (хи-квадрат 750 при пороге 90).

**Рейтинг** — существующие `rating.test.js` (повтор партии, предел на
состав, перезапуск, месяц, группа) + `bot/audit.rating.test.js`: три вопроса
замысла (D-02…D-04).

**Повторное «завершить»** — находка D-01, исправлена (`bot/audit.finish.test.js`).

Объёмы длинных прогонов — в итоге (фаза 7).
