# Покерный стол в Telegram Mini App — проект UX

Главное правило: **открыв стол, игрок за 2 секунды понимает состояние
партии** — свои карты, борд, чей ход, сколько коллировать, банк, стадию.
Ничего не нужно искать в переписке.

---

## 0. Архитектура взаимодействия

```
 Telegram-группа                     Бот (один процесс Node)                Mini App (у каждого)
 ─────────────────                   ───────────────────────                ───────────────────
 /newgame  ───────────────────────▶  создаёт комнату, код a7k2m9qx
 ◀── карточка комнаты ──────────────  «♠️ Покерная комната · 3/8»
     [🃏 Открыть стол] ────────────────────────────────────────────────▶   открывается сразу
                                                                           на нужной комнате
                                     HTTP: отдаёт сам Mini App
                                     WebSocket: ◀──── initData (подпись Telegram) ────
                                                 ────── состояние стола ──────────▶
                                                 ◀───── действия (FOLD/CALL…) ─────
 ◀── карточка правится ─────────────  «Раздача #5 · флоп · ход: Макс»
 личка: «👉 Ваш ход» ◀──────────────  только тому, у кого стол сейчас закрыт
 ◀── итоги вечера ──────────────────  одно сообщение в конце игры
```

**Где живёт правда.** Один процесс: grammY (long polling) + HTTP-сервер для
Mini App + WebSocket. Комнаты в памяти, копия в SQLite. Движок ставок
`server/game.js` и слой карт `bot/cards.js` не меняются: Mini App — это новый
способ смотреть и нажимать, а не новый покер.

**Ограничения Telegram, которые определили схему** (проверены):

| Ограничение | Что из этого следует |
|---|---|
| Кнопка `web_app` работает **только в личке** | в группе — обычная URL-кнопка на прямую ссылку `t.me/<бот>/<приложение>?startapp=<код комнаты>`; её надо один раз зарегистрировать у @BotFather (`/newapp`) |
| `startapp` → приходит в приложение как `start_param` **внутри подписанного `initData`** | код комнаты не нужно вводить руками — ссылка открывает нужный стол |
| Mini App — это веб-страница, и Telegram открывает только **HTTPS** | нужен публичный HTTPS-адрес: туннель (cloudflared) на время тестов, хостинг — для постоянной игры |
| `initData` подписан токеном бота (HMAC-SHA256) | личность игрока в Mini App — это его настоящий Telegram id, подделать нельзя; правило «никто не ходит за другого» переезжает в приложение без изменений |
| Бот не может написать первым | уведомление «ваш ход» в личку возможно только тем, кто хоть раз нажал Start |

**Доступ к комнате = ссылка.** Кто получил ссылку (из группы или пересланную),
может открыть стол и сесть — как по коду комнаты в веб-версии. Код случайный,
не угадывается и не совпадает с id чата. Хост может удалить любого.

## 1. Сценарий от создания до конца

1. **Создание.** В группе `/newgame`. Бот отвечает карточкой:
   «♠️ Покерная комната · Игроков: 1/8 · Ожидание игроков» и кнопкой
   **🃏 Открыть стол**. Автор команды — хост.
2. **Сбор.** Каждый жмёт «Открыть стол» → Mini App открывается сразу на этой
   комнате → одна большая кнопка **«Сесть за стол»**. Карточка в группе
   обновляется: «Игроков: 3/8». Хост видит в приложении настройки: стек,
   блайнды, таймер хода, режим карт (бот раздаёт / настоящие карты и дилер).
3. **Старт.** Хост жмёт **«Начать игру»** (доступно от 2 игроков). У всех, у кого
   стол открыт, прямо на экране появляются свои две карты (анимация раздачи).
   Тому, кто ходит первым, — «ВАШ ХОД», подсветка, вибрация.
4. **Торговля.** Ходы — нижней панелью: FOLD / CHECK или CALL N / RAISE. Состояние
   стола обновляется у всех мгновенно. Карточка в группе показывает, чей ход,
   — для тех, кто стол не открыл.
5. **Ваш ход, а стол закрыт.** Бот пишет в личку «👉 Ваш ход · Раздача #5 ·
   колл 100» с кнопкой, которая открывает стол. Когда ход прошёл, это
   сообщение удаляется — в личке не копится мусор.
6. **Вскрытие.**
   - Бот раздаёт карты: вскрытие автоматическое. Карты победителей и
     олл-инов переворачиваются прямо на их местах, у победителя — «+1 240» и
     название комбинации. Олл-ин до ривера: борд открывается по улице.
   - Настоящие карты и дилер: у дилера открывается экран «Кто выиграл?».
7. **Следующая раздача.** Кнопка «Следующая раздача» у всех за столом, с
   таймером хода — сама через 10 секунд.
8. **Конец.** Хост → меню → «Завершить игру». У всех в приложении — экран итогов
   (P/L). В группу — одно сообщение с итогами вечера. Карточка комнаты:
   «Игра завершена».

## 2. Экраны Mini App

Во время игры экран **один** — стол. Всё остальное — выезжающие снизу листы
поверх стола, которые закрываются свайпом или кнопкой.

| Экран / лист | Когда | Что на нём |
|---|---|---|
| **Подключение** | первые доли секунды | логотип, «Подключаемся к столу…» |
| **Лобби** | до старта игры | название комнаты, игроки кружками по местам, «Сесть за стол» / «Встать»; хосту — настройки и «Начать игру» |
| **Стол** | вся игра | см. раздел 3 |
| лист **Рейз** | нажата RAISE/BET | быстрые суммы, слайдер, подтверждение |
| лист **Меню** | нажато ⋯ | встать из-за стола; хосту — докупка, роли, настройки, пауза, отмена, передать хоста, удалить игрока, завершить игру |
| лист **Кто выиграл?** | вскрытие в режиме дилера | крупные карточки игроков, банк за банком, итог, «Подтвердить» |
| **Итоги** | игра завершена | таблица P/L, статистика, пометки хост/дилер |
| **Ошибка** | неверная ссылка / открыто не из Telegram | одна фраза, что сделать |

## 3. UX игрового стола (телефон, портрет)

```
┌──────────────────────────────────────┐
│ FLOP   #12 · 25/50            ⏱ 0:42 ⋯│  ← стадия, раздача, блайнды, меню
├──────────────────────────────────────┤
│   ┌Макс──┐              ┌Дима──┐     │
│   │ 1 500│              │  860 │     │  ← соперники по кругу стола,
│   └FOLD──┘              └BET 100┘    │    по часовой стрелке от вас
│ ┌Саша──┐   ╭──────────────╮  ┌Артём┐ │
│ │ 2 100│   │   POT 340    │  │1 240│ │
│ └ХОД ◉─┘   │ [10♠][J♥][Q♣]│  └CALL┘ │  ← банк и борд в центре
│            │  [ — ][ — ]  │          │
│            ╰──────────────╯          │
├──────────────────────────────────────┤
│        ┌─────┐┌─────┐                │
│        │ A   ││ K   │   Иван 9 400   │  ← ВАШИ карты, крупно, всегда
│        │  ♠  ││  ♥  │   Старшая A    │
│        └─────┘└─────┘                │
│  ┌────────┐ ┌────────────┐ ┌───────┐ │
│  │  FOLD  │ │  CALL 100  │ │ RAISE │ │  ← 1 нажатие
│  └────────┘ └────────────┘ └───────┘ │
└──────────────────────────────────────┘
```

**Место игрока:** кружок с инициалом, имя, стек крупными цифрами, под ним
плашка статуса — одна, и она отвечает на вопрос «что с ним сейчас»:

| Плашка | Значение |
|---|---|
| `ХОД` + зелёное свечение + кольцо таймера | ходит сейчас |
| `BET 100` / `RAISE 300` / `CALL 100` | сколько поставил **на этой улице** |
| `CHECK` | прочекал на этой улице |
| `FOLD` | сбросил — место приглушено |
| `ALL-IN 2 100` | олл-ин — красная плашка |
| `SB 25` / `BB 50` | блайнд, ещё не ходил |
| `D` (круглая фишка) | баттон |
| две рубашки карт | ещё в раздаче |

**Центр:** `POT 340` крупно, под ним 5 мест для борда. Пустое место — пунктирная
рамка: сразу видно, сколько карт ещё выйдет. Новая карта переворачивается.

**Вы — внизу, крупно:** две карты картинками, имя, стек, **название вашей
комбинации** с учётом борда («Две пары, A и K»). Это не подсказка стратегии, а
то, что игрок и так видит, если смотрит на свои карты.

**Панель действий** — три большие кнопки, только доступные сейчас:
- перед вами ставка: `FOLD` · `CALL 100` · `RAISE`;
- ставки нет: `CHECK` · `BET` (FOLD скрыт: сбросить бесплатно — всегда ошибка,
  и это самое дорогое случайное нажатие на телефоне);
- колл — это весь ваш стек: `CALL 250 · ALL-IN`;
- повысить нельзя (короткий олл-ин закрыл торговлю или не хватает фишек) —
  RAISE нет.

**Рейз — 2 нажатия:** RAISE → лист с кнопками `+BB 100` · `½ POT 170` · `POT
340` · `ALL-IN 9 400`, **на каждой написана итоговая сумма**. Нажатие на сумму
сразу делает ход. ALL-IN — единственный с подтверждением («Точно весь стек?»):
случайный тап не должен стоить стека. Ниже — слайдер и «RAISE ДО 520» для
своей суммы.

**Ваш ход — сразу несколько сигналов:** зелёная рамка вокруг ваших карт,
надпись «ВАШ ХОД» с таймером, панель из серой становится яркой, лёгкая
пульсация, вибрация телефона (Telegram Haptic). Не ваш ход — панель серая, на
ней «Ход: Макс · 0:31».

## 4. UX дилера

**Режим дилера — это игра настоящими картами.** Дилер раздаёт колоду за
реальным столом, приложение ведёт только фишки, а победителя отмечает человек:
бот карт не знает. (Именно так было в самой первой версии и в веб-приложении.
Выбирать победителя вручную, когда карты раздаёт бот, смысла нет — бот и так
знает, чья рука сильнее.)

- Хост в лобби выбирает «Карты: 🤖 раздаёт бот / 🃏 настоящие» и в меню «Роли»
  назначает дилера. Дилер за столом не сидит и фишками не рискует. Дилер в
  комнате один: назначить другого — значит забрать роль у прежнего.
- Во время раздачи у дилера вместо своих карт — подсказка, что делать руками:
  «Раздайте по 2 карты» → «Выложите флоп» → «Тёрн» → «Ривер». Места борда
  показаны рубашками: видно, сколько карт должно лежать на столе.
- **Вскрытие:** у дилера сам открывается лист **«Кто выиграл?»**:
  - `MAIN POT · 1 200` — крупные карточки только тех, кто может претендовать
    на этот банк (сбросившие не показываются никогда);
  - можно отметить несколько — банк делится;
  - «Далее» → `SIDE POT 1 · 600` → … Банк, на который претендует один игрок,
    — это возврат, его дилер не выбирает;
  - **итоговый экран распределения** — суммы из `previewPayouts()` движка, той
    же функции, которая потом двигает фишки: превью не может разойтись с
    результатом;
  - «Подтвердить» — только после этого фишки двигаются. «Назад» — к любому
    банку. «Отменить результат» — до следующей раздачи.
- Остальные в это время видят «Дилер определяет победителя…» и банки.
- Дилера нет — победителя отмечает любой, кто сидит за столом.

## 5. Поведение Telegram-бота

Бот больше **не ведёт игру в чате**: никаких кнопок ставок и команд `/call`,
`/raise` в группе.

**В группе бот:**
- по `/newgame` публикует **карточку комнаты** и дальше только **правит** её
  (правка не звенит и не засоряет чат): игроки, статус, номер раздачи, стадия,
  чей ход, итог последней раздачи;
- публикует **итоги вечера** отдельным сообщением в конце игры;
- `/table` — заново выложить карточку вниз чата, если она уехала;
  `/finish`, `/cancel` — хосту, `/help`.

**В личке бот:**
- «👉 Ваш ход» — только если стол у вас сейчас **не открыт**, один раз за ход,
  с кнопкой, которая открывает стол; сообщение удаляется, когда ход прошёл;
- `/start` — разрешить уведомления.

## 6. Отображение карт

- **52 картинки** (SVG) + рубашка, в одном стиле: белая карта, крупный ранг в
  углах, большая масть в центре, красные ♥♦ и чёрные ♠♣. Генерируются
  скриптом `tools/make-cards.mjs` — стиль правится в одном месте для всех 52.
- Интерфейс собирает любую руку из этих 52 файлов: `AS.svg`, `KH.svg`,
  `10D.svg`, `2C.svg`, `back.svg`. SVG весят по 1–2 КБ, чёткие на любом экране;
  все 53 грузятся при открытии, до первой раздачи.
- **Размеры:** ваши карты — самые крупные; борд — средние; у соперников —
  маленькие рубашки (кто ещё в раздаче), на вскрытии рубашки переворачиваются
  лицом.
- **Чужие карты не приходят на телефон вообще.** Сервер собирает состояние
  **для каждого зрителя отдельно**: ваши карты — только вам; чужие — только
  если их обязаны показать на вскрытии; колода не покидает сервер никогда.
  Спрятать в интерфейсе недостаточно: то, что пришло на телефон, можно
  увидеть.

## 8. Что пишется в группу, а что живёт только в Mini App

| Событие | Mini App | Группа | Личка |
|---|---|---|---|
| комната создана | — | **новое сообщение** (карточка) | — |
| игрок сел / встал | сразу | правка карточки (3/8) | — |
| игра началась, новая раздача | сразу, раздача анимацией | правка карточки | — |
| CHECK / CALL / BET / RAISE / FOLD | сразу | **ничего** | — |
| смена улицы, карты борда | сразу | правка карточки (стадия) | — |
| чей ход | сразу, подсветка + вибрация | правка карточки | «👉 Ваш ход» — только если стол закрыт |
| вскрытие, кто что забрал | сразу, на местах | правка карточки (последний итог) | — |
| таймаут, пропуск | сразу | правка карточки | — |
| игра завершена | экран итогов | **новое сообщение** с итогами | — |

За вечер в группу приходят **два новых сообщения**: карточка комнаты и итоги.
Всё остальное — правки одной карточки, которые не звенят.

## 9. Адаптация под телефон

- **Портрет, от 320 до 430 px шириной** — основной случай. Высота распределяется
  так: шапка 44 px, стол забирает всё свободное место, ваши карты ~120 px,
  панель действий 64 px + безопасная зона снизу. Скролла на столе нет.
- **Места соперников** раскладываются по краю овала по заранее подобранным
  схемам для 1–7 соперников, по часовой стрелке от вас — как за настоящим
  столом.
- **Кнопки не меньше 48 px**, цифры моноширинные (не прыгают при смене
  ставки), главное — крупно: стек, банк, сумма колла.
- **Telegram:** `expand()` на весь экран; `disableVerticalSwipes()`, чтобы
  движение слайдера не закрывало приложение; цвет шапки и фона — в тон стола;
  вибрация через `HapticFeedback`; безопасные отступы iPhone.
- **Компьютер / планшет:** тот же стол, центрированный, не шире 520 px — это
  тот же интерфейс, а не отдельная вёрстка.
- **Одна тема — тёмная**, независимо от темы Telegram: стол должен выглядеть
  столом и в светлом клиенте.

## Решения, принятые без вас (поправьте, если не так)

1. **Режим дилера = игра настоящими картами** (см. раздел 4).
2. **До 8 игроков** за столом (плюс дилер): больше на экране телефона не
   помещается читаемо.
3. **Игру из чата убираю:** кнопки ставок и команды `/call`, `/raise` и т. д. в
   группе больше не работают — вся игра в Mini App. Иначе у партии два
   интерфейса, и ни один не удобен.
4. **Карты в личку больше не приходят** — они на столе. Личка — только
   уведомления о ходе.
5. **Быстрая сумма рейза делает ход сразу** (2 нажатия), кроме ALL-IN (3 — с
   подтверждением).
