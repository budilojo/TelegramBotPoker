# Набор эмодзи «Фишка»

Смайлики-реакции с талисманом — зелёной покерной фишкой с лицом. Рисовал владелец;
папка «эмодзи фишки» на рабочем столе. Приложение берёт готовые уменьшенные файлы из
`miniapp/emoji/`, список — в `miniapp/emoji/manifest.json` (его читает чат и реакции,
агент Q; интерфейс — не здесь).

## Что внутри (16 штук, 56 КБ вместо 11 МБ исходников)

| Набор | `id` набора | Для каких игр | Смайлики (`id` — подпись) |
|---|---|---|---|
| Реакции | `universal` | все (`"*"`) | **быстрые:** `gg` Хорошая игра · `haha` Ха-ха · `wow` Ого! · `sad` Не повезло · `think` Думаю; остальные: `hello` Привет · `thanks` Спасибо · `sorry` Прости · `wait` Жду · `cheers` Ура! · `cool` Круто · `fire` В ударе · `facepalm` Ну как так · `angry` Злюсь |
| Покер | `poker` | `poker` | `allin` Олл-ин · `bluff` Блеф |

Наборов для шахмат, шашек, нард, морского боя, дурака и UNOQ **нет — картинок для них
в папке не было**. Анимированных файлов нет (все — статичные PNG).

## Как пересобрать

```
node tools/build-emoji.mjs "/путь/к/папке эмодзи фишки"
```

Скрипт читает `tools/emoji-map.json` (файл владельца → набор, `id`, подпись, быстрый ли;
порядок строк = порядок показа) и заново создаёт `miniapp/emoji/`. Что делает с каждой
картинкой: обрезает по контуру, вписывает в 112×112 внутри 128×128 (поля 8 px),
сжимает цвета до 48 (плоский рисунок — почти без потерь), сохраняет PNG-8 с
прозрачностью. Сами рисунки не правятся и не перекрашиваются. Повторный запуск даёт
побайтно те же файлы. Зависимостей нет (только Node). Исходники в git не кладутся
(`assets-incoming/` в `.gitignore`).

## Как добавить смайлик

1. Положить PNG с прозрачным фоном в папку владельца (или в `assets-incoming/emoji-fishki/`).
2. Добавить строку в `tools/emoji-map.json` в нужный набор (новый набор — новая запись
   в `sets`, `games` — `"*"` или список игр из `bot/games/index.js`).
3. Запустить сборку, запустить `npm test` (`bot/emoji.manifest.test.js`).
4. Закоммитить `miniapp/emoji/` и карту.

## Правила и бюджеты (охраняет `bot/emoji.manifest.test.js`)

- `id` — латиница, строчные, цифры и дефис; **уникален во всём манифесте и неизменен
  навсегда** (сервер хранит/принимает смайлик по `id`).
- Файл — `<набор>/<id>.png`, 128×128, прозрачность, ≤ 12 КБ; весь набор ≤ 700 КБ.
- Подпись — по-русски, до 18 символов; быстрых в `universal` — от 3 до 6 (сейчас 5).
- `games` — `"*"` или реальные игры из реестра.

## Что сообщено владельцу

- Исходники 1254×1254 по ~750 КБ — для приложения слишком тяжёлые; уменьшены.
- У части картинок рука/край упирается в самый край исходника (например `haha`, `cool`,
  `cheers`, `allin`): возможно, срезано генератором. Я ничего не дорисовывал.
- Покерных картинок всего две; для остальных игр своих нет — они пользуются «Реакциями».
- `facepalm` и `wait` слабо читаются в 48 px (мелкое лицо, зелёная рука на зелёном).
- Анимации нет — «идей на потом» не набралось.
