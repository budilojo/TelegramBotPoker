# Покер: курс «Обучение» (волна 3)

Что это: 29 коротких уроков в шести разделах — от правил до основ GTO. Открывается в
приложении: **Игры с ботами → Покер → «Обучение»** (полный экран, шторки нет). Прогресс
чтения — на телефоне (`localStorage`: `learn.read`, `learn.quiz`), на сервер не уходит
(решение 052). Старая «Школа покера» живёт внутри курса как «Практика с наставником».

## Где что лежит

| Что | Файл |
|---|---|
| Разделы и порядок уроков (данные, не экран) | `miniapp/learn/sections.js`, `miniapp/learn/content/{basics,preflop,ranges,math,postflop,gto}.js` |
| Экраны: список, урок, «Практика с наставником» | `miniapp/learn/screens.js` |
| Числа курса — **факты**, считаются кодом | `miniapp/learn/facts.js` (формулы — `miniapp/train/poker-math.js`) |
| Схемы (стол, улицы, лесенка комбинаций, матрица, колода) | `miniapp/learn/diagrams.js`, `miniapp/learn/parts.js` |
| Интерактивные примеры (18 штук: ползунки, выбор, шаги) | `miniapp/learn/play.js` |
| Подключение к экрану (крючок) | `miniapp/learn/hook.js` |
| Прогресс чтения | `miniapp/learn/progress.js` |
| Стили (только токены) | `miniapp/learn.css` |
| Темы — общий словарь с Тренировкой | `miniapp/train/topics.js` |

## Как добавить урок

1. Тема в `miniapp/train/topics.js` (id не переименовывать и не удалять — на них ссылается сохранённый прогресс).
2. Объект урока в файле раздела (`goal`, `needs`, `blocks`, `remember` — три пункта, `quiz`).
3. Числа в тексте — только `{{fact:id|формат}}`; факт описать в `facts.js`. Пишете «35 %» руками — тест упадёт.
4. Всё, что не считается точно (диапазоны, размеры ставок, GTO-частоты), — с блоком `['rule', …]` «правило порядка, не точный солвер».

## Честность чисел

`bot/learn.facts.test.js` пересчитывает каждый факт **независимо** (перебор колод через
`bot/eval.js`); `bot/learn.content.test.js` следит за формой уроков, живыми ссылками на факты,
«голыми» вероятностями, пометкой «правило порядка» и отсутствием `innerHTML` и внешних доменов.
Проверено «на зубы» (K, 2026-10-26): подмена факта, удаление темы из реестра и «голое» число в тексте — тесты падают.
Ещё K пересчитал 13 фактов своим перебором (оценщик, не `bot/eval.js`): расхождений нет.

## Связка с Тренировкой

Урок, открытый из ошибки («Изучить тему»), знает, куда вернуться, и показывает «Вернуться к
заданию» (то же упражнение, тот же seed); обычный урок — «Потренироваться» (только если по теме
есть упражнения). Устройство — `docs/poker-training.md`, раздел про связку.

## Не проверено

Прокрутка и ползунки в настоящем iOS/Android WebView, кнопка «Назад» Telegram, перезагрузка
WebView посреди урока. Эмуляция Chromium (e2e `tools/e2e-learn.mjs`, `tools/e2e-scroll-train.mjs`)
— это не устройство.
