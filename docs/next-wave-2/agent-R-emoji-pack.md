## Что сделать

1. **Найти папку.** `~/Desktop/эмодзи фишки` (на Mac владельца; проверь и варианты
   написания: `ls ~/Desktop`, `ls -la ~/Desktop | grep -i эмодзи`). **Не найдена или пуста —
   остановись и скажи владельцу** простыми словами, где искал и что ему сделать (положить
   в `assets-incoming/emoji-fishki/` внутри папки проекта). Фантазировать содержимое
   нельзя.
2. **Опись.** Сколько файлов, форматы (png/webp/gif/svg/lottie), размеры, прозрачный ли
   фон, анимированные ли, общий вес. **Осмотри каждую картинку глазами** (инструмент
   `Read` показывает изображения). Составь таблицу «файл → что нарисовано → к какому
   набору относится».
3. **Разбить по смыслу** на наборы (названия по-русски для интерфейса):
   - **«Реакции»** (`universal`) — универсальные, для всех игр: например «хорошая игра»,
     «ого», «ха-ха», «не повезло», «думаю», «привет», «спасибо», «прости», «жду», «ура»;
   - **«Покер»** (`poker`) — покерные эмоции и символы (олл-ин, блеф, фишки, карты…);
   - **специфические** — наборы для своих игр (`chess`, `checkers`, `nardy`,
     `battleship`, `durak`, `unoq` — только те, для которых реально есть картинки).
   Из «Реакций» отметь **5 быстрых** (`quick: true`) — самые частые, они будут всегда под
   рукой. Спорные картинки — в отчёт владельцу с вариантами, а не молча.
4. **Подготовить файлы** (без новых зависимостей: Chromium из Playwright, `sips` или
   `convert`, если есть; иначе скажи владельцу):
   - прозрачный фон сохранить; размер **128×128** (края не обрезать, поля ≥ 8 px);
   - вес файла **≤ 12 КБ**, весь набор **≤ 700 КБ** (если больше — сожми, а если не
     выходит — скажи, что и почему);
   - анимированные: **в интерфейс пока статичный кадр**; анимацию не подключай, в
     отчёте укажи, что она есть (`ideas.md`);
   - имена `id` — латиницей, коротко, навсегда неизменные (`gg`, `allin`, `fish-stack`);
   - исходники из папки владельца в git **не класть** (папка `assets-incoming/` в
     `.gitignore`); в git — только готовые `miniapp/emoji/<набор>/<id>.png`.
5. **`miniapp/emoji/manifest.json`** — ровно по контракту плана:
   ```
   { "version": 1, "sets": [
     { "id": "universal", "title": "Реакции", "games": "*",
       "items": [ { "id": "gg", "file": "universal/gg.png", "label": "Хорошая игра", "quick": true } ] },
     { "id": "poker", "title": "Покер", "games": ["poker"], "items": [ … ] } ] }
   ```
   Подписи — по-русски, до 18 символов (в две строки в клетке 4 колонок на 320 px),
   порядок — как показывать (частое первым). `games` — `"*"` или список `id` игр из
   `bot/games/index.js` (poker, durak, colors, chess, checkers, nardy, battleship).
6. **Воспроизводимая сборка:** `tools/build-emoji.mjs <папка владельца>` читает
   `tools/emoji-map.json` (файл → набор, `id`, подпись, `quick`) и создаёт
   `miniapp/emoji/`; повторный запуск даёт тот же результат. Карта и скрипт — в git.
7. **Тест `bot/emoji.manifest.test.js`:** манифест валиден; `id` уникальны во всём наборе;
   каждый файл существует, ≤ 12 КБ, PNG с прозрачностью; подписи ≤ 18 символов; `games`
   — реальные игры из реестра; есть ≥ 3 и ≤ 6 быстрых в `universal`; суммарный вес в
   бюджете. **«На зубы»:** подменить `id`, удалить файл, раздуть файл — каждый раз падает.
8. **`docs/emoji.md`:** откуда набор, как пересобрать, как добавить смайлик (какие
   файлы и строки менять), бюджеты размера, правила `id`.
9. `npm test` — зелёный. Когда запушил — **коротко сообщи агенту Q** (если он запущен:
   `ListAgents`, затем `SendMessage`): «манифест эмодзи в `redesign`, `commit …`».
