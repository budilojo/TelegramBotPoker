# Карта навигации: действие → старая точка входа → кнопка (2026-10-30, исполнитель C)

Правило: каждое обычное действие игрока и хоста доступно кнопкой. Команды остаются только служебные
(`/start`, `/help`, `/game`, `/paysupport`, `/terms`) и у владельца (админ-бот). Старые команды **не удалены**:
они работают и отвечают с кнопкой, чтобы старые сообщения не стали тупиком; из меню «/» они убраны.

| Действие | Старая точка входа | Кнопка сейчас | Кто может | Возврат |
|---|---|---|---|---|
| Выбрать игру и создать лобби | `/game` (оставлена), `/chess` `/durak` `/unoq` `/checkers` `/nardy` `/battleship` | «🎮 Выбрать игру» под карточкой → каталог карточек → игра → «Создать лобби» | любой участник группы | «Назад» Telegram / «← Все игры группы» |
| Каталог игр | список в столбик | страницы: «‹ ›», точки, свайп, «Страница N из M»; позиция помнится | все | вкладка «Игры» |
| Присоединиться к столу | карточка в группе | «Присоединиться» в «Открытых играх» или по карточке | участник группы | «← Все игры группы» |
| Показать карточки игр внизу чата | `/table` | не нужна: карточка «Выбрать игру» и список «Открытые игры» | — | — |
| Завершить игру с итогами | `/finish` | Меню стола → «Завершить игру» (7 игр) | хост | итоги в группу |
| Удалить игру/лобби | `/cancel [код]` | **новое:** Меню стола → «Удалить игру» → подтверждение (сообщение `drop`) | только хост (сервер) | хаб группы |
| Новый покерный стол | `/newgame`, `/poker` | «Создать лобби» / «+ Ещё один стол» | любой | — |
| Игра с ботом | `/bot` (личка) | «🤖 Играть с ботом» (личка, группа, хаб); любое слово в личке отвечает справкой с кнопками | любой | «← Мои группы» |
| Рейтинг / Магазин / Настройки | — | нижняя панель на экранах хаба | любой | «Игры» |
| Магазин | вкладка «скоро» | вкладка «Магазин»: если сервер включил коллекции — витрина «Коллекции», иначе «скоро»; «Настройки → Коллекции» тоже | любой | «Назад» витрины |
| Мои покупки, поддержка, условия | `/paysupport`, `/terms` (оставлены) | «Коллекции» → «Мои покупки», «Написать в поддержку», «Условия» | покупатель | — |
| Настройки стола в партии | меню стола | Меню → «Настройки стола» (хост) | хост | закрыть шторку |
| Вернуться к столу | список ниже | первая кнопка хаба «↩ Вернуться к столу · игра» | сидящий за столом | тот же стол |
| Напоминание «ваш ход» | `/start` у бота | «Настройки → Открыть бота» | любой | — |
| Админ-действия | `/stats /now /stop /pause /resume …` | админ-бот; пульт-экран | владелец | **не тронуты** |

## Просмотр раздела ≠ выход из партии
«← Все игры группы» (и «Назад» Telegram) уводят **только страницу**: место за столом, раздача, очередь хода,
банк и часы не меняются (тест `bot/navigation.table.test.js`: за время просмотра ход по таймеру сделан; место
не освобождено). Возврат — «Вернуться к столу» (те же карты, та же раздача). Стол, удалённый за это время, из
хаба пропадает, вход по старому коду — отказ словами. Чужие столы по коду из другой группы не открываются.

## Ограничения Telegram (по документации core.telegram.org/bots/webapps, открыта 2026-10-30)
- Mini App из чата открывается прямой ссылкой `t.me/<бот>/<приложение>?startapp=…` — так сделаны карточки в группе;
  `web_app`-кнопки проект ставит только в личке. Для групп документация об ограничении web_app-кнопок не говорит
  прямо — выбранный путь (ссылка) не зависит от этого.
- `BackButton` показывается/скрывается методами `show/hide`, нажатие даёт событие — приложение ведёт по нему из-за стола в хаб.
- Лимиты `setMyCommands` страница не описывает — не проверено; меню стало короче, превышения быть не может.
- Не обещано: закрепление кнопок в группе, «inline» вход без ссылки.

## Что не сделано / оставлено
- Единой «нижней панели внутри партии» нет: в партии — компактное меню «⋯» и «← Все игры группы»; панель остаётся
  только на экранах хаба, чтобы не перекрывать доску, чат и действия. Решение исполнителя.
- Уведомление о своём ходе при просмотре раздела: страница в хабе считается не за столом, поэтому личное
  напоминание бота работает как раньше; в живом Telegram не проверено.
- Команды `/finish`/`/cancel` с кодом работают для старых сообщений; удаление через кнопки — только хостом.
