## Баг «при изменении настроек стола во время игры»
- **Воспроизведён** (`tools/e2e-settings.mjs`, настоящий Chromium): хост в раздаче открывает «Настройки стола», печатает в поле блайнда; приходит обновление стола — шторка пересобиралась целиком, поле теряло фокус (клавиатура закрывается), курсор уходил в начало (набрали «7», потом «5» → «57»).
- **Причина:** `refreshSheet()` на каждое состояние заново строил форму (`miniapp/ui.js`). Двигатель `server/game.js` ни при чём, `ENGINE-NOTE.md` не нужен.
- **Исправлено:** общий механизм шторок запоминает поле в фокусе и курсор и возвращает их (затрагивает все формы). В покере: «лобби / посреди раздачи» берутся свежими (раньше запоминались при открытии — после начала раздачи смена карт отклоняла весь набор); проверка границ словами (пусто/0/большой<малого/стек<БB) с закрытой кнопкой «Сохранить»; повторное нажатие шлёт один набор; подсказка про таймер («применяется сразу…»). Дурак — та же устаревшая «партия идёт» поправлена.
- **Сервер (`bot/room.js`, не `game.js`):** повторное «Сохранить» тех же блайндов посреди партии считалось изменением и копило «отмену» — теперь сравнивается с ожидающими блайндами.
- **Что применяется когда:** стек — только в лобби; блайнды — со следующей раздачи; таймер — сразу (включили посреди хода — у ходящего свежий отсчёт, выключили — часов нет); карты — между раздачами. Текущая раздача, банк, очередь и часы не меняются — `bot/settings.live.test.js` (9 тестов).
- Какая игра имелась в виду, неизвестно; формы остальных игр — только кнопки (дефекта фокуса у них быть не может), не воспроизводились отдельно.

## Навигация и каталог
- `docs/next-release/navigation-map.md` — действие → старая точка → кнопка → права → возврат.
- **Каталог игр** (`miniapp/catalog.js`, `catalog-pager.js`): страницы по 2–4 карточки (по высоте экрана), «‹ ›», точки 44 px, свайп, «Страница N из M», позиция помнится; список — из реестра; 0/1/много страниц, длинные названия, 320/390 px. Хаб группы и «Игры с ботами».
- **Кнопки вместо команд:** новое «Удалить игру» (`drop`, только хост, во всех 7 играх) вместо `/cancel`; меню «/» — только `/game`, `/help`; старые команды работают и отвечают с кнопкой; справка и любой текст в личке — с кнопками; `/paysupport`, `/terms`, админ-команды не тронуты.
- **«Вернуться к столу»** — первая кнопка хаба для сидящего за столом; уход в хаб место/раздачу/часы не трогает (`bot/navigation.table.test.js`).
- **Магазин B:** вкладка «Магазин» открывает витрину «Коллекции», если сервер её включил; иначе — «скоро». Экран «скоро» поверх готового магазина не возвращается.
- Решение: нижней панели внутри партии нет (не перекрывать доску/чат), вместо неё меню «⋯» и «← Все игры группы».
