Известное падение при подготовке этих документов 2026-10-28: npm test — 1234/1235, bot/battleship.bot.test.js:298, expected bot1, actual 101. Воспроизвести и установить причину; не списывать на нестабильность и не ослаблять тест без доказательства ошибки в нём.

Используй 01-common.md. Проверяй фактический итог A–D, а не только их отчёты. Исправь дефекты интеграции в согласованном объёме, не добавляй новые функции. Выполни npm test, полный e2e, layout, kit, contrast, preview с визуальным просмотром; colors при изменении UNOQ. Разбери ранее отмеченную high-уязвимость через актуальную проверку зависимостей: достижимость, исправление совместимым обновлением и регрессия. Не запускать audit fix --force. Не скрывать нестабильные тесты и падения.

Проверь платежную матрицу B, отказоустойчивость, права покупки/возврата, приватность, совпадение опубликованных документов с поведением, выключатель продаж и невозможность обхода со страницы. Проверь отсутствие покупки игровых преимуществ. Браузерные тесты не заменяют официальную тестовую оплату Telegram. Повтори критические проверки после интеграционных исправлений; новые защиты — «на зубы».

Проверь локальное восстановление из копии тестовой базы и план отката при незавершённых платежах. Боевые данные и сервер не менять. Сверь инструкцию выкатки с обязательной /pause и обработкой оплат во время обслуживания. Саму выкатку не выполнять.

Подготовь docs/next-release/release-readiness.md с решением «готово / не готово» отдельно для кода, бесплатных функций, открытия продаж и рейтинга. Для каждого препятствия — доказательство и что необходимо сделать. Ни один незаполненный обязательный реквизит, отсутствие утверждённых цен/готовых товаров, нерешённое правовое ограничение или непроверенная внешняя платёжная операция не должны раствориться в общей отметке «тесты зелёные».

Собери ОДИН окончательный список для владельца из owner-inputs.md и всех отчётов: только действительно необходимые факты/решения, с простыми вариантами, без повторов. Укажи непроверенные устройства. После этого — проект плана выкатки, без её выполнения и без утверждения о полной юридической гарантии.
