## Правила версий

- В шапке каждого публичного документа: `Версия`, `Дата`, `Статус` (`ПРОЕКТ` / `Действует` / `Заменён версией N`).
- Заказ хранит номер версии условий, показанных при покупке (L-xx раздел 11, ограничение О-10 для B).
- Новая версия условий действует только для **новых** покупок; купленное раньше — по своей версии.
- Пока у документа статус `ПРОЕКТ` или есть хотя бы одно поле `[НЕ ЗАПОЛНЕНО`, серверный выключатель продаж открывать
  нельзя (условие У-1). Это условие B может проверить кодом: поиск строки `[НЕ ЗАПОЛНЕНО` в публикуемой версии.

## Чего в документах нет намеренно

- Отказов от обязательных прав покупателя («возврат невозможен», «претензии не принимаются» и т. п.).
- Обещаний, что всё законно, и обещаний для других стран.
- Цен, реквизитов, сроков, которые владелец не назвал.
