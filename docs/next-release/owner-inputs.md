# Что нужно от владельца (единый список)

Ведут все исполнители по очереди; итоговый сводный список даёт E в `release-readiness.md`.
Правило плана: незаполненное **блокирует продажи, но не разработку**; ответы не выдумывать;
до заполнения действует «безопасное поведение». Строки не повторять — если факт уже есть, дополнить.
