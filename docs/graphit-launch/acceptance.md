# Критерии приёмки и обязательные проверки

## Общие (для каждого исполнителя перед статусом `done`)

1. `npm test` зелёный целиком; число тестов в отчёте.
2. Каждая новая защита проверена «на зубы»: скрипт/тест **возвращает сломанный код** и тест **падает**; результат — в отчёте (таблица «защита → как
   сломано → упал ли тест»). Тесты не ослаблять (`AGENTS.md`, п. 3).
3. Личность — только из проверенного `initData`; тело сообщения не даёт прав; отказы — словами через существующие ошибки/`ERRORS`.
4. Приватность: тест через настоящий хаб с настоящими страницами проверяет **всё, что получил каждый телефон за всю партию** (запись всех
   сообщений каждого участника, а не последний экран): нет чужих карт/колод, нет чужих прав/выбора/`pending`, нет демо-флагов и цен у других.
5. Оформление не влияет на правила, ходы, часы (`room.turn`), рейтинг, шансы: тест сравнивает ход партии с оформлением и без при одинаковой колоде.
6. Файлы только своей зоны (`ownership.md`); общие — фрагментами в отчёт; `git diff --stat origin…` без чужих файлов.
7. Интерфейс (где есть): ширины **320/360/390/430 px**, длинные имена, малые карты и аватары, контраст (текст ≥ 4.5, значимое нетекстовое ≥ 3),
   зоны нажатия ≥ 44 px, фокус и подписи, `aria`, отсутствие перекрытий, горизонтального скролла и прыжков (`tools/lib/scroll-probe.mjs`, `docs/scroll.md`);
   скриншоты **посмотрены глазами** (инструмент `Read` показывает изображения), находки перечислены.
8. Честность проверок: Chromium с эмуляцией — не Telegram. Чего не проверено на телефоне — раздел «Не проверено на телефоне» в отчёте; **запрещено**
   писать «проверено в Telegram».
9. Отчёт `reports/<id>.md` и статус `reports/<id>.status.json` записаны, коммит сделан в ветку `gr/<id>`, `git status` чистый.

## По исполнителям

**lead-contracts:** контракт сверен с кодом (по каждому пункту «подтверждено/поправка»); найдены и записаны фактические точки снимка раздачи покера
и дурака, жизненный цикл хоста; каркас общих файлов на месте, `npm test` зелёный; никакого функционала.

**server:** все операции протокола; демосреда по умолчанию выключена и **не включается** ни клиентом, ни базой (тесты: `collectionsDemo` выключен →
`COL_DEMO_OFF`; демо-строки в базе при выключенном — игнорируются; значения `COLLECTIONS_DEMO` кроме `1` — выключено); идемпотентность `req`;
владение/цвет/слот проверяются; снимок раздачи замораживается и переживает переподключение, перенос хоста и перезапуск (сериализация);
лобби обновляется сразу; старые комнаты без `look` читаются; `view` содержит только публичное; старый код `7afb285` открывает базу; `MemStore` и `Store` ведут себя одинаково.

**assets:** 4 цвета × все виды; одинаковые viewBox/геометрия/толщины (тест сравнивает структуру без цветов); только цвета палитры; нет запрещённых
элементов; бюджет веса; детерминированность; контраст линии к фону предмета ≥ 3:1 в реальных размерах и отличимость Петроли от зелёного `#137A43`
(метод и числа — в отчёте); скриншоты на малых размерах просмотрены; `art/README.md` с правилами применения; **не** вырезки из PNG.

**client:** весь путь «витрина → карточка → цвет → примерка → демополучение → инвентарь → применение»; все состояния из SPEC (загрузка, пусто, нет связи,
ожидание, ошибка применения, уже куплено, частичный комплект); выбор «сохранён» только после ответа сервера; защита от повторного нажатия; «Так видят друзья»
только в примерке; точка входа отсутствует вне демо; e2e на 4 ширинах; зубы (убрать проверку подтверждения сервера, показать выдачу до ответа, показать вход в рабочем режиме).

**screens:** рубашка у каждого места по `look.backs`, лица карт не заменены; стол в покере и дураке; центр свободен; рамка/знак только в лобби и результатах;
вид не меняется в раздаче, в том числе после переподключения (e2e с обрывом связи); базовый вид при отсутствии файла; читаемость карт/банка/кнопок на 320 px; **не** сломаны
`layoutTable`/`watchBox`/`holdStep`; Петроль не путается с индикатором хода (скриншоты на всех цветах); зубы.

**homescreen:** методы и события проверены по официальной документации (ссылки и дата в `docs/homescreen.md`); состояния недоступности/отказа; успех только по подтверждению;
нет навязчивых предложений; независимость от коллекций; тесты на заглушке Telegram с разными вариантами ответов; честно: настоящее добавление иконки не проверено.

**research:** каждый документ: дата проверки, ссылки на **официальные** источники, разделы «Подтверждено», «Интерпретации», «Неясно», «Что нужно уточнить владельцу»; отделены
правила платформы и налоговые/юридические вопросы; никаких обещаний сумм без подтверждённых условий; отсутствие найденного запрета **не** считается разрешением.

**lead-integration:** все ветки слиты (или конфликт разрешён и записан); полный `npm test`; `npm run e2e` целиком (включая новые файлы, добавленные в `package.json`); `layout`, `kit`,
`contrast`, `preview` на 320/360/390/430 с просмотром скриншотов; сквозной сценарий демонстрации; приватность по всей истории; рабочий режим без демо: вход скрыт, вкладка «Магазин»
не изменилась; общие файлы обновлены; память проекта обновлена, готовые функции не отмечены как реализованные в живом Telegram; `FINAL.md` и `FINAL.status.json`.

## Сквозной сценарий демонстрации (проверяет `lead-integration`)

Демосреда включена → «Настройки» → «Коллекции» → витрина → карточка рубашки → цвет «Бордо» → примерка (есть «Так видят друзья») → «Получить для демонстрации» →
получение → инвентарь → применить рубашку и стол → за столом покера в **текущей** раздаче вид прежний → **следующая** раздача: рубашка Бордо на закрытых картах владельца у всех,
стол хоста у всех (и в дураке) → рамка и знак в лобби и результатах → переподключение посреди раздачи не меняет вид → возврат к базе. Затем рабочий режим (демо выключено): входа нет,
`grant` отклонён, вкладка «Магазин» — «скоро».
