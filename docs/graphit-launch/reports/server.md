# Отчёт: server (серверная часть «Графита»)

## 1. Что сделано
* **Демосреда.** Опция `collectionsDemo` в `App` (по умолчанию `false`); `bot/index.js` читает `COLLECTIONS_DEMO` и включает только при значении ровно `1`. В `.env.example` — закомментированная строка с пояснением «только для демонстрационной среды». Права администратора и `cosmeticsUnlocked` демо не включают.
* **Таблицы** `collection_demo_grant`, `collection_choice`, `collection_req` — в `Store` (SQLite) и `NullStore` (памяти; `MemStore` в проекте нет, см. поправку контракта). Версия схемы осталась `5`.
* **Протокол `{t:'col'}`** (`bot/collections/index.js`, класс `Collections`, доступен как `app.collections`): `state`, `grant`, `apply`, `clear`; проверка по каталогу, владению, слоту и цвету; идемпотентность по `req` (хранится до 50 последних); лимит 20/мин по `app.clock.now()`; отказы словами из `protocol.js`. Ветка в `bot/hub.js` стоит рядом с `shop`; админская страница получает `COL_OP`. Решение 106 и `shop` не тронуты.
* **Состояние при подключении:** `Hub.open` теперь оболочка над `openInner` и шлёт своё `state` (только при включённом модуле).
* **Снимок раздачи** `room.look`: лобби — пересборка при каждой отправке вида (`App.draw` → `collections.settle`); начало раздачи/партии — `collections.freeze` в `App.afterDeal` (его вызывают и покерные `start`/`next`/автораздача, и дурак `start`/`next`), дальше заморожен. Стол — выбор `room.hostId` на момент снимка; рубашки — каждого сидящего (покер); рамки — каждого. Нет права / предмет не для игры → база. Сериализуется вместе с комнатой; старая комната без `look` читается как база. Игры с ботами считаются так же.
* **Поля `view`:** см. список ниже.
* Решения 110–113 в `docs/brain/decisions/`.

### Список для `screens`
* Покер `tableView` (`bot/view.js`): `look: {v:1, table:{item,color}|null, backs:[{seat,item,color}], dealNo}`; `players[i].frame: {item,color}|null`; `results[i].frame` — рамка на момент итога.
* Дурак `view` (`bot/games/durak/view.js`): `look` (без `backs` — всегда `[]`), `players[i].frame`; в итогах дурака рамку несут `players[]` вида.
* Функции: `lookView(room,{withBacks})` и `frameOf(room,id)` в `bot/collections/look.js`; места вызова — `bot/view.js`, `bot/games/durak/view.js`.
* Фактическое поведение хоста: стол — хоста **на момент начала раздачи**; перенос хоста посреди раздачи снимок не меняет, со следующей — стол нового хоста (совпадает с контрактом).
