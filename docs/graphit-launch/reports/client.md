# Отчёт: client (экраны коллекций «Графит»)

## 1. Что сделано

Клиентская часть демонстрации коллекций работает на тестовой заглушке сервера:

* **Вход.** Строка «Коллекции» (подпись «Демонстрация · Без оплаты») в «Настройках» — только если сервер прислал `enabled && demo`. Вне демо строки нет; адреса `/#collections`, `?collections=1` и `localStorage` ничего не открывают; вкладка «Магазин» осталась «скоро».
* **Витрина** «Графит»: три предмета и комплект, отметки «Доступно» / «В вашей коллекции» / «Применено» / «Применится со следующей раздачи» / «Получено N из 3»; цены 79/99/199/249 — только в демо и с пометкой «цена демонстрационная». Кнопок «Купить» нет.
* **Карточка**: картинка (`art.js` → `/collections/art/…`, при ошибке — нейтральный запасной вид), назначение, «Навсегда», «Все 4 цвета включены», четыре подписанных цвета; выбранный — светлый нейтральный контур + галочка + слово для чтения экраном. Рубашки дурака нигде не обещаются.
* **Примерка**: свой локальный цвет, ничего на сервер не отправляет (проверено подсчётом кадров). Рубашка на закрытых картах и блок «Так видят друзья» — только здесь; стол и профиль — на образцах.
* **Демополучение**: «Получить для демонстрации» → запрос `grant` с `req`; пока ответа нет — «Ждём ответ сервера…», повторное нажатие не уходит; экран «Получено» только после ответа. Повтор после молчания идёт с тем же `req`. Частичный комплект: показано имеющееся и недостающее, кнопка комплекта закрыта, пояснение «цена дополнения комплекта ещё не утверждена». Уже полученное: «✓ Уже в вашей коллекции», кнопки получения нет.
* **Получение**: состав, переключатели применения (встают только после ответа сервера), переход в инвентарь; само получение выбор не меняет.
* **Инвентарь**: вкладки «Карты», «Столы», «Профиль»; база «Классика» («Вернуть базовое»), полученное с выбором цвета, «Применить»/«Сменить цвет», отметки по `pending`; ещё не полученное — закрытая карточка со ссылкой на витрину.
* **Состояния**: загрузка (заглушка тех же размеров — достижима только при потере состояния, см. п. 4), пустой инвентарь (база + пояснение + переход в витрину), нет связи (плашка, «Повторить» при отсутствии данных, владение не выдаётся), ожидание, отказ сервера (прежний выбор, текст словами, «Повторить»), нет ответа 8 с, сервер выключил демо (слой закрывается, входа нет).
* Подключение: `msg.t === 'col'` → `bus.onCollections` в `miniapp/net.js`; в `miniapp/app.js` — один импорт, `collections.onMove()` и `collections.sync()`.
* Файлы: `miniapp/collections/{index,state,art,showcase,item,fitting,inventory,receive,settings-row}.js`, `miniapp/collections.css`, `tools/e2e-collections.mjs`, `tools/graphit-client-teeth.mjs`, `bot/collections.client.test.js`, решения 117–120.

Найдено глазами на скриншотах и исправлено: в инвентаре подписи цветов рвались по буквам («Графи/т») — карточки перестроены (картинка и название сверху, элементы управления на всю ширину), цвета в столбик на узких экранах, в e2e добавлена проверка «подпись не переносится». Ещё два дефекта нашёл e2e: после «нет ответа → Повторить» не открывался экран «Получено»; после выключения демо строка «Настроек» не исчезала.

## 3. «На зубы»

`node tools/graphit-client-teeth.mjs` — на целом коде тест зелёный, на каждой поломке красный; файлы возвращаются как были.

| Защита | Как сломана | Упал ли тест |
|---|---|---|
| выдача только после ответа | владение ставится сразу при нажатии | да |
| вход только в демо | достаточно `enabled` | да (и e2e: «вне демо входа нет») |
| демо — строго `demo === true` | любая «правдивая» строка | да |
| защита от двойного нажатия | убрана проверка `wait` | да |
| повтор с тем же `req` | повтор с новым `req` | да |
| отказ сервера | отказ игнорируется | да |
| частичный комплект | комплект разрешён при частичном владении | да |
| «Так видят друзья» только в примерке | строка на карточке | да |
| выбранный цвет не синий | `#2c6fd1` | да |
| выбор не только цветом | убрана галочка | да |
| демо только от сервера | демо из `localStorage` | да |
| нет выдуманной оплаты | кнопка «Купить» | да |

## 4. Что не удалось или не проверено

* **Серверного модуля в моей ветке нет:** e2e работает на **заглушке** ответов `col` внутри `tools/e2e-collections.mjs` (по контракту, раздел 2). Совпадение с настоящим сервером проверит `lead-integration`.
* **Картинок нет** (`art/` — зона `assets`): проверен только запасной вид; как выглядят настоящие SVG в четырёх цветах — не проверено. Запасной вид не передаёт выбранный цвет.
* Состояние «загрузка» (заглушка) на практике почти недостижимо: слой открывается только когда `state` уже пришёл; заглушка есть для потери состояния, отдельно её e2e не показывает.
* Контраст новых пар не считался отдельным инструментом; `npm run layout` не гонялся.
* Время «нет ответа» — 8 секунд, взято мной.

### Не проверено на телефоне в живом Telegram
Всё. Проверен только Chromium с эмуляцией телефона и заглушка Telegram. Не смотрели: шрифты и отступы у края экрана и «выреза», безопасные зоны, касания пальцем и зоны нажатия руками, поведение кнопки «назад» Telegram при открытом слое, прокрутку в webview, клавиатуру, реальное переподключение сети.

### Будущая оплата (только описание, не реализовано)
Отмена: вернуть на карточку без изменений, владение не выдавать. Ожидание: кнопка занята, экран прежний, повтор с тем же идентификатором платежа. Ошибка: текст словами и «Повторить», ничего не выдавать. Восстановление: после перезапуска/обрыва спросить у сервера состояние и показать «Получено» только по подтверждению сервера; дубль платежа должен быть невозможен по идентификатору. Правила и сроки — только после решения владельца.

## 5. Запросы к контракту

* Клиент считает ответом на запрос и `op:'state'`, если в нём виден нужный результат (контракт говорит «ответ — `state`»; поле `op` в ответе совпадает с запросом или равно `state`). Менять не нужно.
* Для кнопки «Применить» и подписей «Применится сразу» для профиля клиент опирается на `when`/`pending`; если сервер для профиля отдаст `pending`, подпись будет «Применится со следующей раздачи».
* Прошу `server` не присылать `demo:true` без `enabled:true` и всегда отвечать на `state` после переподключения (клиент так и спрашивает).
