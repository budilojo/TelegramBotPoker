# Пакет запуска: коллекция «Графит», иконка на рабочий стол, исследования

Подготовлено 2026-10-27. Это пакет заданий и средство запуска; **код продукта этим пакетом не написан**.
Запуск — одной командой (раздел «Запуск»). Реализация начнётся только после неё.

## Запуск (одна команда)

На Mac, в папке проекта, на ветке `redesign` с чистым деревом:

```
cd ~/TelegramBotPoker && git pull origin redesign && node tools/graphit-run.mjs
```

Проверка без запуска агентов (ничего не создаёт и не меняет): `node tools/graphit-run.mjs --dry-run`.
Что делает команда и как продолжить после остановки — `docs/graphit-launch/00-plan.md`, разделы 6 и 7.

## Что происходит после команды

1. **Проверки** (останавливают запуск, если что-то не так, и говорят, что исправить): Node ≥ 22.5; `git`; `claude` и его параметры (`--agent`, `--permission-mode`, `--output-format`, `--print`);
   ветка `redesign`; чистое рабочее дерево; `origin` доступен и `redesign` не расходится с ним; манифест корректен; нет второго запущенного экземпляра. Дополнительно (только предупреждение) — сверка
   `~/Desktop/graphit-collections.zip` и `~/Desktop/README — копия.md` с `design/collections/` по SHA-256: расхождения печатаются, **файлы репозитория не перезаписываются**.
2. **Фаза 1** — `lead-contracts` (и параллельно `research`), потом **фаза 2** — `server`, `assets`, `client` (не более трёх одновременно), затем `screens` и `homescreen` и, когда все закончили, **фаза 3** — `lead-integration`.
3. Каждый исполнитель — отдельный `claude -p --agent …` в своей рабочей копии рядом с проектом (`../TelegramBotPoker-gr-<id>`), без участия человека; отчёты — `docs/graphit-launch/reports/`.
4. Слияние ветки исполнителя в `gr/integration` делает скрипт, по одной. Итог зелёный (`FINAL.status.json`: `ok` и `push_ready`) → один обычный `git push origin gr/integration:redesign`. Иначе ничего не публикуется.

## Повторный запуск и остановки

* Та же команда **продолжает**: готовое пропускается, оборванное и упавшее запускается снова (до 3 попыток, один раз за запуск), существующие рабочие копии и ветки используются, новых дубликатов нет.
* Состояние: `node tools/graphit-run.mjs --status`; журналы — `.graphit-run/logs/<агент>.<попытка>.out.json` и `.err.log`.
* **Лимит использования Claude:** запуск останавливается с кодом 75 и сообщением; повторите команду позже.
* Если после «упавшего» агента исправили причину и он слился, итоговая интеграция запускается заново автоматически.
* Мак не должен засыпать (запуск идёт часами): при желании — `caffeinate -i node tools/graphit-run.mjs`.
* Начать полностью с нуля вручную (осторожно, удаляет только копии запуска): `git worktree remove --force ../TelegramBotPoker-gr-<id>`, `git branch -D gr/<id>`, `rm -rf .graphit-run`. Скрипт сам ничего подобного не делает.

## Параметры

`--dry-run` (проверки и план, ничего не создаёт); `--status`; `--check` (только манифест); `--max-parallel N`; `--only id[,id]`; `--no-push`; `--model <модель>`; `--permission-mode <режим>`
(по умолчанию `auto`, как «auto mode» у вас в окнах; можно `GRAPHIT_PERMISSION_MODE`); `--agent-timeout-min N` (по умолчанию 240).
