# Промт для Claude Code: морской бой

Вставьте всё, что ниже разделителя, в Claude Code (в папке проекта на Mac). Перед
этим пусть он сделает `git pull` в ветке `redesign` (в промте это есть). План и
решения — в `docs/plan-battleship.md`. Работа идёт этапами с остановкой после
каждого.

---

Сначала выполни `git pull` в ветке `redesign`. Потом прочитай `AGENTS.md`,
`docs/duels.md` (раздел 4 «Как добавить следующую дуэль»), `docs/bots.md`,
`docs/game-hub.md` (раздел «Модуль игры»), `docs/checkers.md` и `docs/nardy.md`
как образцы, и главное — **`docs/plan-battleship.md`**: в нём план, решения и
требования к приватности. Работай в ветке `redesign`. Пользователь — не
программист: в отчётах говори просто и по-русски, что сделано, что проверено и
чего проверить нельзя.

Делай **по этапам из плана, строго по порядку**: этап 1 (правила и сервер, с
тестами приватности), этап 2 (экран), этап 3 (бот, полировка, документы). После
каждого этапа: `npm test` (и e2e/вёрстка/контраст/кит там, где этап их
затрагивает), коммит по-русски понятным предложением, пуш в `redesign`,
**короткий отчёт и остановка** — жди моего слова «дальше». Не переходи к
следующему этапу сам.

**Главное — приватность флота.** В морском бое расстановка каждого игрока —
тайна всю партию. Сервер хранит обе расстановки, а страницам до конца партии
уходит только их собственный вид: свой флот, попадания по себе и результаты
своих выстрелов («мимо», «ранил», «убил»; убитый корабль — целиком). Чужая
расстановка не должна просочиться ни в сообщения игрока или наблюдателя, ни в
карточку группы, итоги, шеринг, пульт владельца, логи, тексты ошибок. Тесты
приватности из плана (весь трафик каждого телефона за партию, наблюдатель,
до готовности, отказы не выдают, перезапуск) пиши **раньше экрана** и проверяй
«на зубы»: верни код к сломанному виду (например, добавь чужой флот в `view`) —
тест обязан упасть.

**Железные правила (из AGENTS.md, главное):**
- Никто не ходит за другого: личность только из подписанного `initData`;
  любой отказ объясняется словами. Бот ходит через тот же `handle`, что человек,
  и решает **только по своему виду** — чужого флота в его данных нет.
- Если тест падает — по умолчанию неправ код, а не тест; ассерты не ослаблять.
- `server/game.js` не трогать. `.env` не открывать и не показывать.
- Интерфейс по-русски; тексты — по `MESSAGES.md`; `/help` игр не называет.
- Дизайн: токены из `miniapp/tokens.css`, плоско, без градиентов и свечения;
  состояния клеток различимы не только цветом; зона нажатия от 44 px;
  проверка от 320 px. Выстрел на телефоне — в два шага (выбрал клетку → «Огонь»).
- Не запускай пачками субагентов. Pull request не создавай. **На сервер ничего
  не выкатывай** — выкатку я попрошу отдельно.
- Если что-то нельзя проверить из этой среды (перетаскивание пальцем, живой
  Telegram) — не выдумывай: скажи прямо и дай мне список, что проверить руками
  на телефоне.

Начинай с этапа 1.
