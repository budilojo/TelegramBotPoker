# Отчёт F (chess): итог партии в шахматах

Ветка `release2/run`, без push, PR и выкатки. `server/game.js`, `.env`, правила шахмат и формула рейтинга не менялись.

## Воспроизведено (через хаб, два телефона, настоящие страницы-заглушки, онлайн с человеком)
Детский мат за два телефона. Что было:
- Оба: комната остаётся `playing`, на экране мелкая строка «Вы проиграли — мат», кнопки «Ещё партия», «Поделиться», «Завершить».
- История партии и рейтинг победителю (+20) записывались **сразу сами** — «победу не засчитали» в данных неверно.
- В группу уходила только тихая правка карточки («🏆 Партия #1 — Макс, мат»), без нового сообщения. Сообщение со сводкой и победителем приходило лишь после «Завершить» — отсюда ощущение, что без неё ничего нет.
- «Ещё партия» мог нажать любой из двоих — партия начиналась сразу, без согласия второго.
Что не воспроизвелось: «победа не засчитана» как потеря данных — не воспроизведено (запись есть). Причина слов владельца — тихий итог в чате и кнопка «Завершить» как единственное видимое «окончание».

## Что изменилось
- Итог каждой сыгранной партии (мат, сдача, время, ничья по согласию, пат и т. д.) сам уходит в группу один раз: «♟ Макс победил Ивана — мат (партия 1). Счёт: …». Единый путь `afterAction`/`finishUp`; дедуп `room.announced`; отменённая партия и партии с ботами не объявляются; у старых столов старые партии не повторяются.
- Экран: «Вы победили — мат» / «Вы проиграли — мат» / «Ничья — …».
- «Ещё раз» по согласию: один предлагает, второй видит «Соперник зовёт ещё раз» и «Принять»; с ботом — сразу.
- «Завершить» после партии → «Закончить» (шторка «Закончить серию?» объясняет, что сыгранное уже записано). Итог записывается до любых кнопок.
- Тексты — в `MESSAGES.md`; `docs/duels.md`, решения 161–164, сессия, статус, задачи.

## Другие дуэли (шашки, нарды, морской бой)
По коду та же схема (кнопка «следующая» односторонняя, итог партии в чат — только по «Завершить», хука нет). Быстрый прогон не удался (сдача в первые ходы запрещена), поэтому **не воспроизведено, только прочитано**; не чинил вслепую (разные формы истории, у морского боя тайна флота). Хук `announcements` и схема `askRematch` в общем коде готовы. Решение 164.
