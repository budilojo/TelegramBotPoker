## Решения владельца для этого пакета

- **Цены владелец поручил выбрать нам** (30.10). Выбрано: рубашка **75 ⭐**, знак (рамка и значок) **50 ⭐**, стол **100 ⭐**,
  комплект **175 ⭐** (сумма отдельно — 225; комплект на ~22 % дешевле). Основание: низкий порог для пробной покупки в игровом хабе
  для друзей, комплект выгоднее трёх вещей. Это **рабочие стартовые цены, не рыночный анализ**; менять — в админке (шаг H).
  Цены не открывают продажи: остальные условия (`gate()`: контакт, документы, реквизиты) остаются. Спрос не проверен.
- **Поддержка** — через самого бота (владелец отвечает ботом). Публичный контакт для документов и реквизиты ИП — по-прежнему
  в `owner-inputs.md`: выдумывать их нельзя.
- Остаётся в силе всё из `docs/next-release/00-plan.md`: только косметика без игровых преимуществ; нет подписок, фишек за деньги,
  вывода; платёжный API — заглушка в тестах; продажи закрыты выключателем; **выкатки нет**.
