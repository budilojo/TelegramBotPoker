# Графические элементы для приложения

Готовых SVG-исходников пока нет. PNG — визуальные ориентиры; не разрезать макеты
на фрагменты, заменяющие настоящий интерфейс. Подготовить самостоятельные
исходники и подключить их к существующим компонентам Mini App.

Для каждого элемента ниже нужны четыре палитры: Графит, Сапфир, Бордо, Петроль
из SPEC. Одна геометрия и одинаковая толщина линий, цвет задаётся параметрами.
Имена файлов ниже — план, а не заявление о существовании этих ресурсов.

| Элемент / предлагаемое имя | Назначение | Формат и требования |
|---|---|---|
| `card-back-detail.svg` | Крупная карточка товара и примерка | SVG, подробный симметричный орнамент, центральный ромб, одинаковый viewBox |
| `card-back-small.svg` | Закрытые карты в реальной игре и миниатюры | SVG, упрощённые линии без шума, читаемый ромб; проверить при минимальном размере карт |
| `table-ornament.svg` | Край стола покера и дурака | SVG, плоская декоративная полоса, центр свободен; адаптировать к фактической геометрии каждого игрового поля |
| `table-diamond.svg` | Спокойный центральный знак | SVG, отдельный слой, не мешает картам и банку |
| `avatar-frame-detail.svg` | Крупная примерка профиля | SVG, прозрачный центр, геометрические насечки, не зелёный статус |
| `avatar-frame-small.svg` | Лобби и результаты | SVG, упрощённый вариант, не уменьшает читаемость инициалов |
| `profile-mark.svg` | Знак рядом с именем | SVG, простой полый ромб, читаемый малым, не знак рейтинга |
| Миниатюры предметов | Витрина, инвентарь, переключатель цвета | SVG-композиции или локальные WebP/PNG из исходников, одинаковый масштаб |
| Композиция комплекта | Карточка комплекта, получение | Из самостоятельных SVG/компонентов либо локальный WebP/PNG, не из вырезок макета |
| Базовое оформление | Бесплатная альтернатива и fallback | Существующие ресурсы проекта, не перекрашивать лица карт |

Рамки не должны обрезать аватар. Знак не должен расширять строку имени за границы
экрана. На 320 px длинные имена сокращать по текущим правилам проекта, сохраняя
доступное полное имя. Декоративные SVG скрыть от скринридера; интерактивные
элементы имеют подписи, фокус и состояние выбора независимо от цвета.
Не загружать графику или шрифты с внешних доменов.

## Подготовка и проверка

1. Восстановить согласованную геометрию по референсам, не копировать расхождения
   линий генерации. Подготовить детальный и упрощённый уровни.
2. Сделать четыре варианта одной геометрии через палитры, проверить одинаковые
   viewBox, размеры, толщины и отступы.
3. Проверить реальный малый размер, 320/360/390/430 px, контраст на подложках,
   отсутствие мерцания узора и наложений. У Петроли отличать декор от «Ваш ход».
4. Проверить загрузку/ошибку ресурса и базовую подстановку без влияния на игру.

## Что не переносить с генераций

Градиенты, тени, случайные цвета интерфейса, слишком тонкие узоры, неточные
счётчики и тексты, декоративные кнопки без действия, ошибки количества карт,
ставок или доступных ходов. Данные игры берутся из движка и персонального view,
а не из изображения. Детальный список и приоритет требований — в SPEC.
Подарки и эмблема клуба — будущие ресурсы, сейчас не требуются.
