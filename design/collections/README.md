# Коллекция «Графит»: пакет для реализации

Пакет от 27 октября 2026 года для Telegram Mini App проекта TelegramBotPoker.
Содержит 11 оригинальных PNG-референсов, спецификацию, перечень будущих
графических исходников и готовое задание Claude Code. Это концепты, а не
скриншоты работающих функций. Код приложения этим пакетом не меняется.

## Порядок чтения

1. Актуальный `AGENTS.md` в корне репозитория.
2. Этот README, затем [SPEC.md](SPEC.md) — источник продуктовых требований.
3. [ASSET-LIST.md](ASSET-LIST.md) — что подготовить отдельно от макетов.
4. [CLAUDE-CODE-PROMPT.md](CLAUDE-CODE-PROMPT.md) — готовое задание исполнителю.

При противоречии текста на картинке и SPEC следовать SPEC; устройство приложения
определять по актуальному репозиторию. Все цены демонстрационные.

## Границы этапов

Первая версия: персональная рубашка покера, стол хоста для покера и дурака,
рамка и знак в лобби и результатах, комплект, четыре цвета каждого предмета.
Первый результат реализации — демонстрация без реальных списаний.
Реальные платежи — следующий самостоятельный этап с серверной выдачей.
Подарки, клуб, встречи и клубная статистика — будущее, не часть первой версии.
Рубашки дурака отложены до решения о переходе карт общей колоды между игроками.

## Важные отклонения изображений

На генерациях остались тональные переходы, тени, местами слишком мелкий орнамент,
случайные оттенки элементов интерфейса. На цветовых игровых макетах пары карт
боковых игроков показаны неточно; это не спецификация количества карт.
На подарке счётчик `23/160` не соответствует тексту и не задаёт лимит сообщения.
Подробный список запретов — в SPEC и ASSET-LIST. Не переносить эти ошибки в код.
