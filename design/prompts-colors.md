# «Радуга»: что генерировать для новой игры

## Сначала — чего генерировать не надо

**Не просите нарисовать колоду цветных карт.** Их 108, и в этой игре карты
лежат рядом веером: разъедутся поля, разойдутся оттенки красного, цифры встанут
на разной высоте — и это будет видно сразу. Цифры, кружки и цвета нарисует код,
точно и одинаково, как он уже делает это для покерной колоды
(`tools/make-cards.mjs`).

**Не просите рисовать надписи.** Генератор пишет по-русски с ошибками и
кривыми буквами. Все слова на экране — «Радуга!», «Поймал!», имена, цифры —
ставит код. В промтах ниже надписей нет нигде специально.

**Не просите нарисовать Uno.** Это чужое название и чужой фирменный стиль.
Нам нужна своя игра с цветными картами, а не копия чужой упаковки.

## Что нужно на самом деле: четыре знака, рубашка и два макета

Генерацией стоит делать только то, что рукой рисуется долго, а кодом не
рисуется вовсе:

1. четыре знака особых карт — **«+2»**, **«стоп»**, **«разворот»**, **«смена
   цвета»**;
2. **рубашка** карты;
3. **иконка игры** для карточки в хабе;
4. два **макета экрана** — чтобы верстать по картинке, а не по описанию.

Остальное — цифры, цветные поля, углы, размеры — код.

## Общие требования ко всем промтам

Это важно, иначе картинки не вшить в карты:

- **Белый фон, ровный, без тени и без градиента.** Фон снимается заливкой от
  края (`tools/make-court-art.mjs`), серый или тонированный фон сломает это.
- **Один знак в кадре, по центру, с полями** примерно в десятую часть ширины.
- **Квадрат, 1024×1024.**
- **Плоская векторная графика**, толстый ровный контур, никакой трёхмерности,
  никаких блёсток, отражений и объёмных теней.
- **Без текста и без цифр** (единственное исключение — знак «+2», там цифра часть
  знака).
- Один стиль на все четыре знака: просите их **одной серией, по одной картинке
  за раз**, и в каждом промте повторяйте описание стиля целиком.

## Промт 1: знаки особых карт

Сделайте четыре отдельных запроса, подставляя нужный знак.

```
Нарисуй один знак для игральной карты, плоская векторная графика.

Знак: ДВЕ КАРТЫ, ЛЕЖАЩИЕ ВЕЕРОМ, И РЯДОМ БОЛЬШОЙ ПЛЮС
(варианты для следующих запросов:
 — РАСКРЫТАЯ ЛАДОНЬ, КАК ЗНАК «СТОЙ»;
 — ДВЕ ИЗОГНУТЫЕ СТРЕЛКИ, ИДУЩИЕ НАВСТРЕЧУ ДРУГ ДРУГУ ПО КРУГУ;
 — ЧЕТЫРЕ КАПЛИ КРАСКИ, СОЕДИНЁННЫЕ В КРУГ, КАЖДАЯ СВОЕГО ЦВЕТА:
   красная, жёлтая, зелёная, синяя)

Стиль: плоский вектор, толстый ровный контур одной толщины, крупная простая
форма, читается с расстояния вытянутой руки и в размере ногтя. Чёрный контур,
внутри — белая заливка (для знака с каплями — четыре цвета). Без объёма, без
теней, без градиентов, без блеска, без мелких деталей.

Фон: чистый белый, ровный, ничего кроме знака.
Знак строго по центру, занимает примерно восемьдесят процентов кадра.
Квадратное изображение 1024×1024.
Никаких букв, слов и цифр, кроме знака плюс в первом варианте.
```

Почему именно так: эти знаки будут стоять в углу карты размером меньше ногтя и
в центре карты крупно. Всё, что сложнее четырёх линий, в углу превратится в
грязь.

## Промт 2: рубашка карты

```
Нарисуй рубашку игральной карты — узор на обратной стороне.

Узор: радужные мазки краски, расходящиеся из центра по кругу, четыре цвета —
красный, жёлтый, зелёный, синий, — на глубоком тёмно-синем фоне. Узор
плотный, ритмичный, повторяющийся, без единого центрального предмета и без
надписей.

Стиль: плоская векторная графика, крупные простые формы, насыщенные цвета,
толстый ровный контур. Без объёма, без теней, без блеска, без мелких деталей.

Вертикальный прямоугольник в пропорции 2 к 3, узор заполняет его целиком до
самых краёв, без рамки и без полей.
Разрешение не меньше 1024 по короткой стороне.
Никаких букв, слов и цифр.
```

## Промт 3: иконка игры для хаба

```
Нарисуй иконку настольной игры: три игральные карты, лежащие веером, каждая
своего цвета — красная, жёлтая, зелёная, — слегка перекрывают друг друга.

Стиль: плоская векторная графика, толстый ровный тёмный контур, насыщенные
плотные цвета, крупная простая форма, читается в размере ногтя. Без объёма, без
теней, без градиентов, без блеска, без мелких деталей, без лиц и персонажей.

Фон: чистый белый, ровный, ничего кроме карт.
Строго по центру, с небольшими полями.
Квадратное изображение 1024×1024.
Никаких букв, слов и цифр.
```

## Промт 4: макет экрана стола

Это не картинка для вшивания, а макет для вёрстки: по нему я сделаю SVG, как
делал со столом дурака. Поэтому здесь нужен **экран телефона целиком**.

```
Нарисуй макет экрана мобильного приложения — карточная игра «цветные карты» на
телефоне. Вертикальный экран 9:16, вид сверху вниз.

Что на экране, сверху вниз:
— узкая верхняя полоса: слева круглая кнопка «назад» в виде стрелки, справа
  маленький круглый аватар;
— три круглых аватара соперников по верхней части экрана, под каждым —
  маленькая овальная плашка с местом под число; у одного аватара светящаяся
  рамка, показывающая, что сейчас его ход;
— центр экрана: две карты рядом — слева закрытая карта с радужным узором на
  тёмно-синем фоне (колода), справа открытая зелёная карта с крупной цифрой
  (куча сброса); вокруг них по кругу тонкая стрелка, показывающая направление
  хода;
— ниже: широкая яркая кнопка-пилюля;
— внизу экрана: веер из семи карт, повёрнутых друг относительно друга,
  перекрывающих друг друга примерно на треть; карты четырёх цветов — красные,
  жёлтые, зелёные, синие — с крупными цифрами; средние карты приподняты выше
  крайних.

Стиль: тёмный фон экрана — глубокий тёмно-зелёный, как сукно игрового стола, с
мягким свечением в центре. Карты — плоские, со скруглёнными углами, с белой
рамкой по краю, цвета насыщенные и чистые. Интерфейс простой и крупный, как в
хорошем мобильном приложении: большие кнопки, много воздуха, ничего лишнего.
Плоский дизайн, без трёхмерности, без фотореализма.

Все надписи оставь пустыми плашками — никакого текста, никаких букв.
Разрешение не меньше 1024 по короткой стороне.
```

## Промт 5: макет шторки выбора цвета

```
Нарисуй макет нижней шторки мобильного приложения — выбор цвета в карточной
игре. Вертикальный экран 9:16.

Верхние две трети экрана — затемнённый размытый игровой стол тёмно-зелёного
цвета, он на втором плане. Нижняя треть — поднявшаяся снизу светлая панель со
скруглёнными верхними углами, в ней:
— узкая горизонтальная полоска-ручка по центру сверху;
— пустая плашка под заголовок;
— четыре крупные квадратные кнопки со скруглёнными углами в ряд два на два:
  красная, жёлтая, зелёная, синяя, насыщенные и чистые цвета, у каждой тонкая
  белая обводка;
— внизу широкая кнопка-пилюля нейтрального серого цвета.

Стиль: плоский дизайн, крупные элементы, много воздуха, как в хорошем мобильном
приложении. Без трёхмерности, без теней под каждым элементом, без фотореализма.

Все надписи оставь пустыми плашками — никакого текста, никаких букв.
Разрешение не меньше 1024 по короткой стороне.
```

## Как присылать результат

Четыре знака и рубашку — **файлами** (png или webp), по одному на знак, как
присылали короля, даму и валета: они пойдут через `tools/make-court-art.mjs` в
колоду. Два макета можно просто картинками в чат — по ним я сделаю SVG и вёрстку.

Если какой-то знак получился не с первого раза — присылайте лучший из
нескольких, но **все четыре должны быть из одной серии**: разные по стилю знаки
на столе рядом видно сразу.
