# Промты для ChatGPT: картинки-макеты

Как пользоваться: копируете **общую часть**, под ней — промт нужного экрана,
отправляете одним сообщением. Одна картинка — один экран.

Если картинка вышла «постером» (блёстки, объём, золото) — допишите в конец:
«Плоско. Это интерфейс приложения, а не иллюстрация. Без объёма, бликов и
свечения». Обычно с первого раза выходит именно постер.

**Текст на картинке набирать не нужно.** Модель всё равно напишет бессмыслицу.
Мне нужна композиция: что где лежит, что крупное, что мелкое, какого цвета.
Настоящие слова я подставлю сам.

## Общая часть — ставить в начало каждого промта

```
Нарисуй макет экрана мобильного приложения. Это интерфейс, а не иллюстрация.

Формат: вертикальный, пропорции экрана телефона 9:19.5, без рамки телефона,
без руки, без стола вокруг — только сам экран, во всю картинку.

Стиль: плоский современный интерфейс, тёмная тема. Без объёма, без бликов,
без свечения, без золотых завитушек, без 3D. Мягкие скругления у плашек и
кнопок (14–20 px), спокойные тени.

Палитра: фон почти чёрный #0A1216, плашки #13212A, текст белый #F2F7F5,
подписи серо-голубые #A9BCC0, акцент зелёный #2EE08C, золотой #F2C96B только
для важного, красный #D2342B для красных мастей.

Русский интерфейс. Надписи можно не выписывать разборчиво — важна композиция.
```

## 1. Стол дурака

```
Экран: карточная игра «Дурак» на четверых.

Сверху узкая строка: слева маленькая плашка с кодом стола, по центру подпись
про козырь, справа кнопка-многоточие.

Ниже большой овальный стол глубокого бирюзового сукна (#1E6E7E в центре,
#0A2E39 по краю), верх скруглён дугой, низ почти прямой.

По верхней дуге стола три соперника: круглый аватар 44 px, под ним имя и
число карт, у активного — зелёное кольцо вокруг аватара.

ВАЖНО, это главное в макете: колода прижата к ЛЕВОМУ краю экрана и подрезана
им — видно только правую треть стопки, из-под неё вбок торчит одна открытая
карта козыря. Стопка сброса прижата к ПРАВОМУ краю и тоже подрезана — видно
только край веера рубашек. Обе не мешают центру.

Центр стола пустой, в нём только текущий кон: две-три пары карт, в каждой
одна карта лежит поверх другой под небольшим углом, и одна карта ещё не
покрыта — вокруг неё пунктирная голубая рамка.

Внизу две широкие кнопки в ряд: левая тёмная с обводкой, правая зелёная.

Под ними своя рука: шесть крупных карт веером, лицом вверх, перекрывают друг
друга, лежат ниже кнопок у самого низа экрана.
```

## 2. Стол покера

```
Экран: техасский холдем на пятерых.

Сверху узкая строка: слева маленькая плашка со стадией раздачи, по центру
подпись про блайнды, справа кнопка-многоточие.

Ниже большой овальный стол ЗЕЛЁНОГО сукна (#2A7B55 в центре, #0A3322 по
краю) — зелёный, а не бирюзовый: это другая игра.

По овалу четыре соперника: круглый аватар, под ним имя и стек, под стеком
маленькая плашка с его действием. Две карты рубашкой вверх торчат ИЗ-ЗА
аватара сверху, маленькие, они не должны лезть вперёд.

В центре стола, над картами, плашка с банком — крупное число в рамке.
Под ней пять карт борда в ряд: три открыты, две — пустые тёмные гнёзда.

Ниже борда тонкая подпись про текущую ставку.

Внизу, поверх нижнего края сукна, две СВОИ карты — крупные, заметно больше
карт борда, слегка развёрнуты веером. Под ними маленькая плашка с подсказкой
о комбинации.

Под ними строка: слева имя и «ваш ход», справа свой стек. Под строкой тонкая
зелёная полоска — время на ход, заполнена на две трети.

В самом низу три кнопки в ряд: тёмная с красной обводкой, зелёная и золотая.
На каждой сверху слово покрупнее, под ним сумма помельче.
```

## 3. Хаб: выбор игры

```
Экран: список игр, куда попадают из группы.

Сверху крупный заголовок в две строки и под ним серая подпись помельче.

Дальше вертикальный список из четырёх широких карточек-строк, между ними
зазор 12 px. Каждая карточка: слева квадратная иконка со скруглением 16 px,
в середине название игры и под ним мелкая подпись, справа маленькая
скруглённая кнопка.

Первые две карточки активные: тёмная плашка с еле заметной цветной обводкой,
кнопка справа зелёная. Третья и четвёртая приглушённые, полупрозрачные, у них
кнопка серая — это игры «скоро».

Ниже отдельная широкая плашка с золотистой обводкой и золотистым фоном
на 10% — это вход в рейтинг, с иконкой кубка слева.

Под ней мелкий заголовок-разделитель и одна-две строки открытых игр.

Внизу экрана мелкая серая подпись по центру.
```

## 4. Рейтинг

```
Экран: таблица рейтинга игроков.

Сверху маленькая кнопка «назад» стрелкой, под ней крупный заголовок с иконкой
кубка и серая подпись.

Ниже ряд из двух широких кнопок-таблеток: одна зелёная (выбранная), другая
тёмная. Под ними второй такой же ряд, поменьше.

Дальше список из шести строк, между ними зазор 8 px. Каждая строка — тёмная
плашка со скруглением 16 px: слева место (у первых трёх вместо цифры медаль),
в середине имя и под ним мелкая подпись со статистикой, справа крупное
золотое число очков.

Одна строка в середине списка выделена зелёной обводкой — это «вы».

Под списком мелкий серый текст в три строки — объяснение, как считаются очки.
```

## 5. Лобби: стол собирается

```
Экран: собираются играть, ждут остальных.

Сверху крупный заголовок с названием игры и серая подпись под ним.

Ниже большая тёмная плашка со скруглением 18 px, внутри сетка 3×2 из шести
ячеек-мест. Три верхние заняты: круглый аватар и имя под ним. Три нижние
свободны: пунктирная обводка, внутри бледный кружок с плюсом и слово
«свободно».

Под плашкой ряд маленьких таблеток с правилами стола, они переносятся на
вторую строку. Одна таблетка выделена цветной обводкой.

Ниже ещё одна тёмная плашка — два пункта списком, у каждого название и мелкая
подпись, между ними тонкая разделительная линия.

Внизу экрана две широкие кнопки друг под другом: верхняя зелёная, нижняя
тёмная с обводкой.
```

## 6. Итоги партии

```
Экран: партия кончилась, итоги.

Сверху по центру мелкая разрядка золотым — надзаголовок. Под ней крупный
заголовок в одну строку, под ним серая подпись помельче.

Ниже список из четырёх строк-плашек, между ними 10 px. Каждая: слева кружок
с номером места, в середине имя и мелкая подпись, справа — ничего или число.

Первая строка выделена зелёной обводкой, кружок места у неё зелёный.
Последняя строка выделена золотой обводкой, кружок золотой — это проигравший.

Ниже мелкая серая подпись по центру.

Внизу две кнопки в ряд: левая тёмная с обводкой, правая зелёная.
```

## 7. Шторка снизу (любая: ставка, меню, карточка игрока)

```
Экран: поверх затемнённого стола выехала шторка снизу.

Верхние две трети экрана — размытый тёмный стол под затемнением 70%.

Нижняя треть — шторка: скруглена только сверху (24 px), фон #182B35, сверху
по центру короткая серая полоска-«ручка».

Внутри шторки сверху вниз: мелкая разрядка-надзаголовок, очень крупное число
золотым, под ним серая строка пояснения, дальше горизонтальный ползунок с
круглой белой ручкой примерно на трети, под ним три одинаковые кнопки в ряд
(левая выделена), и в самом низу одна широкая кнопка во всю ширину.
```
